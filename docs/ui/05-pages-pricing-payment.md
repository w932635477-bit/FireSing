### 支付流程
```
1. 选择支付方式 → 高亮选中项
2. 点击确认支付
3. 显示二维码弹窗:

   ┌─────────────────────────────┐
   │  微信扫码支付         ✕     │
   │                             │
   │  ┌───────────────────┐     │
   │  │                   │     │
   │  │   [二维码 200×200] │     │
   │  │                   │     │
   │  └───────────────────┘     │
   │                             │
   │  请使用微信扫描二维码        │
   │  ¥49.00                     │
   │                             │
   │  ● 等待支付中...            │
   │  (自动轮询支付状态)         │
   │                             │
   └─────────────────────────────┘

4. 支付成功 → 显示成功动画 (✓ 大勾 + 绿色)
5. 2秒后跳转到 Dashboard
```

# Sings 穿搭视频转型设计：B+D 组合变现路径

日期: 2026-04-24
状态: 已批准

## 决策背景

Sings 穿搭 AB 对比视频经过客观评估，发现以下问题：
- AI 虚拟人做穿搭教学赛道先天不足（无法提供真实穿搭参考）
- 歌曲形式降低信息密度，不如图文/短视频直观
- 缺乏真正的穿搭专业度（通用常识级内容）
- 小红书核心价值是"真实消费体验"，虚拟人缺乏信任基础

核心结论：核心竞争力是"批量生产 AI 视频"的能力，不是"杨梦穿搭"这个内容。

## 转型方向：B+D 组合

### 第一步（0-4周）：代运营验证
- 用现有管线接 2-3 个 AI 视频代运营单子
- 目标：验证有人愿意为 AI 视频付费
- 覆盖 API 成本，产生现金流
- 积累真实客户案例

### 第二步（1-2个月）：内容引流
- 把代运营案例做成内容发布
- 内容定位从"穿搭教学"转为"AI 视频制作展示"
- 吸引目标客户：想做 AI 视频的商家/创作者
- 穿搭内容降为日常维护内容，不再作为主力

### 第三步（2-3个月）：知识产品
- 基于真实案例推出课程或工具包
- 有案例数据才有定价权和说服力
- 产品形态：AI 视频制作教程 / Prompt 模板包 / 训练营

## 穿搭内容的调整

Sings 穿搭内容不放弃，但定位调整：
- 从"穿搭教学"转为"穿搭娱乐"（不需要专业，需要有趣）
- 继续发布维持更新频率，但不再作为变现主力
- 作为展示 AI 视频制作能力的 portfolio

## Config 和管线变更

已完成的优化：
- 所有 config candidates_per_segment 改为 1（降低 50% API 成本）
- suno-rap-batch.py 加 --count 参数（默认只生成 1 首音乐）
- 单视频成本从 ~$1.73 降至 ~$0.50

待做：
- 调整歌词模板为更娱乐化的叙事风格
- 按"故事驱动 AB 对比"方向写新的 config
- 音乐风格按场景定制

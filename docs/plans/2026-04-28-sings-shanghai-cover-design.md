# Sings 上海冷知识对唱翻唱设计

## 概述

用《今天你要嫁给我》（陶喆 & 蔡依林）旋律翻唱，歌词完全重写为上海冷知识主题的男女对唱。杨梦女声 + 男声伴唱，以"去过但不知道这些"的角度引发观众好奇心和互动。

## 原曲信息

- **歌曲**: 《今天你要嫁给我》
- **原唱**: 陶喆 & 蔡依林
- **BPM**: ~90（中速甜蜜流行）
- **风格**: 甜蜜对话式对唱
- **版权**: 已确认版权风险，用户接受用于内容测试

## 歌词设计说明

### 冷知识点覆盖

1. **上海/下海**: 浦东提篮桥有下海庙，与"上海"对应
2. **九曲桥18弯**: 豫园九曲桥名字是"九曲"但实际有18个弯
3. **市花棉花**: 上海最早市花是棉花（现在是白玉兰）
4. **马路**: 来自洋人在上海跑马，"马路"=马走的路
5. **石库门**: 宁波话"石箍门"的误读演变
6. **肉馒头**: 上海人把包子叫"馒头"，肉包=肉馒头

### 歌词风格

- **角度**: "去过但不知道"的冷知识揭秘，不是旅游攻略
- **互动设计**: 每个知识点都是"你知道吗"式提问，引发评论区讨论
- **Outro彩蛋**: "肉馒头=肉包"是轻松收尾，引发"你们那儿叫什么"的方言互动

## 技术方案

### Suno Cover API 翻唱

- **Endpoint**: `generate/upload-cover`
- **Model**: V4_5
- **audio_weight**: 0.8（高旋律保持）
- **原始音频**: 《今天你要嫁给我》原曲音频（需准备）
- **Duet格式**: `Duet (Alternating)` + `[Female]/[Male]/[Both]` 标记
- **[Both]**: 仅用于副歌

### 生产管线

1. 准备原曲音频文件
2. Suno Cover API 生成翻唱
3. Seedream 生成上海冷知识主题参考图
4. Kling 生成视频片段
5. FFmpeg 拼接 + 剪映后期

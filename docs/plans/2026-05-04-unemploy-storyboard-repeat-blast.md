## 2. TTS 完整脚本（含 Director's Notes）

每行为一个独立 TTS 请求，可直接喂入 `gemini-tts-batch.py`。

```
# LINE 01 — HOOK（3s处，第一声）
# 用途：黑屏后的第一句，像一记耳光
# 技法：短促、官方、不带感情——越是客气越刺痛
[calm, corporate, detached] "回去等通知吧。"

# LINE 02 — PATTERN 第1次（4s，3-7s段）
# 用途：面试场景，HR客套式的拒绝
# 技法：礼貌但敷衍，"你的情况了解了"是废话铺垫
[polite, dismissive, slightly rushed at the end] "嗯，你的情况我们了解了。回去等通知吧。"

# LINE 03 — PATTERN 第2次（4s，7-11s段）
# 用途：HR开始不耐烦，比第一次冷淡
# 技法：加快语速，"先"字强调"你只是备胎"
[slightly impatient, dismissive] "我们还有其他候选人，你先回去等通知吧。"

# LINE 04 — PATTERN 第3次（3s，11-14s段）
# 用途：HR给你希望再拿走，最残忍的一种
# 技法："其实你条件不错"说得真诚，"不过"之后语速加快草草收尾
[warm but final, switching to cold] "其实你条件不错，不过...回去等通知吧。"

# LINE 05 — PATTERN 第4次（4s，14-18s段）
# 用途：HR已经不想演了，连客套都省了
# 技法：含糊、匆忙、像在念台词最后一句
[rushed, almost muttering, indifferent] "好，就这样，回去等通知吧。"

# LINE 06 — ESCALATION 快切1（2s，20-22s段）
# 用途：叠音开始，耳语式的压迫
# 技法：气声、贴近话筒、像在自己脑子里回响
[whisper, close to mic, haunting] "回去等通知吧"

# LINE 07 — ESCALATION 快切2（2s，22-24s段）
# 用途：机械化重复，像系统自动回复
# 技法：平直无感情，每个字等间隔，机器感
[flat, robotic, monotone, no emotion] "回去等通知吧"

# LINE 08 — ESCALATION 快切3（2s，24-26s段）
# 用途：自嘲苦笑后的重复，情绪翻转
# 技法：先苦笑一声再说，说的时候嘴角是歪的
[bitter laugh, then resigned] "回去等通知吧"

# LINE 09 — ESCALATION 快切4（2s，26-28s段）
# 用途：最后一击，最慢最轻
# 技法：比所有前面都慢，每个字之间都有停顿，像说完就没力气了
[very slow, defeated, each word separated] "回去...等通知吧"

# LINE 10 — ESCALATION 连击（3s，28-31s段）
# 用途：文字雨配叠音，4句紧贴在一起
# 技法：加速+音量渐强，最后一句几乎是喊出来
[intense, rapid, building to shout] "回去等通知吧回去等通知吧回去等通知吧回去等通知吧"

# LINE 11 — ESCALATION 最后一击（2s，31-33s段）
# 用途：崩溃前的最后一声，内心在尖叫
# 技法：压抑的嘶吼，不是真的喊，是咬牙切齿的喊
[screaming inside, clenched teeth, suppressed rage] "回去等通知吧！！"

# LINE 12 — BREAK 静默后（2s，35-37s段）
# 用途：所有噪音消失后，唯一的、最小声的、最重的话
# 技法：极慢，几乎听不见，像对自己说
[very slow, barely audible, heavy] "半年了。"

# LINE 13 — BREAK 转折（2s，37-39s段）
# 用途：停顿后，最脆弱的一个字
# 技法："你"字拖长，0.5s停顿，像不敢问完
[long pause before, then vulnerable, trailing off] "你..."

# LINE 14 — BREAK 完成（2s，39-41s段）
# 用途：问题终于问完，不需要回答
# 技法：轻微颤抖，句尾下沉
[quiet, trembling slightly, defeated] "还在等吗？"

# LINE 15 — TRAP CTA（4s，43-47s段）
# 用途：从黑暗中拉出来，给观众一个出口
# 技法：语气突然温暖，像朋友在问你
[warm, gentle, encouraging, as if talking to a friend] "你等了多久？"
```

### TTS 技术备注

- **LINE 01-05**：5个独立请求，每句 "回去等通知吧" 都用不同 Director's Notes 组合。即使引擎输出相似，情绪标签的差异会让节奏和重音有微妙变化。
- **LINE 06-09**：ESCALATION 的 4 句是关键差异化段，必须用极端对立的情绪标签（whisper vs robotic vs bitter vs defeated），见第 5 节风险规避。
- **LINE 10**：连击句，单次请求生成，引擎自然会在句尾加速。
- **LINE 12-14**：BREAK 段，每个 TTS 请求只含 2-3 个字，给引擎足够的发挥空间。
- **LINE 15**：CTA 语气突变是设计意图，从压抑突然转到温暖，观众会松一口气。

## 4. 系列变体（3个后续集数）

### Episode 02 — "我们会考虑的"

| 阶段 | 内容 | 文案 |
|------|------|------|
| HOOK | "你已经听过这句话___次了" → "我们会考虑的" | 同结构 |
| PATTERN | 4次递进："我们会考虑的" | 第1次[真诚]→第2次[敷衍]→第3次[不耐烦]→第4次[翻白眼后敷衍] |
| ESCALATION | "我们会考虑的"叠音+文字雨 | 同结构 |
| BREAK | 静默后："三个月了。" "他们考虑过吗？" | 比"半年"短，更日常 |
| TRAP | "你被考虑过几次？评论区说说" | "考虑"二字反讽 |

**差异化要点**：
- "回去等通知吧"是明拒，"我们会考虑的"是假希望，更恶心
- BREAK段用"考虑过吗？"而不是"还在等吗？"——前者是质问，后者是自问
- 次数标记从"第1次"到"第39次"

### Episode 03 — "你年龄不太合适"

| 阶段 | 内容 | 文案 |
|------|------|------|
| HOOK | "HR最常说的一句话，不是'不行'" → "你年龄不太合适" | 更尖锐，直击35+痛点 |
| PATTERN | 4次递进，每次换一个包装 | 第1次："我们需要更有活力的" → 第2次："团队偏年轻化" → 第3次："这个岗位一般30以下" → 第4次："你经验很好，但..." |
| ESCALATION | 各种年龄歧视的变体叠在一起 | "35岁以上""优化""年轻化""结构升级""年龄不太合适" |
| BREAK | "我今年38。" "做错什么了？" | 不提"等"，提"做错"——自责比等待更痛 |
| TRAP | "你的行业卡年龄吗？评论区聊聊" | 引发行业讨论 |

**差异化要点**：
- 不是重复同一句话，而是重复同一个意思的4种说法——观众听到"需要更有活力"就知道是年龄歧视
- ESCALATION 段用不同词汇但同一指向，制造"怎么换汤不换药"的绝望感
- BREAK 的"做错什么了？"指向自我怀疑，比"还在等吗？"更深一层

### Episode 04 — "有消息会通知你的"

| 阶段 | 内容 | 文案 |
|------|------|------|
| HOOK | "最温柔的一句话，最残忍" → "有消息会通知你的" | "温柔"与"残忍"的反差 |
| PATTERN | 4次递进 | 第1次[温柔微笑]→第2次[温柔但眼神已移开]→第3次[温柔+已经在收拾东西]→第4次[温柔+门已关上] |
| ESCALATION | "有消息会通知你"叠音，同时叠加手机"未读0"的视觉 | 旁白说"会通知你"，画面显示永远不会来的通知 |
| BREAK | "一年了。" "手机...没响过。" | 最长的等待，最彻底的沉默 |
| TRAP | "等最久的那次，你等了多久？" | 不问"等了多久"，问"最久的那次"——暗示每个人心里都有一根刺 |

**差异化要点**：
- "有消息会通知你"给的是希望，不是拒绝——希望破灭比被拒绝更痛
- ESCALATION 段叠加视觉元素（手机屏幕永远是"未读0"），画面和声音双重暴击
- BREAK 段"手机没响过"——一个简单的客观事实，比任何形容词都重
- CTA "最久的那次"暗示每个人都有story，不只是数字

## 5. 风险规避：让同一句话的重复听起来完全不同

### 核心问题

Gemini TTS Charon 生成同一句话 15 次，即使 Director's Notes 不同，引擎可能仍然输出高度相似的音频。观众听出"这是 AI 重复同一段"就完了。

### 技术方案（7 层防御）

#### 第1层：极端情绪标签差异化

每一句的 Director's Notes 不只是"换一种感觉"，而是用**互斥的情绪**：

| 句子 | 标签 | 为什么听起来不同 |
|------|------|----------------|
| LINE 01 | calm, corporate, detached | 官方语气，不带人味 |
| LINE 02 | polite, dismissive, slightly rushed | 有礼但敷衍，句尾加速 |
| LINE 03 | slightly impatient, dismissive | 不耐烦，明显赶人 |
| LINE 04 | warm but final, switching to cold | 前半暖后半冷，情绪断裂 |
| LINE 05 | rushed, almost muttering, indifferent | 含糊，像在自言自语 |
| LINE 06 | whisper, close to mic, haunting | 气声耳语，完全不同的音色 |
| LINE 07 | flat, robotic, monotone | 机械感，刻意去人味 |
| LINE 08 | bitter laugh, then resigned | 先笑再说，改变呼吸节奏 |
| LINE 09 | very slow, defeated, each word separated | 极慢+字间停顿 |
| LINE 10 | intense, rapid, building to shout | 加速+渐强 |
| LINE 11 | screaming inside, clenched teeth | 咬牙，改变嘴型和共鸣 |

#### 第2层：上下文包装（Context Wrapping）

每句"回去等通知吧"不单独发送，而是嵌入**不同的前置句子**，给引擎更多语境：

```
LINE 02: "嗯，你的情况我们了解了。回去等通知吧。"
LINE 03: "我们还有其他候选人，你先回去等通知吧。"
LINE 04: "其实你条件不错，不过...回去等通知吧。"
LINE 05: "好，就这样，回去等通知吧。"
```

引擎生成完整句子时，前半句的情绪会自然影响后半句"回去等通知吧"的语调。最终剪辑时可以只保留后半句。

#### 第3层：FFmpeg 后处理变调

对 ESCALATION 段的 4 句做不同程度的音高偏移：

```bash
# LINE 06: 升高 1.5 半音（更紧张）
ffmpeg -i line06.mp3 -af "asetrate=44100*1.09,aresample=44100" line06_pitched.mp3

# LINE 07: 降低 2 半音（更机械、低沉）
ffmpeg -i line07.mp3 -af "asetrate=44100*0.89,aresample=44100" line07_pitched.mp3

# LINE 08: 升高 0.5 半音 + 轻微回声（空旷感）
ffmpeg -i line08.mp3 -af "asetrate=44100*1.03,aresample=44100,aecho=0.8:0.3:40:0.3" line08_pitched.mp3

# LINE 09: 降低 1 半音 + 放慢速度 15%（更绝望）
ffmpeg -i line09.mp3 -af "asetrate=44100*0.94,aresample=44100,atempo=0.85" line09_pitched.mp3
```

#### 第4层：音量与空间处理

| 句子 | 音量 | 声像 | 效果 |
|------|------|------|------|
| LINE 01 | 标准 0dB | 居中 | 干声 |
| LINE 02-05 | 标准 0dB | 居中 | 加轻微房间混响（模拟面试间） |
| LINE 06 | -6dB（很轻） | 居中偏左 | 密集混响（脑海回响感） |
| LINE 07 | -3dB | 居中 | 完全干声（电话音质感） |
| LINE 08 | -2dB | 居中 | 加电话滤波（300-3400Hz bandpass） |
| LINE 09 | -8dB（极轻） | 居中偏右 | 加长混响 tail |
| LINE 10 | -1dB→+3dB 渐强 | 居中 | 双层叠轨（原声+pitch升2半音的副本） |
| LINE 11 | +3dB（最响） | 居中 | 加轻微失真（overdrive） |

#### 第5层：备用生成策略

对 LINE 06-09（ESCALATION 段最关键的 4 句），每句**生成 3 个版本**，选差异最大的：

```
Version A: 原始 Director's Notes
Version B: 增加额外标签 [anxious, trembling voice] / [cold, dead inside] / [sarcastic, laughing at himself] / [exhausted, can barely speak]
Version C: 换一个完全不同的上下文句："那天HR对我说，回去等通知吧" / "每次都是一样的话，回去等通知吧" / "他们笑着对我说，回去等通知吧" / "最后一次听到的是，回去等通知吧"
```

从 3 个版本中选听感差异最大的一条使用。

#### 第6层：BGM 节奏锚定差异

每一句"回去等通知吧"落在不同的音乐节拍位置上：

- PATTERN 段：落在心跳声的正拍上（60bpm，每句正好一个心跳周期）
- ESCALATION 段：心跳加速到 120→140→160bpm，每句的心跳密度翻倍，物理层面制造紧迫感
- BREAK 段：心跳完全消失，用呼吸声替代

观众感知差异的来源不只是声音本身，还有**声音和音乐节奏的关系**。

#### 第7层：视觉节奏差异化

即使声音有相似度，视觉节奏的差异会让观众的大脑觉得"每次都不一样"：

| 句子 | 画面变化 | 剪辑节奏 |
|------|---------|---------|
| LINE 02 | 缓慢推进（4s一个镜头） | 慢 |
| LINE 03 | 固定镜头（4s） | 慢 |
| LINE 04 | 手持微晃（3s） | 中 |
| LINE 05 | 快速推入（4s） | 中 |
| LINE 06 | 硬闪+2s | 快 |
| LINE 07 | 硬闪+2s | 快 |
| LINE 08 | 硬闪+2s | 快 |
| LINE 09 | 硬闪+2s | 快 |
| LINE 10 | 快切叠满屏 | 极快 |

### 风险检查清单

制作完成后，用以下清单自检：

- [ ] 任意两句"回去等通知吧"的波形在 Audacity 中视觉可区分
- [ ] 戴耳机听 ESCALATION 段，4 句的方向感不同（左/中/右）
- [ ] BREAK 段的"半年了"和前面所有"回去等通知吧"的音色明显不同
- [ ] 整片 50s 内没有超过 3s 的纯静态画面（避免滑走）
- [ ] HOOK 的 3s 内有至少 2 次视觉变化（黑屏→白字→红字→素材）

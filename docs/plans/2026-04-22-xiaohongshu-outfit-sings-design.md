# 小红书 Sings 穿搭对比对唱设计

**日期**: 2026-04-22
**状态**: 已批准
**作者**: 用户 + Claude 协作

## 背景

FireSing 内容项目目前有两个工作流（Medvi 叙述驱动 / Sings 对唱驱动），混合发在一个账号里。
决定拆分平台策略，每个平台专注一个工作流，同时将小红书的 Sings 内容从商业主题转向穿搭对比，
匹配小红书年轻女性用户的兴趣。

## 双平台策略

| | 抖音 | 小红书 |
|---|---|---|
| 工作流 | Medvi（叙述驱动） | Sings（对唱驱动） |
| 内容 | 商业名人故事 + 情绪拉动 | 穿搭场景对比 + 美学建议 |
| 角色定位 | 深度思考的杨梦 | 有品味的杨梦 |
| 时长 | 30-45s | 30-45s |
| 色调 | 暗金，电影质感 | 明亮时尚，对比鲜明 |
| CTA | 评论区聊人生感悟 | 投票 A/B 穿搭选择 |
| 发布频率 | 每日 1 条 | 周一至周五每日 1 条 |

核心：同一个 IP，两个平台两个人设侧重点。抖音建立"有深度"的品牌认知，
小红书建立"有品味"的审美信任。两边粉丝互相引流，形成品牌合力。

## 小红书 Sings 单集结构（30-45s）

| 段落 | 时长 | 内容 | 画面 |
|---|---|---|---|
| Hook | 6s | 男声提问穿搭场景 | 杨梦全身 A/B 穿搭并排 |
| Body 1 | 6s | 男女对唱讲 A 套逻辑 | 杨梦穿 A 套特写 + 文字卡 |
| Body 2 | 6s | 男女对唱讲 B 套逻辑 | 杨梦穿 B 套特写 + 文字卡 |
| Body 3 | 6s | 总结穿搭法则 | 对比画面 + 法则文字卡 |
| CTA | 6s | "你选哪套？评论区告诉我" | 杨梦直视镜头微笑 |

### 歌词示例（面试穿搭）

```
[Hook - 男] 面试穿西装还是休闲 评委看第一眼
[Hook - 女] 不是衣服贵不贵 是你对不对位

[Body 1 - 男] A套 深蓝西装配白衬衫 经典不出错
              这条领带太正式 像去银行不是科技
[Body 1 - 女] B套 针织衫搭深色裤子 干净有层次
              不用装成熟 做你自己就够自信

[Body 2 - 男] 穿搭法则第一条 看行业定基调
              金融就要正式 互联网反而太拘谨
[Body 2 - 女] 法则第二条 合身比品牌重要
              肩膀对不上号 大牌也像借来的

[CTA - 合唱] 面试穿搭你站A还是B
             评论区告诉我 你的品味
```

### 视觉风格

- 主色：`#f5e6d3`（奶油白）+ `#2d2d2d`（深灰）+ `#e8a87c`（暖橘色）
- 穿搭对比：左右分屏或快速切换
- 文字卡：白底黑字，时尚杂志排版风格
- Seedream prompt 重点：杨梦全身照，不同风格服装，明亮背景

## 变现路径

| 阶段 | 时间 | 目标 | 变现方式 |
|---|---|---|---|
| 冷启动 | 第 1-4 周 | 粉丝 5000+ | 无变现，纯内容积累 |
| 增长期 | 第 2-3 月 | 粉丝 2 万+ | 淘宝联盟/京东联盟穿搭链接 |
| 变现期 | 第 4 月+ | 粉丝 5 万+ | 品牌合作 + 穿搭课程/电子书 |

关键指标：
- 冷启动：单条播放量 > 1000，互动率 > 5%
- 增长期：粉丝增速、收藏率
- 变现期：链接点击率、品牌询价

## 技术实现

### 保持不变

- Suno AI 男女对唱生成流程
- 130 BPM，4/4 拍，4 beats per bar
- 30-45s 目标时长
- Seedream 生图 + Kling 生视频管线
- FFmpeg 拼接 + 剪映后期

### 需要改动

| 改动项 | 现在 | 改为 |
|---|---|---|
| 歌词主题 | 商业名人故事 | 穿搭场景对比 |
| 视觉色调 | 暗金 | 明亮时尚 |
| Seedream prompt | 杨梦沉思/权威 | 杨梦穿不同风格服装全身照 |
| 文字卡 | 金色调铁律 | 杂志排版风穿搭对比 |
| CTA | "评论区聊聊" | "你选 A 还是 B" |

### 新增

- 新 config 模板：`sings-outfit-template.json`
- 每集生成至少 2 套穿搭的杨梦图片
- 剪映后期新增左右分屏/快速 A/B 切换编辑步骤

## 决策记录

1. 抖音专做 Medvi，小红书专做 Sings -- 避免单账号 AB 测试稀释算法标签
2. Sings 内容从商业转向穿搭 -- 匹配小红书用户画像（年轻女性，关注变美）
3. 杨梦多面体定位 -- 抖音深度思考，小红书有品味，同一 IP 两个侧重点
4. 场景对比型内容 -- 代入感强，互动门槛低（投票 A/B），适合冷启动

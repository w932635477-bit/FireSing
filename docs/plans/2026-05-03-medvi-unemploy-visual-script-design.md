## 1. 画面格式：故事驱动 + 蒙太奇点缀

不是纯蒙太奇（corecore），也不是纯叙事。两者结合：

- **故事线提供框架**：每个碎片围绕一个具体人的经历展开
- **蒙太奇碎片只用在情绪高潮**：降低制作难度，3-4个碎片就够
- **UI截图提供真实感锚点**：钉钉/Boss直聘/微信画面每个失业者都见过
- **符合"故事+方法型"方向**：不只共情，还给"明天能做什么"

## 2. 分镜模板（60-75秒标准结构）

| 段落 | 时长 | 画面类型 | 画面内容 | 声音 |
|------|------|---------|---------|------|
| 片头 | 0-1.5s | 统一片头 | 系列logo + slogan | 片头音效 |
| S01 钩子 | 1.5-6s | UI截图 | Boss直聘/招聘网站搜索结果页 | Charon男声开场 |
| S02 设定 | 6-14s | 氛围空镜×2 | 场景建立 + 日常生活碎片 | 背景交代 |
| S03 蒙太奇 | 14-23s | 快切×4 | UI截图×3 + 空镜×1，0.5-2s/张 | 焦虑升级旁白 |
| S04 转折 | 23-33s | 空镜+UI | 暖色空镜先出现，UI截图作为"证据"最后亮出 | 转折旁白 |
| S05 行动 | 33-48s | 空镜+文字卡片 | 具体行动步骤 + 数字证据卡片 | 行动建议旁白 |
| S06 CTA | 48-60s | 空镜+文字卡片 | 金句卡片 + 开放式问题 | CTA旁白 |

### 节奏设计

- **快**（S01-S03）：截图快速闪切，信息轰炸建立冲击，蒙太奇碎片制造窒息感
- **慢**（S04）：放慢，暖色空镜先出现，转折才有分量
- **中速**（S05）：节奏稳定，传递"能做什么"
- **慢**（S06）：收尾呼吸感，开放式问题引导评论

## 3. 素材来源方案

### 3.1 三级素材分类

| 级别 | 来源 | 内容 | 信任风险 |
|------|------|------|---------|
| **A类：信息载体** | Playwright HTML渲染 | 招聘界面、聊天记录、数据面板 | 零风险 |
| **B类：氛围空镜** | Unsplash下载（优先）+ Seedream（兜底） | 无人空镜、物件特写、光影 | 低风险 |
| **C类：禁止** | 任何来源 | AI生成的截图/UI/人脸 | 高风险，禁止使用 |

### 3.2 A类：Playwright UI截图

沿用 `2026-04-28-medvi-unemployment-visual-design.md` §3 的设计：

- 6个HTML模板（tpl-boss-search / tpl-dingtalk-leave / tpl-resume-stats / tpl-wechat-reject / tpl-wechat-positive / tpl-douyin-comment）
- 数据通过JSON注入
- 截图尺寸1080×1920，PNG静态图，不做Kling转视频
- 名字全部打码或化名

### 3.3 B类：氛围空镜 — Unsplash优先

**工作流：**

1. 根据脚本空镜清单，整理搜索关键词（英文）
2. 调用 Unsplash API 搜索 + 下载
3. 优先选竖版(9:16)或可裁剪的横版照片
4. 筛选标准：无人脸、无文字、自然光线、非摆拍感
5. 下载到 `docs/content/assets/unsplash/{video_id}/` 目录

**Unsplash搜不到的场景（如"凌晨2点中国建材仓库"）** 才用Seedream兜底，遵循visual-design.md的6条铁律。

### 3.4 API Key存储

```
# docs/content/.env（已gitignore）
export UNSPLASH_ACCESS_KEY="..."
export UNSPLASH_SECRET_KEY="..."
```

## 5. 分镜方法：情绪温度 + 节奏表

> 来源：McKee 三幕结构 + Wind Comic 情绪温度系统 + Murch 眨眼规则

### 5.1 情绪温度映射（-10 到 +10）

每个段落有温度值和变化方向，指导画面选择和切镜节奏：

| 段落 | 时长 | 温度 | 变化 | 节奏 |
|------|------|------|------|------|
| S01 钩子 | 0-8s | -3→-7 | 下沉 | 4-6s/镜头，慢 |
| S02 转折 | 8-30s | -7→0 | 爬升 | 3-4s/镜头，中速 |
| S03 蒙太奇 | 30-45s | 0→+5 | 爆发 | 2-3s/镜头，快切 |
| S04 行动 | 45-60s | +5→+3 | 稳定 | 4-5s/镜头，放缓 |
| S05 转折点 | 60-68s | +3→+8 | 高潮 | 3-4s/镜头，节奏感 |
| S06 CTA | 68-75s | +8→+6 | 回落 | 5-6s/镜头，慢 |

### 5.2 切镜规则

**蒙太奇段（S03）专用：**

- 2-3秒一个镜头，最多8个快切
- 每个切点对齐配音的**意群边界**（逗号、句号、自然停顿）
- Murch 眨眼规则：在观众"心理眨眼"的瞬间切镜——一句话说完、一个情绪转折处
- 15-20秒快切后必须有2秒**静息节拍**（rest beat），用一个固定镜头+环境音

**故事段（S01/S02/S04/S06）：**

- 4-6秒一个镜头
- 镜头运动优先：缓慢推（zoom in）> 固定 > 拉出
- 情绪下沉时镜头后退，情绪上升时镜头推进

### 5.3 分镜-配音协同原则

1. 先定配音节奏（语速+停顿），从停顿位置推导切镜点
2. 情绪停（0.5-1s）= 切镜点，观众心理眨眼的瞬间
3. 留白（1-2s）= 转场点，换一个视觉空间
4. 蒙太奇段配音加速 → 镜头也加速，但不超 2s/镜头
5. CTA 段配音放慢 → 镜头也放慢，让观众从情绪回到理性

## 6. 配音方法：语速节拍 + 停顿设计

### 6.1 引擎

- **gemini-2.5-flash-preview-tts**（即 gemini-3.1-flash-tts）
- 声音：Charon（男声）
- 视角：第一人称自述
- 整体风格：低沉克制，像跟老朋友说话

### 6.2 语速基准

- 全片 125-150 WPM（中文约 3.5-4 字/秒）
- S01 偏慢（3 字/秒），S03 偏快（4.5 字/秒），S04 回落到 3.5 字/秒
- 语速变化本身就是情绪信号，不全程匀速

### 6.3 三种停顿类型

| 类型 | 时长 | 用途 | 张伟示例 |
|------|------|------|----------|
| 微停 | 0.3-0.5s | 断句、换气 | "12年（微停）建材行业" |
| 情绪停 | 0.5-1s | 关键信息前 | "（0.8s停顿）一张废纸" |
| 留白 | 1-2s | 情绪消化、转场 | "我给你发个红包吧（1.5s留白）" |

### 6.4 停顿布局规则

1. **情绪下沉点**：重话之前停 0.8-1s（"一张废纸"前）
2. **情绪翻转点**：翻转后停 1-1.5s（"红包"后、"后悔"后）
3. **数据/证据**：数字前微停 0.3s（"4000多"前）
4. **CTA 转向**：CTA 第一句前停 1s，让情绪着陆
5. **蒙太奇段**：句间不停，连续推进制造紧迫感

### 6.5 各段语调规格

| 段落 | 语速 | 声调 | 关键停顿 |
|------|------|------|----------|
| S01 钩子 | 慢 3字/s | 低沉克制 | "一张废纸"前 0.8s |
| S02 转折 | 中快 4字/s | 略带好奇→意外 | "红包吧"后 1.5s，"后悔"后 1s |
| S03 蒙太奇 | 快 4.5字/s | 踏实有节奏 | 句间不停，数字前 0.3s |
| S04 行动 | 中 3.5字/s | 真诚转向 | "到底值多少钱"前 0.8s |
| S05 转折点 | 中 3.5字/s | 自信 | "不是废纸"后 0.5s |
| S06 CTA | 自然 3.5字/s | 放松 | "你做什么行业"后 0.3s |


## 每日内容制作 SOP（7 步流程）

每条视频控制在 **90 分钟**内完成。目标不是完美，是发出去。

### Step 1：选题（10 分钟）

**选题来源**（按优先级）：
1. 从 `docs/plans/2026-04-15-medvi-acquisition-analysis.md` 提取核心观点
2. 从评论区/私信中找高频问题
3. 从竞品热门视频中找灵感（不是抄袭，是"我可以讲得更深"）

**选题公式**（选一个）：
- "我拆解了 [公司/方法]，发现了 [反常识结论]"
- "用 AI 做 [具体任务]，完整流程公开"
- "[工具A] vs [工具B]，实测对比，结论是..."
- "我帮一个 [行业] 客户用 AI 做了 [结果]，这是过程"
- "做 [方向] X 天后的真实数据：[数字]"

### Step 2：写脚本（15 分钟）

**脚本模板（30-60 秒视频）**：

```
【钩子】3-5秒 — 抓住注意力
  "一个 $40 亿的公司，只花了 $103/月做获客"
  "我用 AI 帮一个商家做了 10 条视频，这是结果"
  "为什么你用 AI 做的视频没人看？"

【主体】20-40秒 — 一个核心观点
  只讲一个点。不讲三个。
  用具体数字。不用"很多"、"一些"。
  用你的研究来源背书。

【转化】5-10秒 — 引导互动
  "想知道完整流程？关注我，下期录屏实操"
  "私信'AI获客'领工具清单"
  "你的行业适合用 AI 获客吗？评论区告诉我"
```

**写脚本流程**：
1. 用 ChatGPT 生成初稿：`"帮我写一个30秒抖音短视频脚本，主题是[X]，钩子要强，数据要具体"`
2. 自己改 3 遍：删掉废话，加具体数字，改成口语
3. 大声读一遍。读着不顺的地方就是需要改的地方

### Step 3：录画面（20 分钟）

**画面形式**（选一个，不纠结）：

| 形式 | 适合内容类型 | 制作方式 |
|------|------------|---------|
| 录屏 + 旁白 | 工具实操、流程演示 | QuickTime 录屏 + 旁白 |
| 素材拼接 + 旁白 | 数据展示、方法拆解 | 免费素材（Pexels/Pixabay）+ 旁白 |
| 真人出镜 | 个人观点、避坑指南 | 手机前置摄像头 |
| 图文卡 + 旁白 | 对比、清单、工具推荐 | Canva 做图 + 剪映拼接 |

**前 4 周建议**：以录屏 + 旁白和素材拼接为主。制作快，效果好。

### Step 4：配音（10 分钟）

**前 4 周用自己的声音**。原因：
- AI 配音还需要调参数，耽误时间
- 真人声音建立信任感
- 后续可以验证 AI 配音是否可行

**录音要求**：
- 手机自带录音机就可以
- 找一个安静的房间
- 按脚本分段录（每段 10-15 秒），不满意就重录那段
- 不需要播音腔，自然说话就行

### Step 5：剪辑（20 分钟）

**剪映操作流程**：

1. 导入画面素材
2. 导入配音音频
3. 根据配音切分画面，对齐节奏
4. 加字幕（剪映自动识别，手动校对关键数字）
5. 加 BGM（剪映自带免费音乐，音量调到 10-15%）
6. 加转场（简单的淡入淡出就够了，不要花哨的）

**不要做的事**：
- 不要花 2 小时调色
- 不要加大量特效
- 不要追求电影质感
- 不要反复修改第 5 遍

### Step 6：发布（5 分钟）

**发布清单**：
- [ ] 视频时长 30-60 秒
- [ ] 有字幕
- [ ] 有 BGM（音量低）
- [ ] 封面清晰（选择最有冲击力的一帧）

**标题公式**：
- 数字 + 反常识 = "花了 $103/月获客，这个公司估值 $40 亿"
- 问题 + 答案 = "AI 做的视频为什么没人看？因为你犯了这个错"
- 对比 + 结论 = "国内 AI 工具 vs 海外 AI 工具，差距有多大？"

**标签**（选 3-5 个）：
`#AI获客 #AI营销 #AI视频 #人工智能 #内容营销 #创业`

**发布时间**：周二到周日，每天 1 条。建议时间 12:00 或 18:00（午休和下班高峰）。

### Step 7：互动 + 记录（10 分钟）

**发布后 30 分钟内**：
- 回复每条评论（哪怕只是"谢谢"）
- 点赞每条评论
- 如果有人问问题，认真回答（这可能是未来的客户）

**记录数据**（填入追踪表，见下方）：
- 播放量
- 点赞数
- 评论数
- 新增私信
- 值得注意的评论内容

## 获客漏斗执行流程

### 流程图

```
[抖音/小红书内容]
       ↓（主页简介 + 视频内引导）
["私信'AI获客'领工具清单"]
       ↓
[用户私信]
       ↓
回复："加我微信 [微信号]，我把 PDF 发给你"
       ↓
[微信添加]
       ↓
发送 PDF + 欢迎语
       ↓
判断需求类型：
├─ "我做不好内容" → 推代运营
├─ "我需要 AI 工具" → 推 Agent 搭建
├─ "我就想学学" → 维护关系，后续推知识产品
└─ "没什么特别需求" → 标记，不主动打扰
```

### 私域聊天 SOP

**第 1 条消息**（发送 PDF 后）：
```
这是你需要的 AI 获客工具清单。
我正在用 AI 工具帮企业做获客内容，也会在抖音分享实测数据。
有什么想了解的随时问我。
```

**判断需求**：看对方回复什么。

| 对方说的话 | 需求判断 | 下一步 |
|-----------|---------|--------|
| "我们店也想做抖音" | 代运营需求 | 问具体行业和现状 |
| "我需要 AI 客服" | Agent 需求 | 问具体场景 |
| "这个怎么做的" | 学习需求 | 分享更多内容，维护关系 |
| "谢谢" 后沉默 | 暂无需求 | 不打扰，朋友圈保持可见 |

**代运营报价话术**（等对方表达痛点后用）：

```
我可以帮你试试。方案是这样：
- 用 AI 工具帮你每周做 10 条抖音内容
- 包含：选题 + 脚本 + 视频制作 + 发布
- 你只需要确认内容和回复评论
- 首月 [价格] 元，看看效果
你觉得怎么样？
```

**Agent 搭建报价话术**：

## 服务交付 SOP

### 代运营交付流程（单个客户）

**接收客户后**：

1. **了解客户**（30 分钟）：
   - 行业、产品、目标客户
   - 现有抖音/小红书账号情况
   - 竞品分析（搜 3 个同行账号，看什么内容火）

2. **制定内容计划**（30 分钟）：
   - 确定 4 个内容方向
   - 每个方向 2-3 条视频的选题
   - 确定发布节奏（每周几条）

3. **批量制作**（每周 2-3 小时/客户）：
   - 周一：写本周所有脚本（ChatGPT 辅助）
   - 周二-周四：制作视频（按 SOP 7 步流程）
   - 周五：排期发布

4. **周报**（15 分钟）：
   - 发给客户本周数据
   - 下周内容方向建议

### Agent 搭建交付流程（单个客户）

1. **需求确认**（1 小时）：
   - 客户要解决什么问题？
   - 涉及哪些数据/系统？
   - 预期效果是什么？

2. **搭建**（1-3 天）：
   - 用 Coze/Dify 搭建 Agent
   - 接入客户数据/知识库
   - 内部测试

3. **交付**（1 小时）：
   - 演示给客户看
   - 教客户怎么用
   - 收集反馈

4. **维护**（每月 1-2 小时）：
   - 监控运行情况
   - 根据反馈调整
   - 收维护费

## 4 周后决策表

### 数据决策矩阵

| 观察到的数据 | 判断 | 行动 |
|------------|------|------|
| 粉丝 > 500，企业主 > 10，有人问"帮我做" | H1 验证（代运营/Agent 需求成立） | 开始接客户，扩大内容产出 |
| 粉丝 > 500，但主要是个人，问"怎么学" | H2 验证（知识需求成立） | 制作 PDF 手册，定价 99 元测试 |
| 发现评论区反复出现同一需求 | H3 验证（发现新需求） | 围绕新需求设计产品 |
| 粉丝 < 100，私信 < 5 | 全部失败 | 停止。复盘：内容方向错？平台错？定位错？ |
| 粉丝 > 500，但没人问付费相关 | 有流量无需求 | 调整内容方向，从"教方法"转向"展示结果" |

### 不延长的硬约束

4 周到了就做决策。三种选择：
1. **继续**：数据达到"通过"标准，继续当前方向
2. **转向**：数据部分通过，调整方向（换内容主题/换平台/换变现方式）
3. **停止**：数据明确失败，停止投入，复盘原因

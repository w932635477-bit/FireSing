## 背景

基于 Medvi 全链路工作流拆解（见 2026-04-15-medvi-acquisition-analysis.md 第十章），
以及 AI 视频风格化方向的否决分析（见 2026-04-16-ai-video-stylizer-design.md），
确定新方向：**不做工具，做服务。用海外 AI 工具链为中国商家提供高质量内容生产。**

### 方向否决记录

AI 视频批量风格化方向已否决，原因：
1. 窗口期仅 6-12 周（剪映可 2 周内复制）
2. 本质是 FFmpeg 滤镜功能，无护城河
3. 2 个月跑道 + SaaS 开发周期不匹配
4. 32k 赞是兴趣信号，非付费验证

详见 MEMORY.md 中 [方向否决 2026-04-16] 条目。

## 一、定位

**用海外 AI 工具链为中国商家批量生产高质量营销内容。**

不是卖工具，是卖用工具做出来的成品。护城河不是技术，是工具链信息差 + 工作流经验。

### 为什么这个方向可行

| 维度 | 评估 |
|------|------|
| 变现速度 | 1-2 周内可接第一单（不需要做产品） |
| 窗口期 | 12+ 个月（海外工具质量优势短期内不会消失） |
| 护城河 | 海外工具链 + 工作流经验 + 自动化能力（国内大多数商家不具备） |
| 启动资金 | ~750 元/月（工具订阅费） |
| 风险 | 极低（卖不出去只是损失工具订阅费） |

## 三、工具链

### 核心工具（海外）

| 步骤 | 工具 | 用途 | 月费 |
|------|------|------|------|
| 脚本/文案 | ChatGPT / Claude | 生成视频脚本、产品文案、社交媒体帖子 | $20-25 |
| 图片生成 | Midjourney | 产品主图、场景图、社交媒体素材 | $30 |
| 视频生成 | Runway | 从静态图生成动态短视频 | $15 |
| 配音 | ElevenLabs | 高质量 AI 语音旁白（中英文） | $5 |
| 图文制作 | Canva Pro | 批量生成不同尺寸的营销图文 | $13 |
| 工作流自动化 | 自定义 Python 脚本 | 批量处理、参数化生成、自动化管线 | 自建 |
| **月总费用** | | | **~$103（约 750 元）** |

### 工具链选择说明

经多次实测验证，海外 AI 生成工具在输出质量上显著优于国内工具：
- Midjourney >> 即梦 AI / 通义万相（图片质量、细节、风格多样性）
- Runway >> 可灵 / 即梦视频版（视频连贯性、画质、时长）
- ElevenLabs >> 剪映 AI 配音（语音自然度、情感、多语言）

国内工具仅用于分发环节（巨量引擎、腾讯广告等）和后期处理（剪映加字幕）。

## 四、工作流

基于 Medvi 工作流拆解，适配中国市场合法合规版本。

### 标准工作流（每批内容）

```
Step 1: 需求分析（与客户沟通或自行选题）
  确定产品、目标平台、内容类型、数量
  ↓

Step 2: 脚本/文案批量生成（ChatGPT/Claude）
  输入：产品信息 + 目标受众 + 内容类型
  输出：N 条不同角度的脚本/文案
  自动化：Python 脚本批量调用 API
  ↓

Step 3: 图片素材生成（Midjourney）
  输入：脚本 + 产品参考图 + 风格指令
  输出：产品主图、场景图、社交媒体素材
  批量：不同参数变体确保视觉差异化
  ↓

Step 4: 视频制作（Runway + 剪映后期）
  输入：Midjourney 图片 + 脚本
  输出：5-15 秒短视频
  Runway: 图片生成动态视频
  剪映: 加字幕、加 AI 标注、适配平台尺寸
  ↓

Step 5: 配音（ElevenLabs）
  输入：脚本文字
  输出：高质量 AI 旁白
  不同内容用不同声音预设
  ↓

Step 6: 组装 + 交付
  视频素材 + 配音 + 字幕 → 成品
  按客户需求打包交付
```

### 自动化能力

用 Python 脚本实现以下自动化：
- 批量调用 ChatGPT API 生成脚本变体
- Midjourney 参数随机化（每张图不同的种子、风格参数）
- ElevenLabs 批量生成不同声音的配音
- FFmpeg 自动合成视频 + 音频 + 字幕
- 批量导出不同平台尺寸（9:16 抖音、3:4 小红书、1:1 电商）

## 六、获客路径

### 第一阶段：作品获客（第 1-3 周）

1. 制作第一批样品并发布到抖音/小红书/TikTok
2. 所有作品标注"接单/合作私信"
3. 目标：获得 10+ 次合作咨询

### 第二阶段：社群获客（第 2-4 周，并行）

1. 加入电商卖家、矩阵号运营、出海企业等微信群/QQ群
2. 不发广告，分享作品并说"这个是我用 AI 做的，需要合作私聊"
3. 目标：获得 5+ 次直接咨询

### 第三阶段：口碑获客（第 4 周起）

1. 每个满意客户索要推荐
2. 在作品中展示客户案例（经许可）
3. 逐步提高定价（从低价启动到正常定价）

## 九、风险与应对

| 风险 | 严重程度 | 应对 |
|------|---------|------|
| 找不到客户 | 高 | 多渠道并行获客，低价启动 |
| 客户觉得 AI 内容不值钱 | 中 | 强调"海外工具品质差异"，用作品说话 |
| 客户要求反复修改 | 中 | 合同约定修改次数，超出加价 |
| 海外工具被墙/支付困难 | 中 | 提前准备 VPN 和海外支付方式 |
| AI 标注法规 | 低 | 所有交付内容添加 AI 标注，合规经营 |
| 国内工具追上质量 | 低（12+ 个月窗口） | 窗口期内建立客户基础和口碑，转向更高附加值服务 |

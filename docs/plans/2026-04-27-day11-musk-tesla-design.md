## 1. 选题

**主题：** 黄金时代的终结 — 马斯克停产 Model S/X，转投机器人

**为什么选这个：**
- 实时热点：Model X "last chance version officially gone"（Teslarati，2026-04-26），Optimus V3 专利曝光（2026-04-25），Cybercab 量产加速
- Day8 讲"不合群"，Day11 讲"敢砍过去"——同一人物不同角度，不重复
- "造车只是热身"极具传播力——把万亿市值重构为"热身"，反差感强
- 外国人物（马斯克），无名誉权风险（Day10 任正非被投诉后吸取的教训）

**名人原话锚定（两处）：**
1. "我宁愿乐观地犯错，也不愿悲观地正确" — widely attributed to Musk
2. "当一件事足够重要，即使胜算不大，你也该去做" — Musk 2013 60 Minutes interview

> 注：原话 1 需在发布前确认精确出处。如无法确认，替换为行为描述。

## 2. 结构与文案

4 段自由叙事（非铁律三段式），shock→tension→reversal→warm+CTA。

总时长 ~47s，总字数 ~202 字。

### S01 shock (11s)

**Voiceover:**
Model X 的最后一辆车下线了。没有仪式。没有掌声。就像关上一扇门，连灯都没开。马斯克什么也没说。他的沉默，比任何话都响。

**Subtitle:** 没有仪式 没有掌声

**情绪:** 具体事件开场(最后一辆车下线) → 短句连击(没有仪式/没有掌声) → 意象(关上门连灯都没开) → 沉默收束

**视觉:** 杨梦 shock 表情，冷光，黑暗背景。
**故事图:** S01-01 Model X 最后一辆车在空旷工厂中 / S01-02 手机屏幕上的停产新闻推送

---

### S02 tension (12s)

**Voiceover:**
Model S 也只剩最后一批。外面炸了。销量在跌。所有人都在喊他完了。马斯克说过："我宁愿乐观地犯错，也不愿悲观地正确。" 他什么也没解释。

**Subtitle:** 所有人都在喊他完了

**情绪:** 事实叠加(只剩最后一批) → 外界反应(炸了/销量跌/喊完了) → 名人原话反击 → 沉默

**视觉:** 杨梦 tension 表情，暖光压迫。
**故事图:** S02-01 空旷的 Tesla 服务中心 / S02-02 新闻标题堆叠的混乱画面

---

### S03 reversal (10s)

**Voiceover:**
Optimus 机器人的手，比人手还灵活。Cybercab 出租车量产在加速。从改变汽车，到改变一切。造车，只是热身。

**Subtitle:** 造车 只是热身

**情绪:** Optimus 事实(机器手) → Cybercab 事实(量产加速) → **签名时刻**：从改变汽车到改变一切 → "造车只是热身"终极重构

**视觉:** 杨梦 reversal 表情，冷暖交替光。
**故事图:** S03-01 Optimus 机器人的手部特写 / S03-02 Cybercab 出租车在路上

---

### S04 warm + CTA (12s)

**Voiceover:**
马斯克说过："当一件事足够重要，即使胜算不大，你也该去做。" 他砍掉的不是车，是过去的自己。你攥着不放的，是热爱，还是习惯？评论区聊聊。

**Subtitle:** 你攥着不放的 是热爱还是习惯

**情绪:** 名人原话(行动勇气) → 名人→观众过渡(砍掉的是过去的自己) → 观众代入(热爱还是习惯) → CTA

**视觉:** 杨梦 warm 表情，暖光。
**故事图:** 无（直接 CTA 互动）

## 3. 配音设计

**引擎:** Gemini TTS (Aoede voice) — 强制女声 mandate
**风格:** 女声，全部使用 Aoede 声音保持一致性

**Director's Notes:**

S01: "Model X 的最后一辆车下线了"用平缓近乎叙述，"没有仪式"稍顿，"没有掌声"再顿，"就像关上一扇门"放慢，"连灯都没开"压低带失落，"马斯克什么也没说"轻描淡写，"他的沉默，比任何话都响"加重"沉默"二字后停顿。

S02: "Model S 也只剩最后一批"中速，"外面炸了"稍快，"销量在跌"加重，"所有人都在喊他完了"语速加快带焦虑感，名人原话"我宁愿乐观地犯错"要稳重有力，"也不愿悲观地正确"上扬带自信，"他什么也没解释"回到平静。

S03: "Optimus 机器人的手"中速清晰，"比人手还灵活"微微惊讶，"Cybercab 出租车量产在加速"节奏紧凑，"从改变汽车"放慢，"到改变一切"每个字清晰有力停顿，"造车"短暂停顿，"只是热身"轻描淡写但分量极重。

S04: 名人原话"当一件事足够重要"温暖有力，"你也该去做"鼓励语气，"他砍掉的不是车"转为叙事，"是过去的自己"温暖带理解，"你攥着不放的"转为对观众说话，"是热爱"停顿，"还是习惯"真诚发问，CTA 自然友好。

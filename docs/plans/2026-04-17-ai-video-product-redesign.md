## 一、产品重新定位

### 从"AI 代运营服务商"升级为"AI 视频获客方法论布道者"

原有定位的问题：代运营是苦力活，客单价低（500-2000/月），规模化靠堆人力。

新定位：

```
你不是在帮人做视频，你是在教一套"用 AI 替代整个营销团队"的方法论。
```

### 产品矩阵（三层）

| 层级 | 产品 | 定价 | 交付物 | 目标 |
|------|------|------|--------|------|
| **引流层** | 短视频内容 | 免费 | 抖音/小红书日更 | 建立专业权威 + 获取线索 |
| **入门层** | AI 获客工具包 + 方法论 | 99-299 元 | PDF 手册 + 视频教程 + Prompt 模板 | 筛选付费意愿用户 |
| **核心层** | AI 视频获客训练营 | 1999-4999 元 | 4 周陪跑 + 1v1 答疑 + 工具链搭建 | 高客单价收入 |
| **增值层** | 定制化 AI Agent 搭建 | 5000-20000 元 | 企业级自动化获客系统 | 企业客户 |

**关键转变：从卖"我做给你"变成卖"我教你做"。**

理由：
- Medvi 证明了这个方法有效 → 你有现成的案例背书
- 教别人做，边际成本为零，可以无限复制
- "一个人用 AI 替代整个营销团队"这个概念本身就有传播力
- 客户学会后还想让你帮忙 → 自然过渡到高端服务

### 核心卖点（一句话）

> "一个人 + AI 工具 = 替代一个 10 人营销团队，成本降 90%，产出提 10 倍。"
>
> 证据：Medvi 用 2 个人 + $103/月工具费，做了同行 2400 人 + 数亿预算才做到的事。

## 二、视频内容生产体系（学习 Medvi）

### Medvi 视频的 4 种格式（从他们的视频中学习）

**格式 1：数据震撼型（40%）**
```
结构：抛出惊人数字 → 解释背景 → 给出方法 → 行动号召
视觉：大号数字字幕 + 暗色背景 + 电影感素材
时长：30-45 秒
示例："2个人，$103月费，$4亿营收。这是怎么做到的？"
```

**格式 2：对比冲击型（25%）**
```
结构：传统方式（贵/慢/差）→ AI 方式（便宜/快/好）→ 数据证明
视觉：左右分屏对比、价格对比表、效率对比图
时长：30-60 秒
示例："传统代运营：5人团队，月费2万，日产3条内容。AI方式：1人，月费750，日产30条。"
```

**格式 3：实操演示型（20%）**
```
结构：展示问题 → 录屏演示 AI 工具操作 → 展示成品 → 邀请尝试
视觉：屏幕录制 + 真人画外音 + 关键步骤标注
时长：45-90 秒
示例："从0到1用AI做一条获客视频，全过程只用了15分钟"
```

**格式 4：方法论拆解型（15%）**
```
结构：提出一个行业痛点 → 给出 AI 解决框架 → 列出具体步骤
视觉：流程图 + 工具截图 + 关键指标
时长：45-60 秒
示例："AI获客5步法：脚本→素材→配音→合成→分发。每一步都自动化。"
```

### 脚本写作框架（Prompt 模板）

#### 模板 1：数据震撼型脚本

```
你是一个抖音短视频脚本专家。请按以下结构写一个30-45秒的短视频脚本：

主题：[具体主题，如"2个人用AI做了4亿营收"]

结构要求：
1. 钩子（前3秒）：用一个震撼的数据或反常识的陈述开场
2. 展开（10-20秒）：用2-3个关键数据点展开，每个数据点配一个画面建议
3. 方法（10-15秒）：简要说明核心方法，不讲透，留悬念
4. CTA（最后3-5秒）：引导关注或私信

格式要求：
- 每个镜头单独一段，标注：[画面] [字幕] [旁白]
- 旁白用口语化表达，短句为主，每句不超过15个字
- 字幕突出关键数字，用大号字体
- 总字数控制在120-150字（30-45秒语速）

禁止：
- 不要用"今天就教大家"之类的套话
- 不要堆砌形容词
- 不要超过60秒
```

#### 模板 2：对比冲击型脚本

```
写一个30-45秒的对比型短视频脚本：

对比主题：[传统方式 vs AI方式，具体到某个场景]

格式：
1. 开场（3秒）：抛出对比场景
2. 传统方式（10秒）：列出3个痛点（贵/慢/难），每个配一个数据
3. AI方式（10秒）：对应3个优势（便宜/快/简单），配数据
4. 证明（5秒）：引用一个真实案例（Medvi、或其他）
5. CTA（3秒）：引导行动

画面要求：
- 传统方式用灰色/暗色调
- AI方式用明亮/科技感色调
- 数据对比用左右分屏或上下翻页

语气：冷静陈述事实，不煽情。让数据说话。
```

#### 模板 3：实操演示型脚本

```
写一个45-90秒的录屏实操脚本：

演示内容：[具体操作，如"用Runway从一张图片生成一条获客视频"]

结构：
1. 钩子（5秒）：展示最终成品效果，引起好奇
2. 准备（5-10秒）：展示需要什么工具和素材
3. 操作步骤（30-60秒）：3-5个关键步骤，每步标注：
   - [录屏画面] 要录制什么
   - [操作说明] 怎么操作
   - [字幕标注] 画面上要标注什么关键信息
4. 成果展示（5-10秒）：对比成品和预期效果
5. CTA（5秒）：引导关注获取完整工具清单

要求：
- 步骤要具体到"点击这里"、"输入这个参数"
- 每个步骤不超过15秒，超过就拆分
- 突出"自动化"、"批量"等关键词
```

## 三、视频编辑标准

### Medvi 视频的核心特征（需复刻）

| 特征 | Medvi 做法 | 我们的做法 |
|------|-----------|-----------|
| 格式 | 图文幻灯片 + AI 旁白 | 静态素材 → Runway 动态化 + AI 旁白 |
| 时长 | 15-60 秒 | 30-60 秒（抖音主战场） |
| 字幕 | 大号字幕叠加 | 大号 + 关键数据用金色高亮 |
| 画面 | 暗色背景、电影感 | 统一暗色调 + 胶片颗粒 + 暗角 |
| 音频 | AI 配音 + BGM | MiniMax 配音 + 低音量 BGM |
| 节奏 | 快速切换、信息密集 | 每 3-5 秒一个信息点 |
| CTA | "点击链接" | "私信 AI获客" |

### 后期处理参数（去 AI 塑料味）

```
# FFmpeg 后期处理
film grain:    noise=c0s=12:c0f=t+u     （轻柔颗粒感）
contrast:      eq=contrast=1.08          （微增对比度）
saturation:    eq=saturation=0.92        （微降饱和度）
vignette:      angle=0.3                 （轻微暗角）
brightness:    eq=brightness=0.01        （微提亮度）

# 剪映精修
BGM 音量:      8-12%（不能盖过旁白）
字幕样式:      白色/金色，黑底描边，字号 48-60
转场:          硬切为主，偶尔用 0.3s 淡入淡出
速度:          钩子部分 1.2x，展开部分 1.0x，CTA 部分 0.9x
```

## 四、信任构建策略

### 最大的挑战：为什么用户要信你？

Medvi 卖的是减肥药，产品本身就是结果（体重下降）。你卖的是方法论，用户看不到即时结果。

**解决方案：4 层信任体系**

### 第 1 层：数据可信度（内容层）

- 每条视频引用可验证的数据源
- "根据 NYT 2026年4月报道…""Business Insider 调查发现…"
- 不编造数据，不夸大效果
- 展示你自己的真实测试过程和原始数据

**关键话术：**
- "NYT 报道了一个 2 个人的公司…"
- "这不是我说的，是 Business Insider 调查发现的…"
- "我花 2 天拆解了他们的完整工作流，这是真实数据…"

### 第 2 层：能力证明（展示层）

- 你自己的视频就是你能力的证明
- "这条视频就是用 AI 做的，从脚本到成品只用了 45 分钟"
- 每条视频展示部分制作过程（工具截图、参数设置）
- 定期发布"我用 AI 做了 X 条视频"的实验报告

**关键话术：**
- "你正在看的这条视频，就是用我说的方法做的"
- "我用同样的方法，一周做了 20 条内容"
- "这是我的工具链截图，总共月费 750 元"

### 第 3 层：透明度（差异层）

- 公开你的工具、成本、流程
- 不装成"大师"，而是"一个正在验证方法的研究者"
- 发布失败案例和踩坑经验
- 公开你的数据追踪表

**关键话术：**
- "我从 0 开始测试，这是第 X 天的真实数据"
- "这个方法也有不适用的时候，比如…"
- "我踩过的 5 个坑，你也可能遇到"

### 第 4 层：社会证明（积累层）

- 前期：引用 Medvi、行业报告作为第三方证明
- 中期：收集用户反馈和成功案例
- 后期：学员成果展示（"用我的方法，X 周后他做到了…"）

## 六、从 Medvi 视频中学习的方法论

### 分析 Medvi 视频的 5 个维度

**1. 钩子模式（前 3 秒决定生死）**

Medvi 的高播放量视频钩子特征：
- 反常识数字："你可能不需要运动就能瘦"
- 身份认同："如果你BMI超过30，这个视频是给你的"
- 恐惧触发："减肥行业不想让你知道的真相"
- 好奇心缺口："这个医生说的方法，99%的人不知道"

**可复用的钩子模板：**
```
"X个人，用了X个月，做到X营收。怎么做到的？"
"行业里有个秘密，[揭示反常识事实]"
"我花了X天拆解一个[形容词]案例，发现了[X件事]"
"你的同行在用[方法]，但他们不会告诉你[X]"
```

**2. 信息密度（每 3 秒一个刺激点）**

Medvi 视频的节奏：
- 0-3s：钩子（数字/反常识）
- 3-8s：背景（一句话说明上下文）
- 8-15s：核心数据（2-3 个关键数字）
- 15-25s：方法暗示（"秘密是…"但不说透）
- 25-35s：行动号召（"点击链接"/"私信我"）

**3. 视觉策略（信息在字幕，情感在画面）**

Medvi 的画面只是氛围营造工具：
- 暗色背景 → 专业、严肃、可信
- 缓慢运动 → 不分散注意力
- 人物特写 → 情感连接（即使是假的）
- 文字叠加 → 信息传递的主要载体

**4. 声音设计（旁白是主角）**

- 清晰的 AI 配音，不带口音
- 语速适中，关键信息有停顿
- BGM 几乎听不到，纯背景氛围
- 没有多余的音效

**5. CTA 设计（低摩擦行动引导）**

Medvi 的 CTA 演进：
- 早期："点击链接免费咨询"（直接跳转）
- 中期："DM 我了解更多"（平台内私信）
- 后期："看我个人简介"（更低摩擦）

**我们的 CTA 策略：**
- 抖音："关注后私信'AI获客'，我发你完整工具清单"
- 小红书："评论区扣1，我发你 AI 获客工具包"
- 朋友圈："加我微信，领 AI 视频制作 SOP"

## 十、与原有计划的关系

| 原计划 | 新方案的变化 |
|--------|------------|
| AI 代运营（500-2000/月） | 保留但降为增值服务，不再主动推 |
| AI Agent 搭建（3000-5000/单） | 保留为高端定制，面向企业客户 |
| 4 周验证 | 不变，严格执行 |
| 免费钩子 PDF | 升级为"AI 获客工具包"，含 Prompt 模板 |
| 自己配音（前4周） | 改为：先用 AI 配音验证内容方向，效果好后再加真人版 |

### 核心转变

```
旧：做内容 → 吸引客户 → 卖服务（代运营/搭建）
新：做内容 → 建立权威 → 卖方法论（工具包/训练营）→ 高端服务跟进
```

理由：服务的本质是卖时间，方法论的本质是卖认知。后者可复制、可规模化、边际成本为零。

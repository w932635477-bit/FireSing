> 状态：已批准

## 1. 核心概念

用"今天你要嫁给我"旋律翻唱，男声扮演"全国挑衅者"，女声扮演"上海反击者"，逐级展示上海吵架的10个段位。每段都是独立争议点，评论区三波人：上海本地人辩护、外地人共鸣挑衅、其他城市来对比。

**目标**：评论区炸裂 → 流量爆发。CTA 触发全国城市参与。

## 2. 段位结构

| 段位 | 主题 | 争议点 | 评论区分歧 |
|------|------|--------|-----------|
| 1-3级 | 嘴巴功夫 | "脑子瓦特了"是骂人还是关心？上海话吵架听不懂 | 上海人：亲昵！外地人：在骂我 |
| 4-6级 | 美食战争 | 生煎vs小笼、上海是美食荒漠、甜咸豆腐脑 | "美食荒漠"引爆最大争议 |
| 7-9级 | 文化鄙视链 | 浦东不算上海、南京路外地人去、咖啡比茶多 | 本地人区域鄙视链公开处刑 |
| 10级 | 终极Boss | 上海话快消失了 | 文化传承争议 |

争议强度递进：轻松搞笑 → 开始上火 → 地域话题 → 文化痛点。

## 3. 歌词

适配"今天你要嫁给我"旋律，14行，约45秒。

```
[Intro - 6秒]
[Male] 你知道上海人吵架分几个段位吗
[Female] 十个段位 外地人扛不过三级

[Verse 1 - 嘴巴功夫 10秒]
[Male] 一级"你脑子瓦特了" 外地人以为在骂人
[Female] 那是关心你懂不懂
[Male] 二级上海话开骂 语速快到像念咒
[Female] 三级弄堂阿姨开嗓 街坊全知道你欠了菜钱

[Chorus - 美食战争 12秒]
[Both] 上海人的嘴 段位一直在升
[Both] 吵着吵着就变成文化课了
[Male] 四级生煎小笼谁正宗 有人说上海是美食荒漠
[Female] 那是他没凌晨四点排过葱油饼的队

[Outro - 终极Boss+CTA 6秒]
[Male] 十级 上海话快没人会说了
[Female] 你们那里吵架什么段位 来评论区比
```

## 4. 歌词设计要点

- 每句都是争议引爆器（语言文化差异、地域偏见、文化传承）
- 冷知识嵌入自然，是吵架中的"反击武器"
- 男声每句在挑衅（代表全国网友刻板印象）
- 女声每句在反击（上海本地视角+冷知识）
- Chorus 两人合唱，自嘲+点题

## 5. 视觉方案

4个固定镜头，每个对应一个段位区间：

| 段落 | 视觉 | 情绪 | Seedream 场景 |
|------|------|------|--------------|
| Intro (S01) | 杨梦在外滩 | 俏皮 | 外滩+浦东天际线 |
| Verse 1 (S02) | 杨梦在弄堂 | 夸张 | 老式石库门弄堂 |
| Chorus (S03) | 杨梦在美食街 | 激动 | 生煎店门口/夜市 |
| Outro (S04) | 杨梦特写对镜头 | 挑衅 | 上海街头特写 |

## 6. 技术规格

- 分辨率：1080x1920，24fps，H.264
- 音乐引擎：Suno Cover（"今天你要嫁给我"原曲+新歌词）
- 图像引擎：Seedream 4.5（1440x2560）
- 视频引擎：Kling 3.0（720x1280→升采样）
- 合成：FFmpeg + 剪映
- 预估成本：$0.50-0.80

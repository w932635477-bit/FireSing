## Problem Statement

中国经济下行，裁员潮持续。数千万职场人面临"保住饭碗"或"找到新饭碗"的压力。他们需要简历优化、面试准备、职业规划，但线下服务贵（单次 500-2000 元），线上信息碎片化。AI 可以把简历优化和面试准备的成本降到接近零，但大多数人不会用 AI 工具。

## Why This Problem (Medvi 方法论匹配度)

Medvi 的核心不是"AI 生成内容"，而是三个要素的组合：
1. **AI 极低成本获客** → 用 AI 批量生产小红书/抖音内容，获客成本趋近于零
2. **高需求高毛利产品** → 产品本身用户已经在花钱买，且边际成本趋零
3. **极简团队 + 外包重资产** → 不需要工厂、仓库、团队

**匹配分析**：
| Medvi 要素 | 职业服务匹配度 | 说明 |
|-----------|-------------|------|
| AI 零成本获客 | 完美 | 小红书上简历技巧、面试经验、薪资数据天然有流量 |
| 高需求产品 | 完美 | 经济下行期"保住饭碗"是硬需求，不是锦上添花 |
| 高毛利 | 完美 | 简历模板边际成本零，AI 简历优化 API 调用几分钱 |
| 极简团队 | 完美 | 1 人启动，AI 辅助交付 |
| 创始人兴趣 | 匹配 | 创始人有技术+商业背景，对职场话题有真实积累 |
| 监管安全 | 极好 | 职业服务无资质要求，无政策敏感性 |

## Demand Evidence

- 小红书低粉丝卖家通过简历模板和虚拟资料每月赚 6 万+（已验证）
- 猎聘 B2B 收入 17.6 亿元，C2C 简历优化和职业咨询需求持续增长
- 中国知识付费市场 2025 年预计达 2808 亿元，教育/培训占 45%
- 求职焦虑内容在小红书收藏量极高，天然适合传播
- 经济下行期求职服务逆势增长（2008 年美国 LinkedIn 3 年涨 3 倍的历史验证）

## Status Quo

求职者目前解决简历/面试问题的方式：
1. 在小红书/知乎搜索免费简历模板（质量参差不齐）
2. 花 50-200 元在淘宝买简历模板
3. 花 500-2000 元找线下职业顾问做简历优化和面试辅导
4. 用 ChatGPT 辅助写简历（但不知道怎么写出好简历，提示词不对）
5. 靠朋友推荐面试经验（信息有限）

## Target User & Narrowest Wedge

**目标用户**：22-35 岁，正在找工作或准备跳槽的职场人，月收入 5000-15000 元。

**最窄切入点**：在小红书卖 9.9 元的 AI 优化简历模板包。第一天就能变现。

**为什么是简历而不是面试**：简历是最高频、最低决策门槛的付费点。9.9 元是冲动消费区间。用户买了简历模板后，可以自然引导到更高价的服务（AI 简历优化 → 面试准备 → 职业辅导）。

## Constraints

- 1 人全职启动，启动预算 ~500 元（AI API 费用）
- 创始人有技术背景（N8N、API 集成）和商业运营经验
- 必须轻资产，纯信息交付
- 不涉及金融/投资建议（需要资质）
- 不做"教人赚钱"类内容（监管风险高）
- 第一天就能开始卖东西，不先花几周"跑样板"

## Premises

1. **经济下行期，求职服务是逆势增长的刚需**。验证：2008 年美国 LinkedIn 用户 3 年涨 3 倍；2024-2026 年中国裁员潮持续。已同意。

2. **9.9 元简历模板是小红书上已验证的付费产品**。低粉丝卖家也能月入数万。已验证。

3. **AI 可以显著降低简历优化和面试准备的成本和门槛**。DeepSeek/Kimi API 调用成本每次几分钱。已同意。

4. **创始人的技术能力（N8N + API）是差异化竞争力**。大多数做简历服务的人不会搭建自动化系统。已同意。

5. **从低价数字产品起步，逐步升级到高价服务**。不先做高价安装服务，从 9.9 元开始降低用户决策门槛。修正自 Codex 建议（原建议砍掉低价入口，但在这个赛道低价产品本身就是利润来源）。

## Cross-Model Perspective

### Codex Review #1 (v1 方案)
建议从 done-with-you 服务起步，砍掉低价课入口。已采纳并推动了从"AI 流水线安装服务"到"职业服务"的方向转变。

### Codex Review #2 (v2 方案，当前)

Codex 提出了三个关键观点：

1. **最强版本不是简历服务，而是 AI 求职转化引擎**：诊断短板、重写定位、模拟面试、提升面试通过率。内容是获客，简历评分是入口，真正的产品是"把迷茫求职者变成高概率候选人"的标准化流水线。

2. **最大风险**：用户为简历优化付费，但他们真正想要的是面试和 offer。简历优化是代理问题。如果用户感受不到面试邀约率提升，复购和转化全崩。判断信号：50+ 人做了简历评分但 199 元转化率低于 5-10%，且用户反复说"太贵/我自己做/能保证面试吗"。

3. **替代方案"涨薪作战室"**：不做简历，做 AI 跳槽加速服务。免费钩子：上传目标 JD + 简历 + 当前薪资，出"薪资差距报告"。付费产品：60 天行动计划、成就改写、面试模拟、谈判话术。目标：拿到更高 offer。内容更病毒（"我如何从 8k 涨到 15k"），付费意愿更高。

**Claude 与 Codex 分歧**：Codex 建议直接跳到涨薪服务。Claude 认为应先用 9.9 元简历模板验证流量（成本低、速度快），流量成立后再升级。

**最终决策**：分阶段执行。Phase 1 用简历服务验证流量，Phase 2 升级到涨薪作战室。

## Approaches Considered

### Approach A: AI 职业加速服务（推荐）

**漏斗设计**：
```
第1层：AI 内容获客（Medvi 核心方法论）
  └─ 先开 1 个小红书号，主题"简历优化+求职技巧"
  └─ 每天发 3-5 条内容（AI 生成 + 人工改写）
  └─ 内容类型：简历技巧、面试经验、薪资数据、求职心态
  └─ 扩张触发：单号粉丝过 1000 或月销 50 单后，开第 2 个号
  └─ 成本：~200 元/月（DeepSeek API）

第2层：免费钩子（让用户占便宜）
  └─ "AI 免费简历评分"：用户私信发简历文字 → 你用 DeepSeek 分析 → 回复评分报告
  └─ 评分报告模板：
     - 整体评分：X/100
     - 优势：[3 条具体优点]
     - 问题：[3 条具体问题]
     - 改进建议：[3 条具体建议]
     - "想要完整的优化版？试试我们的 AI 简历优化服务"
  └─ 评分提示词："你是一个资深 HR，请对以下简历进行评分（0-100 分），
     指出 3 个优势、3 个问题、3 条改进建议。回复格式..."

第3层：低价数字产品（利润中心 + 筛选）
  └─ 简历模板包：9.9 元（20+ 模板，Canva 可编辑格式，按互联网/科技岗位分类）
  └─ AI 生成的部分：模板中的示例文案、岗位描述关键词
  └─ 边际成本：零
  └─ 小红书店铺直接成交（验证当前保证金政策：0 元试运营或 1000 元保证金）

第4层：中价服务（AI 辅助 + 人工审核）
  └─ AI 简历深度优化：199 元（AI 生成优化版 + 人工审核调整）
  └─ 每天最多交付 5 单（每单约 30 分钟人工审核）
  └─ 交付物：优化后的 Word 文档 + 修改说明 + 面试准备建议

第5层：高价 1 对 1 服务（第 8 周后推出）
  └─ 职业辅导/面试辅导：999-2999 元
  └─ AI 辅助生成个性化方案 + 1 对 1 视频辅导
  └─ 每月限 5 个客户
```

**启动成本**：~500 元（DeepSeek API + 小红书店铺保证金，验证最新政策）
**首次变现时间**：第 1 天就能挂产品链接。但注意：新号前 2-4 周小红书算法可能限流，首周真实销量可能为 0-5 单。

**容量限制**：
- 低价数字产品：无限制（自动交付）
- 199 元中价服务：每天 5 单上限（超过则排队或招兼职）
- 999+ 元高价服务：每月 5 个客户

**月收入预估（保守，第 1 个月，考虑新号限流）**：
- 低价产品（20 单 x 10 元均价）= 200 元
- 中价服务（3 单 x 200 元）= 600 元
- 合计：~800 元/月（第一个月主要在积累内容和数据）

**月收入预估（乐观，第 3 个月+）**：
- 低价产品（300 单 x 12 元均价）= 3,600 元
- 中价服务（20 单 x 250 元均价）= 5,000 元
- 高价服务（3 单 x 1500 元均价）= 4,500 元
- 合计：~13,100 元/月

**利润率**：90%+（数字产品边际成本零，中高价服务主要是 AI API 费用 + 时间）

### Approach B: AI 内容流水线安装服务（上一版方案，已推翻）

理由：需求太软，变现周期太长（4-6 周），不如职业服务第一天就能变现。

### Approach C: 纯 AI 职业工具 SaaS

做一个 AI 简历生成器/面试模拟器 Web 工具。

**问题**：需要开发周期，启动成本高，要与大量工具竞争。
**结论**：Phase 2 的产品。先用内容 + 服务验证需求，再产品化。

## Recommended Approach

**Approach A：AI 职业加速服务。**

核心理由（Medvi 视角）：
1. **AI 零成本获客**：求职内容在小红书上天然有流量，AI 批量生产降本
2. **高需求产品**：经济下行期找工作是硬需求，不是可选消费
3. **极快变现**：第 1 天就能卖 9.9 元模板，不需要等几周验证
4. **你的真实优势**：技术能力让你能搭 AI 自动化系统（简历评分、优化、面试模拟），这是大多数做简历服务的人做不到的
5. **监管安全**：职业服务无资质要求，不会像李一舟那样被封号
6. **复购路径清晰**：简历模板 → 简历优化 → 面试准备 → 职业辅导，每一步都是自然的升级

## Open Questions

1. 简历模板的行业覆盖：先做哪几个行业？建议先做互联网/科技（你最熟悉）

3. 矩阵号的人设是否需要真人出镜？如果不出镜，纯图文内容的流量上限是多少？

## Technical Architecture

**Phase 1（前 4 周，手动为主，验证流量）**：
- 内容生产：手动用 DeepSeek 生成文案 → 人工改写 → 手动发布小红书
- 免费评分：用户私信发简历文字 → 手动粘贴到 DeepSeek → 复制回复给用户
- 产品交付：小红书店铺自动发货（Canva 模板链接或百度网盘链接）
- 数据记录：飞书表格手动记录每条内容的浏览/互动/销售数据

**Phase 2（第 5-12 周，涨薪作战室，采纳 Codex 建议）**：

当 Phase 1 验证通过后（单条内容 1000+ 浏览或月销 20+ 单），升级漏斗：

```
免费钩子升级：
  "薪资差距报告"：用户提交 目标岗位JD + 当前简历 + 当前薪资
  → AI 分析差距（技能/经验/话术）→ 出报告
  → "你想在 60 天内拿到这个 offer 吗？"

付费产品升级：
  "涨薪作战室"（核心产品）：999-1999 元/60 天
  - 第 1 周：AI 分析短板 + 制定 60 天行动计划
  - 第 2-4 周：AI 改写工作成就 + 优化简历（针对目标岗位）
  - 第 5-6 周：AI 模拟面试练习 + 薪资谈判话术
  - 持续：每周行动清单 + 微信答疑
  - 承诺：60 天内拿到至少 1 个目标岗位面试，否则部分退款

内容升级：
  主题从"简历技巧"转向"我如何从 8k 涨到 15k"
  真实案例（脱敏后）作为内容素材
  更强的传播力
```

**Phase 3（第 4 个月+，产品化）**：
- 涨薪作战室产品化为 SaaS 工具（N8N 自动化交付）
- 自动化矩阵号管理
- 可能扩展到其他赛道（留学、考证）

## Regulatory Notes

- 职业服务不需要特殊资质（区别于金融建议、医疗咨询）
- 简历优化和面试辅导是标准商业服务，无政策敏感性
- 需要避免：承诺"保证拿到 offer"、"保证涨薪 X%"（夸大宣传风险）
- AI 生成内容需标注（2025 年 9 月规定）

## Competitive Moat

短期壁垒（3-6 个月）：
- AI 自动化能力：能用 N8N + DeepSeek 搭建自动化的简历评分和优化系统
- 内容规模：矩阵号批量生产求职内容，获客成本趋零
- "免费简历评分"钩子：让用户占便宜，建立信任

长期出路：
- 积累用户数据后产品化为 AI 简历/面试 SaaS 工具
- 积累行业薪资数据，做职场信息平台
- 或者用同样的 Medvi 方法论扩展到其他职业赛道（留学、考证、技能培训）

## The Assignment

**今天（第 1 天）**：
1. 用 Canva + AI 生成 20 个简历模板（按互联网/科技岗位分类，Canva 可编辑格式）
2. 写 3 篇小红书内容（"HR 最讨厌的 3 种简历格式"、"大厂面试官看简历只看这 5 秒"、"你的简历分数是多少？免费帮你评"）
3. 在小红书开通店铺（验证当前保证金政策），上架 9.9 元模板包
4. 发布第一条内容，带上产品链接
5. 准备数据隐私声明："您的简历仅用于评分分析，24 小时内删除，不存储不分享"

**第 1 周**：
- 每天发 3-5 条内容（AI 生成 + 人工改写）
- 记录每条浏览/互动数据
- 目标：卖出前 5 单

**第 2-4 周**：
- 根据数据放大有效内容类型
- 推出 199 元 AI 简历优化服务
- 开始建微信私域（买过低价产品的用户加微信）
- 目标：50 单低价产品 + 5 单中价服务

**第 5-8 周**：
- 推出面试准备包和职业辅导服务
- 如果数据好，开第 2-3 个矩阵号
- 目标：月营收 15,000-30,000 元

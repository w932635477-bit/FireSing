# Medvi 视觉升级设计：Spec v4.1 → v4.2

> 设计日期：2026-04-29
> 状态：已批准
> 依据：海外 AI 情绪视频制作技术研究（Corecore / Gen Z 纪录片 / 竖屏安全区）
> 目标：Spec v4.1 → v4.2

---

## 1. 设计决定

| # | 决定 | 依据 |
|---|------|------|
| 1 | 保持旁白驱动，吸收海外技术细节 | 核心竞争力是故事+旁白，纯 corecore 无旁白不适合抖音 |
| 2 | 后处理只对 AI 空镜，Playwright 截图不做 | 截图的价值是"证据感"（干净锐利），空镜需要后处理消除 AI 感 |
| 3 | 节奏表精确到秒写入 Spec | 海外数据证明呼吸式节奏提升 35% 完播率 |
| 4 | 字幕安全区作为硬性约束写入 Spec | 抖音底部 320px、小红书底部 540px 被 UI 遮挡 |
| 5 | 文字叠加用极简白字硬切 | 海外 corecore 标准做法，越粗糙越真实 |

## 2. 新增 §6.6 AI 空镜后处理管线（SHOULD）

### 2.1 后处理步骤

| 步骤 | 效果 | 参数 | 剪映实现 |
|------|------|------|---------|
| 胶片颗粒 | 可见但微妙的噪点纹理 | 强度 15-25% | 特效 → 噪点/颗粒 |
| 降饱和度 | 褪色感，不纯黑白 | 降低 20-30% | 调色 → 饱和度滑块 |
| 暗角 | 边缘渐暗，视觉聚焦中心 | 中等强度 | 特效 → 暗角 |
| 色差偏移（可选） | 模拟模拟信号感 | 2-3px 红蓝偏移 | 需要自定义 |

### 2.2 适用范围

- **适用：** Seedream/Kling 生成的 atmosphere_shots（氛围空镜）
- **不适用：** Playwright UI 截图（保持像素级真实，不做任何后处理）

### 2.3 设计理由

截图负责"证据感"（干净、锐利、像素级真实），空镜负责"氛围感"（带颗粒、略褪色、有温度）。两者风格差异帮助观众潜意识区分"这是真实素材"和"这是氛围渲染"。

## 3. 更新 §8 混剪节奏表（精确到秒）

### 3.1 呼吸式节奏原则

慢画面（3-5s）建立情绪 → 突然快切（0.5-1s × 3-5 个）制造冲击 → 再回到慢。这种"呼吸"式节奏比匀速快切提升 35% 完播率。

### 3.2 段落节奏表

| 段落 | 节奏模式 | 具体时间值 | 画面处理 |
|------|---------|-----------|---------|
| S01 前置高潮 | 极快闪切 | 0.5s/张 × 6-10 张截图 | 截图原始状态，无后处理 |
| S02 设定 | 中速 | 2-3s/张，穿插 1 张截图 | 空镜(后处理) + 截图(原始) |
| S03 崩塌 | 呼吸式：慢→快→慢 | 3s → 1s → 0.5s×3-5 → 2s → 1s → 0.5s×3 | 快切段用截图，慢段用空镜 |
| S04 转念 | 放慢 | 3-4s/张 | 暖色空镜先出现，截图最后 |
| S05 收尾 | 最慢，呼吸感 | 4-6s/张，纯空镜 | 空镜(后处理)，让观众消化 |
| S06 互动 | 收尾 | 2s，1 张截图 | 截图(原始) |

### 3.3 节奏设计关键数值

- 最低保持时间：0.8s（新的视觉元素至少 0.8s 才能被观众"注册"）
- 快切频率：0.5-1s/张（制造焦虑/紧迫感）
- 慢镜头：3-6s（让观众"进入"画面，激活共情）
- 情绪转折点：用节奏突变标记（突然从 3s 切到 0.5s，观众生理上会有反应）

## 4. 新增 §8.2 字幕安全区规则（MUST）

### 4.1 平台安全区

**1080×1920 竖屏安全区：**

| 平台 | 顶部遮挡 | 底部遮挡 | 安全区 |
|------|---------|---------|-------|
| 抖音 | 130px（关注/推荐标签） | 320px（用户名、文案、音频） | 130-1600px（7%-83%） |
| 小红书 | 150px（Reels 标题） | 540px（大型 UI 区域，28%屏幕） | 150-1380px（8%-72%） |
| YouTube Shorts | 顶部搜索/相机图标 | 右侧互动+底部频道信息 | 类似抖音 |
| **通用安全区** | 150px | 540px | **画面高度 8%-72%** |

### 4.2 硬性规则（MUST）

- 所有字幕/文字叠加放在画面高度 **25%-70%** 区域（留余量）
- 距屏幕左右边缘至少 **60px**
- 字体：无衬线（PingFang SC / 思源黑体）
- 最小字号：**18pt**（移动端观看）
- 每行最多 **42 个字符**
- 每条字幕显示时长：最短 **1s**，最长 **6s**
- 连续字幕之间留 **2 帧**间隔

## 5. 新增 §8.3 文字叠加样式（MUST）

### 5.1 样式规格

| 属性 | 值 |
|------|-----|
| 字体颜色 | 白色（#FFFFFF） |
| 对比度要求 | ≥ 7:1（WCAG 2.1 AA） |
| 阴影 | 无 |
| 描边 | 无（或仅底图过亮时用 1px 黑色描边） |
| 动画 | 无 — 硬切进出（瞬间出现，瞬间消失） |
| 位置 | 画面高度 25%-70%，水平居中 |
| 背景 | 半透明黑色遮罩（可选，仅当底图太亮无法保证对比度时） |

### 5.2 禁止项

- 不用淡入淡出动画
- 不用彩色字体
- 不用描边（除了纯黑背景上的白字不需要任何修饰）
- 不用花哨字体
- 不用打字机效果
- 不用弹跳/缩放动画

### 5.3 设计理由

海外 corecore 标准做法。纯白字硬切看起来"像匆忙加上去的"，这种粗糙感反而产生真实感和冲击力。精致的字幕动画在情绪视频中会显得"被设计过"，削弱信任感。

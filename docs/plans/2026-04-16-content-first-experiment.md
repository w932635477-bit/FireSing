## 核心策略

**用内容获客，用服务变现，从服务中发现产品。**

```
内容（展示 AI 能力）
  → 吸引企业主/商家
    → 聊需求，卖服务：
      a) 帮他们做内容 = AI 代运营（500-2000元/月/客户）
      b) 帮他们搭 AI 工具 = AI Agent 代搭建（3000-5000元/单）
      c) 发现其他共性需求 = 未来产品方向
```

这不是"做内容等灵感"。内容就是获客渠道，代运营和 Agent 代搭建就是变现方式。4 周内验证：你的内容能不能吸引愿意付费的企业主。

## 变现路径

不是"看数据再定"，而是带着两个明确的变现选项开始：

### 路径 A：AI 代运营

| 维度 | 内容 |
|------|------|
| 客户 | 本地商家、小电商、个体户 |
| 你做什么 | 用 AI 工具帮他们批量生产抖音/小红书营销内容 |
| 定价 | 500-2000 元/月/客户 |
| 复购 | 高（月度合同，续约率 80%+） |
| 你的成本 | AI 工具订阅 ~750 元/月 + 时间 |
| 10 客户月收入 | 5,000-20,000 元 |

**你的优势**: Medvi 方法论 + 矩阵号策略。其他代运营公司一个小编一天做 3-5 条内容，你可以用 AI 一天做 30-50 条。效率差一个数量级。

### 路径 B：AI Agent 代搭建

| 维度 | 内容 |
|------|------|
| 客户 | 有线上业务的中小企业 |
| 你做什么 | 用 Coze/Dify 帮他们搭建 AI 客服、AI 销售助手、AI 工作流 |
| 定价 | 3,000-5,000 元/单 + 500-1,000 元/月维护 |
| 复购 | 中（维护费 + 新需求迭代） |
| 你的成本 | 几乎为零（Coze/Dify 免费层） |
| 5 客户月收入 | 15,000-30,000 元（含搭建费+维护） |

**你的优势**: 技术背景。Coze/Dify 不需要写代码，但需要理解 AI 的工作方式。你能做到比一般"AI 工具培训师"更深。

### 两条路径的关系

不需要提前选。做内容吸引来的都是"想用 AI 提升业务"的人，聊了之后才知道他们需要 A 还是 B：
- "我内容做不好，没时间" → 代运营
- "我需要客服/销售工具" → Agent 搭建
- "我都想要" → 两样都卖

## 为什么你的内容可以赢

抖音上教 AI 获客的人很多，但大多数是二手搬运。你的差异化：

1. **一手来源**: NYT、Business Insider、Futurism、36氪 的原始报道，不是从别的博主那里听的
2. **深度拆解**: 你花了 2 天拆解 Medvi 的完整工作流，有具体数字（$103/月工具费、800 账号、5000 广告活动）
3. **实战导向**: 你有技术能力实际操作工具，可以录屏演示完整工作流
4. **透明度**: "我从 0 开始测试，这是真实数据"比"教你月入 10 万"有说服力
5. **内容即能力证明**: 你用 AI 做内容做得好，客户自然想"你能帮我做吗"

## 制作工作流

用 Medvi 方法做自己的内容：

1. **选题**: 从研究文档中提取核心观点
2. **脚本**: ChatGPT 写初稿，自己调整语气和节奏
3. **画面**: 场景素材 + 屏幕录制 + 关键信息字幕卡
4. **配音**: 自己配音（前 4 周不依赖 AI 配音，建立真实感）
5. **后期**: 剪映剪辑，加字幕、BGM
6. **分发**: 抖音 + 小红书同步发布

**重要**: 前 4 周不追求完美。完成比完美重要。每条视频控制在 2 小时内完成。

## 4 周验证标准

| 指标 | 通过 | 失败 |
|------|------|------|
| 总粉丝（抖+红） | > 500 | < 100 |
| 微信私域企业主人数 | > 10 | < 3 |
| 有人问"你能帮我做吗" | > 3 人 | 0 人 |
| 成交服务订单 | > 1 单 | 0 单 |

**成交 1 单就是验证。** 哪怕只收 500 元/月做代运营，第一笔收入说明需求是真的。

### 4 周后的决策

| 结果 | 行动 |
|------|------|
| 代运营需求为主 | 扩大代运营客户，目标 10 客户 = 5,000-20,000 元/月 |
| Agent 搭建需求为主 | 专注 Agent 搭建，标准化流程，提高效率 |
| 两者都有 | 双线并行，优先服务高客单价的 Agent 搭建 |
| 个人用户为主但不愿付费 | 转向知识产品（PDF/课程），但定价要低 |
| 全部失败 | 停止投入，复盘原因，考虑完全不同的方向 |

## 第 5-8 周路径（如果 4 周验证通过）

### 如果代运营验证通过

1. 把前 4 周的内容制作流程标准化
2. 用 Coze/Dify 搭建半自动化内容生产 pipeline
3. 目标：每周服务 5 个客户，每个客户 10 条内容
4. 月收入目标：5,000-15,000 元

### 如果 Agent 搭建验证通过

1. 把常见需求（客服、销售、内容管理）做成模板
2. 每个新客户用模板快速交付，定制化只做 20%
3. 目标：每月 3-5 单搭建 + 10 个维护客户
4. 月收入目标：15,000-30,000 元

### 从服务中发现产品

服务 10+ 客户后，一定会出现共性需求。那个共性需求才是值得做成产品的东西：

```
服务 10 个客户
  → 发现 7 个客户都有同一个需求
    → 这个需求变成了产品方向
      → 用服务收入养产品开发
        → 产品上线后用 Medvi 方法获客
          → 服务 → 产品 → 获客 → 循环
```

## 风险与应对

| 风险 | 应对 |
|------|------|
| 内容没人看 | 前 2 周测试不同标题/风格，找到有效格式后加倍投入 |
| 做着做着变成"教人赚钱" | 定位为"AI 方法论拆解者 + 服务提供者"，不是"赚钱导师" |
| 客户要做你不会的 | 只接你能力范围内的。不会的可以学，但不要过度承诺 |
| 代运营交付耗时太多 | 用 AI 工具标准化流程。每个客户每周不超过 2 小时 |
| Agent 搭建技术不够 | 先用 Coze/Dify 低代码平台，复杂需求用 API 对接 |
| 4 周后没有清晰的需求信号 | 严格止损，不延长实验。数据不够就是信号 |
| 犹豫不决不敢发 | 完成比完美重要。第一条视频发布是最大的障碍 |

## 与之前否决方案的关系

| 方案 | 否决原因 | 现在的区别 |
|------|---------|------------|
| 知识产品 | "别人在免费教" | 内容是获客手段，不是产品。如果数据证明有付费意愿才做 |
| AI 内容工作室 | "好方法不是好产品" | 不预设产品。服务是过渡，产品从服务中发现 |
| AI 配音工具 | 大厂在解决 | 不做工具。用现有工具做服务 |
| 实体产品 | 供应链太重 | 不碰实体。服务和内容零库存 |

## 核心原则

1. **发出去比做完美重要。** 第一条视频不会是好的。第十条会好很多。
2. **成交 1 单 > 1000 粉丝。** 粉丝数是虚荣指标。有人付费才是真验证。
3. **4 周是硬约束。** 不延长。4 周后用数据做决策：继续、转向、停止。
4. **服务是桥梁，不是终点。** 从服务中发现产品。服务赚现金流，产品做规模。
5. **记录一切。** 每条内容的数据、每条有价值的评论、每个客户的需求。这些数据是决策的依据。

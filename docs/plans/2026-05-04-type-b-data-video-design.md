## 视觉方案

v3 工作流（零成本）：

- **数据卡片**：Playwright 截屏生成 TOP5 排行榜卡片（白底黑字+红色数字）
- **空镜素材**：Unsplash 免费 stock 照片（每个行业2-3张）
- **排名数字卡片**：FFmpeg textcards（大号"第5名""第4名"...）
- **拼接**：FFmpeg compose 脚本，配音时长驱动

## 音频

- **配音**：Charon 男声，第一人称叙述（覆盖 Aoede 女声规则）
- **BGM**：紧张悬疑类（低音鼓点），8% 音量

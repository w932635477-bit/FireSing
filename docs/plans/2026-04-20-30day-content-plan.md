# 30 天 AI 视频内容计划

> 目标：用 Medvi + Sings 工作流连续生产 30 条短视频，验证"AI 视频营销方法论"的有效性
> 开始日期：2026-04-21
> 平台：抖音 + 小红书（竖版 9:16）
> 账号定位：AI 增长黑客 / 独立开发者的营销武器

---

| 阶段 | 天数 | 目标 |

## 3. 工作流选择策略

### Medvi 工作流（纪录片旁白，70% 内容）

**适合：** 数据驱动、故事性强、知识科普类选题
**节奏：** 旁白驱动，35-40 秒
**模板：** `config/day1-medvi-story.json`

**批量生产流程（每天 1 条）：**
1. 上午：选题 → 填 JSON 配置（15 分钟）
2. 中午：跑 Seedream 生参考图（10 分钟）→ 人工选图（5 分钟）
3. 下午：Runway 生视频（20 分钟，手动操作）
4. 下午：Edge TTS 配音（5 分钟）
5. 傍晚：FFmpeg 合成（5 分钟）→ 剪映精修（20 分钟）
6. 晚上：发布 + 互动

**单条耗时：** 约 1.5 小时（熟练后可压到 1 小时）

### Sings 工作流（说唱 MV，30% 内容）

**适合：** 有趣、有节奏感、适合传播的选题
**节奏：** 音乐驱动，60-120 秒
**模板：** `config/sings-template.json`

**频率：** 每 3-4 天 1 条（耗时是 Medvi 的 2 倍）

## 4. 效率优化目标

### 第一周：建立流程
- 目标：每条 Medvi 视频 ≤ 2 小时
- 手段：严格按照 SOP 执行，不纠结细节
- 关键：快速出片 > 完美主义

### 第二周：加速
- 目标：每天能出 1.5 条 Medvi 视频
- 手段：并行操作（配音和视频生成同时进行）
- 关键：找到可以批量化的步骤

### 第三周起：半自动化
- 目标：每天 2 条
- 手段：脚本批量化（一次生 3 条视频的参考图）
- 关键：减少手动环节

## 5. 数据追踪

每条视频记录以下数据（Notion 表格）：

| 字段 | 说明 |
|------|------|
| 视频编号 | #01 ~ #30 |
| 发布日期 | 实际发布日 |
| 选题 | 简短描述 |

| 钩子类型 | 名人/数字/成本/利益/认知 |
| 制作时长 | 分钟 |
| 24h 播放 | 发布后 24 小时播放量 |
| 7d 播放 | 发布后 7 天播放量 |
| 完播率 | % |
| 点赞 | 数量 |
| 评论 | 数量 |
| 转发 | 数量 |
| 关键评论 | "教教我"类评论摘录 |

### 数据分析节奏

- **每天：** 记录 24h 数据
- **每周：** 复盘选题类型 vs 数据表现，调整下周选题
- **Day 15：** 中期复盘，确定爆款模式
- **Day 30：** 总结报告，决定是否启动训练营/代运营

## 6. 后续变现路径（Day 30 后决策）

### 如果数据好（总播放 ≥ 10 万，有爆款）

**路线 A：Vibe Marketing 训练营**
- 定价：999 元/人（早鸟）/ 1999 元（正式）
- 班级：10 人小班
- 周期：4 周，每人出 4 条视频
- 交付物：Notion SOP + 4 次直播 + 微信群答疑

**路线 B：AI 营销代运营**
- 定价：5000-10000 元/月
- 交付：每月 8-10 条视频
- 客户：独立开发者、小团队 SaaS

### 如果数据一般（总播放 < 5 万）

- 调整选题方向（可能不是"开发者增长"这个赛道）
- 测试不同视频风格
- 继续迭代，不急着变现

### 如果数据差（总播放 < 1 万）

- 重新评估"AI 视频营销"这个方向
- 考虑是否选题问题还是方法论问题
- 可能需要换赛道

## 7. 每日执行模板

### Medvi 日程（每天）

```
09:00  选题确认（5 分钟）
09:05  填写 JSON 配置（10 分钟）
09:15  seedream-batch.py 生参考图（10 分钟）
09:25  人工选图 + 微调 prompt（5 分钟）
09:30  手动 Runway 生视频（20 分钟，可后台跑）
09:30  edge-tts-batch.py 配音（5 分钟，与 Runway 并行）
09:50  ffmpeg-compose-day1.py 合成（5 分钟）
09:55  剪映后期：字幕 + 滤镜 + 水印（20 分钟）
10:15  导出 + 写发布文案（5 分钟）
10:20  发布到抖音/小红书
---
总计：约 1 小时 20 分钟
```

### Sings 日程（每 3-4 天）

```
上午：选题 → 填 JSON → Suno 生成歌曲（等待 3-5 分钟）
下午：Seedream 参考图 → Runway 视频
傍晚：FFmpeg 合成 → 剪映后期（字幕对齐最耗时）
---
总计：约 2-3 小时
```

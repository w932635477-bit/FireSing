# 启点视频脚本写作框架（v1.0）

> 来源：深度分析天涯说书人「你凭什么比别人更快挣到钱」(129.8万赞, 79%收藏率, 46%分享率)
> 确立日期：2026-05-11
> 原则：固定框架，看数据复盘，迭代框架本身

---

## 第一性原则

1. **赚钱是钩子，不是背景**。观众的目的只有一个：怎么赚钱。故事围绕赚钱展开，认知在故事中递进。
2. **不怕视频长，怕故事无聊**。只要每个段落都有独立钩子，完播率自然上来。
3. **一个爆款研究透彻，围绕它不停干**。不追求数量，每条视频都对比爆款分析。

---

## 六段式结构

| 段落 | 编号 | 功能 | 时长占比 | 钩子类型 | 必须包含 |
|------|------|------|---------|---------|---------|
| 开场钩子 | S01 | 反直觉故事，让观众停下拇指 | 8-12% | 反直觉事实 | 一个具体的"人" + 一个让目标人群觉得"这就是我"的场景 |
| 第一个案例 | S02 | 同类人翻盘，让观众觉得"他行我也能" | 15-20% | 翻盘故事 | 一个"和你差不多的人"做了不一样的事 + 具体动作 |
| 大佬/圈内人视角 | S03 | 引入权威视角，放大价值 | 15-20% | 大佬分析 | 一句"大佬的话"作为翻转点 + 价值放大（"比XX值钱/值XX万"） |
| 核心翻转 | S04 | 口诀+故事佐证，全视频高潮 | 25-35% | 口诀式总结 | 2-3个可执行动作的口诀 + 每个配简短故事 + 一个终极翻转金句 |
| 回到观众 | S05 | 从故事切回观众本身 | 5-8% | 你也能 | "你也行"的温和表达 + 消除恐惧/降低门槛 |
| CTA | S06 | 固定识别语 + 互动引导 | 5-8% | 转化 | 固定识别语 + 下期预告 + 评论区互动（打1-2个字） |

## 每个段落的写作检查清单

### S01 开场钩子

- [ ] 前3秒是否有具体画面（不是抽象描述）？
- [ ] 是否有反直觉（和你想的不一样）？
- [ ] 目标人群是否觉得"这就是我"？
- [ ] 是否以赚钱/值钱为导向？

### S02 第一个案例

- [ ] 主角是否"和观众差不多"（同龄/同行/同处境）？
- [ ] 主角做了什么具体的"不一样的事"？
- [ ] 是否有数据锚点（从X%到Y% / 第一个月赚了X）？
- [ ] 观众是否能照做？

### S03 大佬/圈内人视角

- [ ] 是否有"大佬"或"圈内人"出场？
- [ ] 大佬的话是否是一句金句（可截图）？
- [ ] 是否放大了主角经验的价值？
- [ ] 观众看完是否开始想"我也有这种东西"？

### S04 核心翻转

- [ ] 是否有2-3个字/词的口诀？
- [ ] 每个口诀步骤是否配了具体动作？
- [ ] 是否有一个终极翻转（不是你不行，是方法不对）？
- [ ] 是否有一句"可截图"的金句？

### S05 回到观众

- [ ] 是否呼应了前面的金句/口诀？
- [ ] 是否消除了观众的恐惧（"晚了"/"我不行"）？
- [ ] 是否温和而不是说教？

### S06 CTA

- [ ] 是否以「你的经验比你想象中值钱」开头？
- [ ] 是否有下期预告？
- [ ] 评论区互动是否只需打1-2个字？
- [ ] 互动词是否呼应正文核心概念？

## 固定元素

### 固定识别语（每条视频必须有）

**「你的经验比你想象中值钱」**

位置：S06 CTA段落的第一个分句。
作用：品牌记忆锚点 + 情绪释放。

### TTS配置

```json
{
  "engine": "gemini",
  "voice": "Aoede",
  "emotions": ["calmly_qidian", "simply_qidian", "quietly_qidian"]
}
```

- `calmly_qidian`：开场、案例、CTA（平实讲述）
- `simply_qidian`：核心翻转、口诀（有力量但不煽情）
- `quietly_qidian`：回到观众（温暖、笃定）

## 标题公式

```
赚钱导向 + 悬念/反直觉 + 直接指向目标人群
```

好标题示例：
- 「40岁失业，他怎么靠脑子里的东西赚到第一个五千」
- 「干了18年机床的师傅，怎么靠一个眼神赚钱」
- 「44岁店关了，他怎么靠亏过的钱开始赚钱」

标题要包含搜索关键词：赚钱、经验、变现、失业。

---

## 合规红线

- 不提具体收入数字（用"赚到钱"代替"赚了X万"）
- 不承诺"几天内见效"
- 不引导私信/社群/加微信
- 不使用"暴富""躺赚"等敏感词
- AI生成内容需标注

## 数据复盘模板

每条视频发布后，记录以下数据用于复盘：

```
视频ID: ___________
标题: ___________
发布日期: ___________

数据（发布后第X天）:
- 播放量: _______
- 完播率: _______%
- 点赞: _______  点赞率: _______%
- 收藏: _______  收藏率: _______%（目标 > 10%）
- 分享: _______  分享率: _______%（目标 > 3%）
- 评论: _______
- 评论区互动数: _______

复盘:
1. 哪个段落的跳出率最高？（可能是钩子不够）
2. 收藏率是否达标？（收藏=用户觉得值得反复看）
3. 分享率是否达标？（分享=用户觉得值得转给朋友）
4. 评论区观众说了什么？（暴露真实心理）
5. 哪句话被截图最多？（金句验证）
6. 下次迭代方向：_______________
```

### 数据基准线（参考天涯说书人爆款）

| 指标 | 爆款水平 | 及格水平 | 需优化 |
|------|---------|---------|-------|
| 收藏率 | >50% | 10-20% | <5% |
| 分享率 | >30% | 3-8% | <1% |
| 完播率 | >60% | 30-40% | <20% |

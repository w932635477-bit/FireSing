## 第一性原则

1. **赚钱是钩子，不是背景**。观众的目的只有一个：怎么赚钱。故事围绕赚钱展开，认知在故事中递进。
2. **故事决定时长，时长不决定故事**。不设视频时长上限。天涯说书人10分钟完播率极高，因为每段都有独立钩子。训练段必须展开到观众能照做的程度，宁可3分钟讲透，不可1分钟讲薄。
3. **一个爆款研究透彻，围绕它不停干**。不追求数量，每条视频都对比爆款分析。
4. **对话比独白强10倍**。开场必须是穷鬼-大佬一问一答的戏剧，不是一个人直接讲道理。
5. **每个故事都有三个特征**：具体（有职业、有场景、有细节）、反直觉（和你想的不一样）、可代入（观众能把自己放进去）。
6. **翻转要快，训练要深**。核心翻转（武装+赋能）必须短促有力，不给观众喘息。展开训练必须足够详细，让观众觉得"我真能做到"。时长分配不是均匀的，训练段应该是全视频最长的部分。

## 认知手术六步法（核心模型）

> 天涯说书人的本质不是"讲故事"，是对观众做一场六步认知手术。每一步解决上一步的焦虑，同时制造下一步的需求。

| 阶段 | 手术步骤 | 功能 | 对应段落 | 时长占比 | 核心技术 |
|------|---------|------|---------|---------|---------|
| 打碎自尊 | **羞辱** | 降低观众防御 | S01 | 15% | 穷鬼-大佬对话剧（嘲讽→重定义→毁灭） |
| 摧毁旧认知 | **诊断** | 指出观众的错误 | S02 | 20% | 排比案例 + 核心金句首次出现 |
| 揭示真相 | **揭示** | 展示观众不知道的 | S03 | 25% | 核弹级冲突故事 + 翻转 |
| 给出武器 | **武装** | 口诀式行动框架 | S04前半 | 28% | 三动词口诀 + 每步配具体动作 |
| 详细训练 | **训练** | 让观众觉得"我能做" | S04后半 | (含在S04) | 数据锚点 + 终极翻转 |
| 身份转变 | **赋能** | 给观众新身份 | S05 | 8% | 核心金句第三次 + 消除恐惧 |

### 认知失调链（观众为什么不离开）

每一步都在解决上一步的焦虑，同时制造下一步的需求：

1. "我穷/我被裁了"（承认现状）→ 嘲讽打碎自尊
2. "那你让我怎么办"（产生需求）→ 诊断指出你一直在犯错
3. "我哪里错了"（想知道答案）→ 揭示隐藏的真相
4. "但我不会做"（产生焦虑）→ 武装给你工具
5. "但我不敢/不会用"（产生恐惧）→ 训练降低门槛
6. "但我怕做不好"（最后一道恐惧）→ 赋能给新身份+消除退路

**关键**：观众看完不离开，不是因为"故事好听"，是因为每一步都有未解决的焦虑推着他往下走。

## 六段式结构（映射到认知手术）

| 段落 | 编号 | 认知手术步骤 | 时长占比 | 钩子类型 | 必须包含 |
|------|------|------------|---------|---------|---------|
| 开场钩子 | S01 | 羞辱 | 15% | 三拍对话剧 | Setup悬念 + 嘲讽(不给信息) + 重定义 + 毁灭 + 直指观众 |
| 大哥指点 | S02 | 诊断 | 20% | 排比+金句 | 三个排比案例(递进) + 核心金句第一次(大哥说) |
| 认知翻转 | S03 | 揭示 | 25% | 冲突故事+翻转 | 核弹级冲突故事 + "不是你不行"消除防御 + 金句第二次(主角顿悟) |
| 核心翻转 | S04 | 武装+训练 | 28% | 口诀+展开 | 三动词口诀 + 每步具体动作 + 数据锚点 + 终极翻转 |
| 回到观众 | S05 | 赋能 | 8% | 金句第三次 | 核心金句第三次(观众的现实) + 零成本验证法 + 消除恐惧 |
| CTA | S06 | 转化 | 5% | 互动 | 固定识别语 + 下期预告 + 互动(打1个字) |

## S01 开场钩子：穷鬼-大佬对话剧（强制结构）

> 天涯说书人前76秒（12.6%时长）贡献了绝大部分完播率。这段是一出三拍对话剧，不是独白。

### 五层结构（每条视频的S01必须包含全部五层）

| 层次 | 技巧 | 天涯说书人范例 | 启点ep01范例 | 启点ep02范例 |
|------|------|--------------|-------------|-------------|
| 1. Setup悬念 | 一句话钉住人物处境 | "一个穷鬼去请教大佬" | "老张被裁了，去找大哥求帮忙" | "老陈45岁，厂子关了，去找老东家求帮忙" |
| 2. 嘲讽 | 真正轻蔑，不给任何有用信息 | "刑法里，你去翻翻" | "你这岁数了，回去歇着吧" | "你这岁数，歇着吧" |
| 3. 重定义 | 翻转问题的方向 | "不是最快，是凭什么" | "你不是来找路子的吗？那我先问你——" | "你不是能干活吗？那我问你——" |
| 4. 毁灭 | 排比或反问摧毁最后一个借口 | "去工地看看，去后厨看看" | "别人找你帮忙的，你记得几个？" | "机器一响你就知道哪儿不对，这个本事你卖过吗？" |
| 5. 直指观众 | 从故事中拉出，把刀对准观众 | "这把刀就两个字——资格" | "老张愣住了" | "老陈愣住了" |

### 写作规则

1. **嘲讽必须是真正轻蔑的**：不给任何有用信息。"送外卖吧"是给建议（失败），"歇着吧"是看不起人（成功）。
2. **权威感靠肢体语言**："头都没抬"5个字胜过"大哥很厉害"。不要用形容词描述权威。
3. **穷鬼就是观众**：穷鬼的台词（"我能吃苦""我这双手还能干"）就是观众想说的话。大佬打穷鬼的脸，就是在打观众的脸。
4. **对话不是独白**：一问一答制造戏剧张力。每轮对话必须有情绪变化（急了→愣住→顿悟）。

## 多故事钩子链（每段独立钩子）

> 天涯说书人的核心技巧：不是一个故事讲到底，而是每段都有独立的案例/钩子。

| 段落 | 故事/案例类型 | 观众反应 | 写法要点 |
|------|-------------|---------|---------|
| S01 | 穷鬼-大佬对话 | "我被人看不起，但我也没话说" | 对话剧，嘲讽是轻蔑不是建议 |
| S02 | 排比案例（3个同类场景递进） | "我也有这种经历，而且越来越重" | 从轻到重递进，最后一个制造最大冲击 |
| S03 | 核弹级冲突故事 | "原来大佬是这么看的" | 花大钱请专家 vs 老师傅免费解决 |
| S04 | 主角具体动作（口诀三步） | "我也能这样做" | 每步配具体动作+数据锚点 |
| S05 | 回到观众自己 | "我也有这些东西" | 核心金句第三次出现 |

### 钩子链检查

每个故事的三个必要特征：
- **具体**：有职业、有场景、有细节（不能是抽象概念）
- **反直觉**：你以为是A，其实是B
- **可代入**：观众能把自己放进去（"这不就是我吗？"）

## 核心金句三次重复模式

> 天涯说书人的"资格"概念贯穿全片。启点每条视频必须有一个核心金句，重复三次。

| 出现位置 | 谁说 | 作用 | ep01 | ep02 |
|---------|------|------|------|------|
| S02 | 大哥说 | 首次抛出，权威背书 | "你一直在白送，从来没卖过" | "你觉得基本的，恰恰最值钱" |
| S03 | 主角顿悟 | 内化，观众跟着理解 | "从来没拿出来卖过" | "你觉得基本的，恰恰最值钱" |
| S05 | 变成观众的现实 | 第三次回响，观众代入 | "你是一直在白送，从来没卖过" | "你觉得基本的，恰恰最值钱" |

### 金句要求

- **短**：不超过12个字
- **有矛盾**：看似矛盾但细想有道理
- **和排比呼应**：金句的矛盾感来自S02的排比铺垫
- **三次语境不同**：第一次权威指出，第二次主角领悟，第三次变成观众的现实

## 三动词口诀设计

> 天涯说书人用"抢、骗、偷"三个贬义词。每条视频的口诀也要有张力。

| 视频 | 口诀 | 每步含义 | 张力来源 |
|------|------|---------|---------|
| ep01 | 找、拆、卖 | 找出47个问题→拆成步骤→卖给需要的人 | "卖"直接指向赚钱，消除"不好意思卖"的心理障碍 |
| ep02 | 盯、剥、亮 | 盯住最值钱的直觉→剥成步骤→亮到需要的人面前 | "盯"有猎食感，"剥"有暴力感，"亮"有炫耀感 |

### 口诀设计规则

1. **三个动词，每个一个字**
2. **每个动词有张力**：不是中性词（"看"），是有情绪的词（"盯"）
3. **每步配具体动作**：不是抽象概念，是观众能照做的步骤
4. **有数据锚点**：ep01有"47个问题"，ep02有"三秒vs三天"
5. **终极翻转收尾**："你不是没有X，你是一直在Y"句式

## 三层比喻体系（天涯说书人核心技巧）

天涯说书人用了三个比喻覆盖三个认知层次，每条视频至少需要一个核弹级比喻：

| 认知层次 | 天涯说书人比喻 | 功能 | 启点用法 |
|---------|--------------|------|---------|
| 世界是什么样的 | 蘑菇（有人有手电筒，你两眼一抹黑） | 建立"世界不透明"的认知 | ep01: "MBA理论值钱，踩过的坑不值钱？" ep02: "书本教操作，手感长在身体里" |
| 规则是什么样的 | 赌场（老板只认筹码不认苦劳） | 打碎"努力就有回报"幻觉 | ep01: "你白送了20年的东西，全是你最值钱的" ep02: "花几十万请专家，最后是老师傅解决" |
| 你是什么样的 | 扳手（你是工具，不是使用工具的人） | 打碎"我是有价值员工"幻觉 | ep01: "你把自己的东西看得太便宜了" ep02: "你一直在把最值钱的本能当基本操作白送人" |

## 每个段落的写作检查清单

### S01 开场钩子（穷鬼-大佬对话剧）

- [ ] 是否有Setup悬念句（一句话钉住人物处境）？
- [ ] 嘲讽是否真正轻蔑（不给任何有用信息，不是给建议）？
- [ ] 是否有重定义节拍（大佬翻转问题的方向）？
- [ ] 是否有毁灭节拍（排比或反问摧毁观众的借口）？
- [ ] 权威感是否靠肢体语言（"头都没抬"类描写），而不是形容词？
- [ ] 穷鬼的台词是否是观众想说的话？
- [ ] 前3秒是否有具体画面（不是抽象描述）？
- [ ] 目标人群是否觉得"这就是我"？
- [ ] 嘲讽→重定义→毁灭是否形成三拍递进（情绪从笑到懵到被击中）？

### S02 大哥指点（排比+金句）

- [ ] 是否有3个排比案例（从轻到重递进）？
- [ ] 3个案例是否具体（有职业、有场景、有数据）？
- [ ] 核心金句是否第一次出现（大哥说出）？
- [ ] 最后一个案例是否制造最大价值冲击？

### S03 认知翻转

- [ ] 是否有核弹级冲突故事（花大钱请专家 vs 老师傅免费解决）？
- [ ] 是否以"不是你不行"类句式消除防御？
- [ ] 主角是否在情绪高点顿悟（"那天晚上没睡着"）？
- [ ] 核心金句的变体是否出现（主角内化）？
- [ ] 是否有身体vs理论/知识vs本能的终极对比？

### S04 核心翻转（武装+训练）

- [ ] 是否有3个动词的口诀（每个一个字）？
- [ ] 每个动词是否有张力（不是中性词）？
- [ ] 每个口诀步骤是否配了具体动作（不是抽象概念）？
- [ ] 是否有数据锚点（"三秒vs三天"类具体对比）？
- [ ] 是否有终极翻转（"你不是没有X，你是一直在Y"句式）？
- [ ] 具体动作是否能让观众照做？

### S05 回到观众

- [ ] 核心金句是否第三次出现？
- [ ] 是否直接用"你"指向观众？
- [ ] 是否呼应了前面的数据锚点？
- [ ] 是否给了零成本验证法（"试着说给干了三年的人听"）？
- [ ] 是否温和而不是说教？

### S06 CTA

- [ ] 是否以「你的经验比你想象中值钱」开头？
- [ ] 是否有下期预告？
- [ ] 评论区互动是否只需打1个字？
- [ ] 互动词是否呼应正文核心概念？

## 对比优化检查点

> 每条视频脚本写完后，必须逐项对比天涯说书人爆款，检查差距。

### 必检项（每条脚本都要过）

| 检查项 | 天涯说书人做法 | 检查标准 |
|-------|--------------|---------|
| 开场是否是对话剧 | 穷鬼-大佬三拍对话（0-76秒） | S01必须有嘲讽+重定义+毁灭 |
| 嘲讽是否轻蔑（非建议） | "刑法里，你去翻翻" | 不给有用信息，是看不起人 |
| 是否有重定义节拍 | "不是最快，是凭什么" | 翻转问题方向 |
| 权威感靠肢体还是形容词 | "盘核桃，眼皮都没抬" | 不用"厉害""权威"等形容词 |
| 每段是否有独立钩子 | 6段6个独立案例 | 不是一个故事讲到底 |
| 核心金句是否重复3次 | "资格"贯穿全片 | S02→S03→S05 |
| 口诀是否有张力 | "抢、骗、偷"三个贬义词 | 每个动词有情绪，不是中性词 |
| 是否有数据锚点 | 具体数字增强可信度 | 三秒vs三天 / 47个问题 |
| 是否有核弹级冲突故事 | 花几十万请专家 vs 老师傅 | S03必须有价值对比冲突 |
| 是否有终极翻转 | "你不是没有X，你是一直在Y" | S04收尾句 |
| 首尾是否呼应 | "资格"开头结尾都出现 | 核心概念贯穿全片 |

### 优化方向优先级

1. **开场对话剧质量**（决定完播率）→ 最优先
2. **核心金句的穿透力**（决定收藏率）→ 次优先
3. **口诀的可执行性**（决定分享率）→ 第三
4. **排比案例的具体度**（决定代入感）→ 第四
5. **核弹级冲突故事**（决定认知冲击）→ 第五

## 标题公式

```
赚钱导向 + 悬念/反直觉 + 直接指向目标人群
```

好标题示例：
- 「40岁失业，他怎么靠脑子里的东西赚到第一个五千」
- 「干了18年机床的师傅，怎么靠一个眼神赚钱」
- 「44岁店关了，他怎么靠亏过的钱开始赚钱」

标题要包含搜索关键词：赚钱、经验、变现、失业。

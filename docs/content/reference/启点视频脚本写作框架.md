# 启点视频脚本写作框架（v2.0）

> 来源：深度分析天涯说书人「你凭什么比别人更快挣到钱」(129.8万赞, 79%收藏率, 46%分享率)
> 确立日期：2026-05-11
> v2.0更新日期：2026-05-13
> v2.0改动：基于Whisper逐字稿分析，重构S01为穷鬼-大佬对话剧，新增五层钩子、多故事钩子链、核心金句三次重复、对比优化检查点
> 原则：固定框架，看数据复盘，迭代框架本身

---

## 第一性原则

1. **赚钱是钩子，不是背景**。观众的目的只有一个：怎么赚钱。故事围绕赚钱展开，认知在故事中递进。
2. **不怕视频长，怕故事无聊**。只要每个段落都有独立钩子，完播率自然上来。
3. **一个爆款研究透彻，围绕它不停干**。不追求数量，每条视频都对比爆款分析。
4. **对话比独白强10倍**。开场必须是穷鬼-大佬一问一答的戏剧，不是一个人直接讲道理。
5. **每个故事都有三个特征**：具体（有职业、有场景、有细节）、反直觉（和你想的不一样）、可代入（观众能把自己放进去）。

## 六段式结构

| 段落 | 编号 | 功能 | 时长占比 | 钩子类型 | 必须包含 |
|------|------|------|---------|---------|---------|
| 开场钩子 | S01 | **穷鬼-大佬对话剧**，让观众停下拇指 | 15% | 三拍对话剧 | Setup悬念 + 三拍对话（嘲讽→重定义→毁灭/反问） + 旁白直指观众 |
| 大哥指点 | S02 | 排比证据冲击，抛出核心金句 | 20% | 排比+金句 | 三个"X的"排比 + 核心金句第一次出现（大哥说出） |
| 认知翻转 | S03 | 消除防御+翻转认知 | 25% | 消除防御+翻转 | "不是你不行"消除防御 + 大佬金句放大价值 + 主角顿悟 |
| 核心翻转 | S04 | 口诀+故事佐证，全视频高潮 | 28% | 口诀式总结 | 2-3个可执行动作的口诀 + 每个配具体动作 + 终极翻转 |
| 回到观众 | S05 | 金句回响，切回观众本身 | 8% | 金句第三次 | 核心金句第三次出现（变成观众的现实） + 消除恐惧 |
| CTA | S06 | 固定识别语 + 互动引导 | 5% | 转化 | 固定识别语 + 下期预告 + 评论区互动（打1个字） |

## S01 开场钩子：穷鬼-大佬对话剧（强制结构）

> 天涯说书人前76秒（12.6%时长）贡献了绝大部分完播率。这段是一出三拍对话剧，不是独白。

### 五层结构（每条视频的S01必须包含全部五层）

| 层次 | 技巧 | 天涯说书人范例 | 启点ep01范例 |
|------|------|--------------|-------------|
| 1. Setup悬念 | "只说了一句话，他后半辈子都没忘" | 大佬只说了一句话 | "去找一个做供应链的大哥求帮忙" |
| 2. 嘲讽 | 幽默降低防御，同时建立权威 | "刑法里，你去翻翻" | "你这岁数了，回去歇着吧" |
| 3. 重定义 | 打碎观众原有认知框架 | "不是最快，是凭什么" | "你不是来找路子的吗？那我先问你——" |
| 4. 毁灭/反问 | 排比证据摧毁最后一个借口 | "去工地看看，去后厨看看" | "你干仓储20年，别人找你帮忙的，你记得几个？" |
| 5. 直指观众 | 从故事中拉出，把刀对准观众 | "这把刀就两个字——资格" | 老张愣住了（观众也愣住） |

### 写作规则

1. **嘲讽必须是真正轻蔑的**：不给任何有用信息。"送外卖吧"是给建议（失败），"回去歇着吧"是看不起人（成功）。
2. **权威感靠肢体语言**："头都没抬"5个字胜过"大哥很厉害"。不要用形容词描述权威。
3. **穷鬼就是观众**：穷鬼的台词（"我能吃苦""大哥你别看不起人"）就是观众想说的话。大佬打穷鬼的脸，就是在打观众的脸。
4. **对话不是独白**：一问一答制造戏剧张力。每轮对话必须有情绪变化（急了→愣住→顿悟）。

## 多故事钩子链（每章独立钩子）

> 天涯说书人的核心技巧：不是一个故事讲到底，而是每章都有独立的案例。每个案例都是一个新的钩子。

### 结构要求

| 章节 | 故事/案例类型 | 观众反应 | 写法要点 |
|------|-------------|---------|---------|
| S01 | 穷鬼-大佬对话 | "原来我不值钱不是因为不努力？" | 对话剧，不是独白 |
| S02 | 排比案例（3个同类场景） | "我也有这种经历" | 三个"白帮的/白干的"排比 |
| S03 | 大佬一句话翻转 | "原来大佬是这么看的" | 一句金句翻转认知 |
| S04 | 主角具体动作（找、拆、卖） | "我也能这样做" | 每步配具体动作+数据锚点 |
| S05 | 回到观众自己 | "我也有这些东西" | 核心金句第三次出现 |

### 钩子链检查

每个故事的三个必要特征：
- **具体**：有职业、有场景、有细节（不能是抽象概念）
- **反直觉**：你以为是A，其实是B
- **可代入**：观众能把自己放进去（"这不就是我吗？"）

---

## 核心金句三次重复模式

> 天涯说书人的"资格"概念贯穿全片。启点每条视频必须有一个核心金句，重复三次。

| 出现位置 | 谁说 | 作用 | ep01范例 |
|---------|------|------|---------|
| S02 | 大哥说 | 首次抛出，权威背书 | "你一直在白送，从来没卖过" |
| S03 | 主角顿悟 | 内化，观众跟着理解 | "脑子里装的经验，从来没拿出来卖过" |
| S05 | 变成观众的现实 | 第三次回响，观众代入 | "你是一直在白送，从来没卖过" |

### 金句要求

- **短**：不超过12个字
- **有矛盾**：看似矛盾但细想有道理
- **和"白帮的"排比呼应**：金句的矛盾感来自S02的排比铺垫
- **不能用"卖"和"白送"以外的抽象概念**：必须具体到动作

## 每个段落的写作检查清单

### S01 开场钩子（穷鬼-大佬对话剧）

- [ ] 是否有Setup悬念句（"他只说了一句话，XX都没忘"类似句式）？
- [ ] 嘲讽是否真正轻蔑（不给任何有用信息，不是给建议）？
- [ ] 是否有重定义节拍（大佬翻转问题的方向）？
- [ ] 是否有毁灭/反问（排比或反问摧毁观众的借口）？
- [ ] 权威感是否靠肢体语言（"头都没抬"类描写），而不是形容词？
- [ ] 穷鬼的台词是否是观众想说的话？
- [ ] 前3秒是否有具体画面（不是抽象描述）？
- [ ] 目标人群是否觉得"这就是我"？

### S02 大哥指点（排比+金句）

- [ ] 是否有3个排比案例（"X的。X的。X的。"句式）？
- [ ] 3个案例是否从远到近递进？
- [ ] 核心金句是否第一次出现（大哥说出）？
- [ ] 排比案例是否具体（有职业、有场景）？

### S03 认知翻转

- [ ] 是否以"不是你不行"类句式消除防御？
- [ ] 是否有大佬金句放大价值（"比XX值钱""值XX万"）？
- [ ] 主角是否在情绪高点顿悟（"那天晚上没睡着"）？
- [ ] 核心金句的变体是否出现（主角内化）？

### S04 核心翻转（口诀）

- [ ] 是否有2-3个字/词的口诀？
- [ ] 每个口诀步骤是否配了具体动作（不是抽象概念）？
- [ ] 是否有数据锚点（"47个"类具体数字）？
- [ ] 是否有终极翻转（"从免费改成收费"类认知颠覆）？
- [ ] 口诀是否对应天涯说书人的"抢、骗、偷"三步独立动作结构？

### S05 回到观众

- [ ] 核心金句是否第三次出现？
- [ ] 是否直接用"你"指向观众？
- [ ] 是否呼应了前面的数据锚点（"你也X个"）？
- [ ] 是否温和而不是说教？

### S06 CTA

- [ ] 是否以「你的经验比你想象中值钱」开头？
- [ ] 是否有下期预告？
- [ ] 评论区互动是否只需打1个字？
- [ ] 互动词是否呼应正文核心概念？

## 对比优化检查点

> 每条视频脚本写完后，必须逐项对比天涯说书人爆款，检查差距。

### 必检项（每条脚本都要过）

| 检查项 | 天涯说书人做法 | 我的脚本做法 | 差距？ |
|-------|--------------|------------|-------|
| 开场是否是对话剧 | 穷鬼-大佬三拍对话（0-76秒） | | |
| 嘲讽是否轻蔑（非建议） | "刑法里，你去翻翻" | | |
| 是否有重定义节拍 | "不是最快，是凭什么" | | |
| 权威感靠肢体还是形容词 | "盘核桃，眼皮都没抬" | | |
| 每章是否有独立钩子 | 4章4个独立案例 | | |
| 核心金句是否重复3次 | "资格"贯穿全片 | | |
| 口诀是否拆成动作 | "抢、骗、偷"三个动词 | | |
| 是否有数据锚点 | 具体数字增强可信度 | | |

### 优化方向优先级

1. **开场对话剧质量**（决定完播率）→ 最优先
2. **核心金句的穿透力**（决定收藏率）→ 次优先
3. **口诀的可执行性**（决定分享率）→ 第三
4. **排比案例的具体度**（决定代入感）→ 第四

## 固定元素

### 固定识别语（每条视频必须有）

**「你的经验比你想象中值钱」**

位置：S06 CTA段落的第一个分句。
作用：品牌记忆锚点 + 情绪释放。

### TTS配置

```json
{
  "engine": "gemini",
  "voice": "Aoede",
  "emotions": ["calmly_qidian", "simply_qidian", "quietly_qidian"]
}
```

- `calmly_qidian`：开场S01、大哥指点S02、CTA S06（平实讲述）
- `simply_qidian`：认知翻转S03、核心翻转S04（有力量但不煽情）
- `quietly_qidian`：回到观众S05（温暖、笃定）

## 标题公式

```
赚钱导向 + 悬念/反直觉 + 直接指向目标人群
```

好标题示例：
- 「40岁失业，他怎么靠脑子里的东西赚到第一个五千」
- 「干了18年机床的师傅，怎么靠一个眼神赚钱」
- 「44岁店关了，他怎么靠亏过的钱开始赚钱」

标题要包含搜索关键词：赚钱、经验、变现、失业。

---

## 合规红线

- 不提具体收入数字（用"赚到钱"代替"赚了X万"）
- 不承诺"几天内见效"
- 不引导私信/社群/加微信
- 不使用"暴富""躺赚"等敏感词
- AI生成内容需标注

## 数据复盘模板

每条视频发布后，记录以下数据用于复盘：

```
视频ID: ___________
标题: ___________
发布日期: ___________

数据（发布后第X天）:
- 播放量: _______
- 完播率: _______%
- 点赞: _______  点赞率: _______%
- 收藏: _______  收藏率: _______%（目标 > 10%）
- 分享: _______  分享率: _______%（目标 > 3%）
- 评论: _______
- 评论区互动数: _______

对比优化:
1. 开场对话剧 vs 天涯说书人0-76秒：差距在哪？
2. 核心金句穿透力 vs "资格"：观众记住了吗？
3. 口诀可执行性 vs "抢骗偷"：观众能照做吗？
4. 排比案例代入感 vs "工地/后厨"：观众觉得"这就是我"吗？

数据复盘:
1. 哪个段落的跳出率最高？（可能是钩子不够）
2. 收藏率是否达标？（收藏=用户觉得值得反复看）
3. 分享率是否达标？（分享=用户觉得值得转给朋友）
4. 评论区观众说了什么？（暴露真实心理）
5. 哪句话被截图最多？（金句验证）
6. 下次迭代方向：_______________
```

### 数据基准线（参考天涯说书人爆款）

| 指标 | 爆款水平 | 及格水平 | 需优化 |
|------|---------|---------|-------|
| 收藏率 | >50% | 10-20% | <5% |
| 分享率 | >30% | 3-8% | <1% |
| 完播率 | >60% | 30-40% | <20% |

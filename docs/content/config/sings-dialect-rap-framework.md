# Sings 方言说唱 歌词+BGM 融合框架

## BGM 结构 (Fraelis, 128 BPM Tech House, 95s)

```
时间轴:
0s──────15s──────30s──37s──45s─47s──────60s──────75s──────90s─95s
│ A段(主拍)  │ A段续    │ 过渡段  │DROP│ B段(主拍)  │ B段续    │ B段续    │尾│
│ HIGH ENERGY │ HIGH    │ BREAK   │ !! │ HIGH ENERGY│ HIGH     │ HIGH     │FADE│
└─────────────┴─────────┴─────────┴────┴────────────┴──────────┴──────────┴───┘
```

- 128 BPM → 每拍 0.47s，每小节(4拍) 1.875s，每8小节段(phrase) 15s
- A段 (0-30s): 16小节，高能量主节拍
- 过渡段 (30-45s): 8小节，能量下降，铺垫
- DROP (45-47s): 1-2小节，能量最低→突然回升
- B段 (47-90s): 23小节，高能量，全曲高潮
- 尾声 (90-95s): 5s淡出

## 歌词结构映射

Suno 的 `[Section]` 标记影响演唱风格。必须按 BGM 结构安排：

```
[Intro]              → 0-4s    (2小节)   短感叹/开场白，1-2句
[Verse 1]            → 4-30s   (14小节)  主说唱段，半说半唱，节奏感强
[Break]              → 30-45s  (8小节)   放慢，语气变化，铺垫悬念
[Chorus]             → 47-65s  (10小节)  高潮段，能量最高，金句/包袱
[Verse 2]            → 65-85s  (11小节)  继续说唱，配合高潮余韵
[Outro]              → 85-95s  (5s)      收尾金句/反转
```

## 音节密度规则

128 BPM 下半说半唱风格：

| Section | 每小节音节数 | 每段总音节 | 说明 |
|---------|-------------|-----------|------|
| Intro   | 2-4         | 4-8       | 短促，吸引注意 |
| Verse   | 6-8         | 80-110    | 节奏紧凑，断句清晰 |
| Break   | 3-5         | 24-40     | 放慢，留白，增加戏剧性 |
| Chorus  | 8-10        | 80-100    | 最密集，能量最高 |
| Outro   | 4-6         | 10-15     | 简洁收尾 |

**中文参考**: 东北方言说唱，每句7-10字最顺口（类似二人转的"句"）

## Suno Prompt 模板

### 歌词格式 (suno_format)

```
[Intro]
{1-2句开场感叹，东北口语}

[Verse 1]
{4-6句，每句7-10字，押韵}
{内容：冲突对立主题的前半段}

[Break]
{2-3句，放慢节奏}
{内容：转折/铺垫/悬念}
{语气：自言自语或反问}

[Chorus]
{4-6句，最密集最有力}
{内容：核心冲突/最大包袱}

[Verse 2]
{3-5句，延续高潮}

[Outro]

{节奏：拖长最后一个字}
```


## 冲突对立歌词模板

每集选一个对立主题：

| 对立维度 | 示例主题 |
|---------|---------|
| 职场 | 老板 vs 打工人 |
| 爱情 | 相亲期望 vs 现实 |
| 金钱 | 月光族 vs 富二代 |
| 年龄 | 90后 vs 00后 |
| 消费 | 双11剁手 vs 退款 |
| 社交 | 朋友圈 vs 真实生活 |
| 教育 | 鸡娃 vs 放养 |
| 城市 | 一线城市梦 vs 回老家 |

### 歌词写作原则

1. **每句必须有一个"刺"** — 听众觉得"说到我心里了"
2. **Break段必须有悬念** — 让人期待接下来是什么
3. **Chorus必须是最扎心的** — 这是完播率的决定性段落
4. **Outro必须反转** — 让人想听第二遍
5. **东北方言点缀** — 哎呀妈呀、咋整、嘎哈呢、整挺好，但不过度

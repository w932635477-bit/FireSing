## Day 4 — 首条：你帮公司省过钱吗

**破圈逻辑：** 不讲具体行业，只问一个问题——"你帮公司省过钱吗？"每个打工人都代入。省了200万的采购人、省了50万的程序员、省了20万的行政……评论区自动展开。

### 全文
**Director's Notes:**
开头是提问不是陈述，让人停下来想。"特斯拉"是视觉化锚点，不是冷数字。态度句"公司最被低估的人"要说得像你真的这么认为，不是在喊口号。

```
[calmly] 公司里最被低估的人是谁？
不是清洁工，不是实习生，
是那个帮公司省过钱的人。

你替老板省下的29万，能直接提一辆Model Y。
但你的年终奖，连四个轮子都买不起。
[pause]

[simply] 给老板省钱，不等于给自己赚钱。

你做的那些事——砍价砍掉30%，
避开2个坑，锁住1个好渠道——
换个地方，叫"咨询服务"，按小时收费。

[confidently] 从明天开始，
我跟大家聊聊，
怎么把帮老板省钱的本事，变成自己的收入。

你帮公司省过钱吗？
评论区说说你省了多少。
```

**截图点：** 29万提Model Y vs 年终奖买不起四个轮子 / 给老板省钱≠给自己赚钱
**态度句：** 给老板省钱，不等于给自己赚钱
**转发理由：** 每个打工人都有共鸣——"我就是那个人"

## Day 5 — 你工资配不上你脑子里的东西

**破圈逻辑：** 不讲具体行业，讲一个所有人都有感受的真相——你的工资远低于你知识的实际市场价。每个行业的人都会在评论区说出自己的故事。

### 全文
**Director's Notes:**
开头是判断不是信息，让人不服或认同。"月薪1万5"和"500一小时"要做直接对比，不是分开说。"每个行业都有这种人"是跨圈层锚点，说完后观众会开始想自己认识的人。

```
[calmly] 每个行业都有这种人——
工资配不上脑子里的东西。

14年外贸老炮，年入18万，
但他帮客户省的钱，一年300万起步。
[pause]
做了10年的装修工头，日薪400。
但他知道的那些避坑门道，
准备装修的人愿意花2000块听他讲半天。

[simply] 你的工资不是你的价值。
你的工资，是你老板愿意付你的最低价。
人才市场给你标的价，是500块一小时。

[confidently] 你真正的客户不是HR，
是那些需要你经验的人。

@一个被低估的朋友。
评论区说说他有多懂行。
```

**截图点：** 年入18万 vs 帮客户省300万 / 工资是老板愿意付你的最低价 / 人才市场标价500/hr
**态度句：** 你的工资不是你的价值，是你老板愿意付你的最低价
**转发理由：** @那个被低估的朋友

## Day 6 — 房产中介知道的秘密

**破圈逻辑：** v3版唯一破圈（93分），微调：删掉"199场场满"推销感，加利益冲突揭示增强争论性。房地产是全民话题，买房人+中介两边都会在评论区发言。

### 全文
**Director's Notes:**
"中介不会告诉你的事"像凑近说秘密。"差20%"是最大截图点。删掉了v3的"199场场满"变现推销。"按成交价抽佣"揭示利益冲突，让争论升级。

```
[quietly] 说一个房产中介不会告诉你的事。

同一个小区，挂牌价和真实成交价，
能差20%。
[pause]
干了10年的中介，看一眼就知道——
这套房业主急卖，砍15%没问题。
那套房学区是坑，别碰。
这个户型以后转手没人要。

[confidently] 你在APP上刷三个月，
不如一个干了10年的人带你看一次。

但中介按成交价抽佣，
他不会告诉你底价。
只有被裁了的那个中介，
才敢说真话。

你觉得买房最大的坑是什么？
评论区聊聊。
```

**截图点：** 挂牌价 vs 成交价差20% / APP刷三个月不如带看一次
**态度句：** 只有被裁了的那个中介，才敢说真话
**转发理由：** 买房人必转 / 中介"终于有人说真话了" / 父母转给孩子"买房前看这个"

## Day 7 — 装修行业的信息差有多大

**破圈逻辑：** 替换采购题材。装修是全民话题——人人都要装修，信息差极大。"花10万成本4万"让所有人震惊。装修过的人会在评论区比价，没装修过的人会收藏。

### 全文
**Director's Notes:**
"花10万成本4万"是全组最狠的截图点。"成本4万"说完停顿，让数字砸下去。态度句"你花的钱，一半买材料，一半买不知道"要慢，每个字清楚。"干了15年的工头"不是失业故事，是信息差故事。

```
[calmly] 朋友刚装完103平，花了10万。
你知道实际成本多少吗？
[pause]
大概4万。

另外6万去哪了？
被3个环节赚走了：
设计费1万，渠道费2万，信息差3万。

干了15年的装修工头，
看一眼报价单就知道哪里有水分。
三万块瓷砖，工厂1.2万就出。
全屋定制标价8万，出厂价不到3万。

[confidently] 你以为你在买材料，
其实你在为信息差买单。

装过修的朋友，你觉得你被坑了多少？
评论区说说，让没装的人长个心眼。
```

**截图点：** 花10万成本4万 / 三万瓷砖工厂1.2万 / 全屋定制8万出厂不到3万
**态度句：** 你以为你在买材料，其实你在为信息差买单
**转发理由：** 装修过的人比惨 / 没装修的人收藏 / 转给准备装修的朋友

## 情绪标记速查

| 标记 | 含义 | 使用场景 |
|------|------|----------|
| `[calmly]` | 平静陈述事实 | 抛数字、揭真相 |
| `[simply]` | 简单直接 | 点题、转折 |
| `[confidently]` | 笃定有力 | 结论、态度句 |
| `[quietly]` | 压低声音 | 揭秘、内幕 |
| `[pause]` | 停顿0.5-1秒 | 数字砸下去之前的呼吸 |

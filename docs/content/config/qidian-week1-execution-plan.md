## build-qidian-dayN.py 脚本功能

每个脚本自动完成：
1. 生成渐变背景（径向渐变 + 暗角）
2. 渲染品牌水印（启点·经验变现）
3. 渲染柱状图/数据对比图表
4. 文字卡片动画（fadeIn/fadeOut）
5. 计数器动画（数字翻滚）
6. 弹幕层（白色文字，散布在画面不同位置）
7. 底部黄色字幕（给静音观看者）
8. 合成音频 + 所有视觉层 → MP4 (1080x1920, 30fps)

### 需要更新的内容（每个脚本）

1. **TIMELINE** — 基于新配音实际时长重新计算
2. **SUBTITLES** — 更新为 v4.2 文案
3. **DANMAKU** — 更新为 v4.2 相关弹幕
4. **视觉内容** — 文字卡片内容匹配新脚本
5. **OUTPUT_PATH** — 确认输出目录

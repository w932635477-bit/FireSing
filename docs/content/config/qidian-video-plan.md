# 启点 抖音视频生产方案

## 总览

| 项目 | 设定 |
|------|------|
| 账号 | 启点·经验变现（品牌号） |
| 目标人群 | 40+失业/想搞副业的中年人 |
| 视频形式 | AI配音 + 图文混剪 |
| 发布频率 | 每天1条 |
| 视频时长 | 30-60秒 |
| 制作时间 | 每条约30-45分钟 |

## 一、养号计划（前7天）

### 第1-3天：打标签（不发视频）

每天15分钟：
1. 搜索"失业中年""副业""经验变现""40岁创业""中年转型"
2. 刷相关视频，看完的点赞（5-10个/天）
3. 关注3-5个同类账号
4. 不评论、不转发、不发视频

同时准备第一批视频素材（见下方生产流程）。

### 第4-7天：发首批视频

- 每天发1条，固定时间（建议 7:00-8:00 或 12:00-13:00）
- 播放量200-500是正常的，不要慌
- 关注完播率 > 30%，互动率 > 3%

### 第8天起：常规运营

- 每天发1条
- 回复所有评论（前30条评论一定要回）
- 评论区引导："私信我发'变现'，免费评估你的经验"

## 二、视频内容模板（4种轮换）

每周按 轮换，保持内容多样性。

### 模板A：信心类（周一、四）

**目的：** 打破"我不行了"的心态，给信心。

**结构：**
```
[3秒钩子] 你的经验，比你想象的值钱
[20秒正文] 讲一个普通人靠经验赚钱的故事或观点
[5秒CTA] 关注启点，我教你怎么变现
```

**示例脚本：**
```
你在这个行业干了十几年，
你觉得自己过时了，没人要了。

但你有没有想过，
你随口就能说出来的行业底价、渠道、避坑经验，
这些东西，正在装修的人愿意花钱买。

有个做建材的大哥，
把"瓷砖怎么选不踩坑"写成帖子发到网上，
第一个月就有人来咨询。

你的经验不是废纸。
关注启点，我教你怎么把经验变成收入。
```

**视觉：** 大字标题 + 简单背景（纯色/渐变）+ 关键数据字幕

### 模板B：方法类（周二、五）

**目的：** 给具体可执行的方法。

**结构：**
```
[3秒钩子] 3步把你的经验变成钱
[30秒正文] 具体步骤，每步1句话
[5秒CTA] 关注启点，我一步步教你
```

**示例脚本：**
```
3步把你的行业经验变成钱。

第一步，列出你最常被人问的3个问题。
比如你是做装修的，客户是不是总问你"这个材料贵不贵"？
这些问题就是你的产品。

第二步，把答案写成一篇500字以内的帖子。
不要长篇大论，就写"XX避坑指南"，配上具体价格和对比。

第三步，发到小红书或闲鱼。
标题写"X年XX人教你避坑"，定价99块一次咨询。

不会写？不会发？
关注启点，我手把手教你。
```

**视觉：** 步骤卡片（1/2/3）+ 示例截图 + 流程图

### 模板C：案例类（周三）

**目的：** 用真实故事建立信任。

**结构：**
```
[3秒钩子] 44岁失业半年，他靠什么赚到了钱？
[30秒正文] 匿名化真实案例故事
[5秒CTA] 你也有可以变现的经验，关注启点
```

**示例脚本：**
```
有个大哥44岁，建材行业干了15年，
行业不行了，失业半年。

投简历没人回，去送外卖膝盖受不了。

后来有人跟他说：
你知不知道建材城卖80的砖，工程渠道只要30？
他说是啊，这个我闭着眼睛都知道。

那这就是你的产品啊。
他发了第一个帖子，标题是"10年建材人教你选砖不踩坑"。

第一周，3个人来问。
第一个月，咨询费收了500。

500块不多。
但他说了一句话：我终于觉得我还有用。

你的经验，也有人需要。
关注启点。
```

**视觉：** 时间线卡片 + 数字高亮 + 情绪转折字幕

### 模板D：数据/洞察类（周六、日）

**目的：** 建立专业感，吸引理性用户。

**结构：**
```
[3秒钩子] 你知道吗？XX%的人副业收入超过了主业
[20秒正文] 1-2个数据点 + 你的解读
[5秒CTA] 关注启点，了解更多副业数据
```

**示例脚本：**
```
你知道你的行业经验值多少钱吗？

一个做婚庆策划的姑娘，
在婚庆公司干了8年，管理1000万的广告预算。
她的知识值多少钱？
她开始教小商家怎么做抖音投流，
一节课收500，一个月开了10场。

一个做餐饮的老板，
开了10年店，知道哪个供应商便宜、哪道菜利润高。
他现在专门帮新开餐厅做菜单定价，
一次收2000。

你在这个行业干了多少年？
你的经验值多少钱？
关注启点，免费帮你评估。
```

**视觉：** 数据卡片 + 行业图标 + 对比图表

## 三、生产流程（每条约30-45分钟）

### Step 1：写脚本（10分钟）

从模板中选择一个，根据当天的主题写脚本。
- 字数：100-200字（对应30-60秒）
- 口语化，不用书面语
- 不用"赋能""闭环""生态"这类词

我可以帮你批量生成脚本，你审核修改即可。

### Step 2：生成配音（5分钟）

使用 Gemini TTS（Charon 男声，语速适中）。

```bash
# 在 FireSing 项目中
source docs/content/.env
cd docs/content/scripts
python gemini-tts-batch.py --config ../config/qidian-tts.json
```

配音要求：
- 语速：偏慢（目标用户40+，太快要听不清）
- 情绪：温暖、坚定、有信心
- 男声（Charon），不用女声

### Step 3：制作视觉素材（15分钟）

**不需要 Seedream 人物图。** 用以下素材类型：

1. **大字标题**：用剪映的文字模板，白字+半透明背景条
2. **数据卡片**：用 Keynote/PPT 做简单的数字卡片，导出为图片
3. **纯色背景**：深蓝(#1a365d)、深灰(#2d3748)、白色，交替使用
4. **可选：免费素材**：Pexels/Pixabay 的办公/城市/工作场景（但不要依赖，纯图文也够）

### Step 4：剪映合成（10分钟）

1. 导入配音
2. 按配音节奏切分字幕
3. 每个句子配一张视觉素材
4. 加字幕（剪映自动识别，手动校对）
5. 加背景音乐（极轻，不要压过配音）
6. 导出 9:16 竖版

### Step 5：发布

- 标题：脚本的第一句话（钩子）
- 话题标签：#经验变现 #副业 #中年转型 #失业 #创业 #中年人
- 封面：大字标题，字体醒目

## 四、批量生产建议

每天1条的节奏，建议周日批量准备下一周的：

1. **周日**：写7条脚本（我可以帮你生成初稿，你审核）
2. **周日**：批量生成7段配音
3. **周一到周日**：每天花15分钟在剪映里合成1条 + 发布

这样每天的投入从45分钟降到15分钟。

## 五、数据观察指标

| 阶段 | 时间 | 指标 | 达标线 |
|------|------|------|--------|
| 冷启动 | 第1-2周 | 单条播放量 | 500+ |
| 起量 | 第3-4周 | 单条播放量 | 1000+ |
| 稳定期 | 第2月起 | 粉丝增长 | 50+/天 |
| 引流 | 第2月起 | 私信咨询 | 5+/天 |

**如果2周后播放量还是200以下：**
- 检查完播率（低于20%说明内容不够吸引）
- 检查前3秒钩子（不够抓人）
- 换话题方向试

## 六、红线（再次强调）

1. 不提任何名人名字
2. 不引未验证数据
3. 不承诺"月入XX"
4. 不搬运
5. 不碰政策/裁员原因等敏感话题
6. 不用"AI生成"标签（抖音对AI内容有限流趋势）

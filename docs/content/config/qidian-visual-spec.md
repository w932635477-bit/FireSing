# 启点 视频画面生产手册（v1）

## 工具选择

**唯一工具：剪映桌面版（CapCut PC）**

所有效果都有现成模板，不需要 AE/Canva。

---

## 全局视觉规范

### 字体与颜色

| 元素 | 规格 |
|------|------|
| 主标题 | 思源黑体 Heavy ≥ 52pt，白色 |
| 关键数字（损失/价差） | #FF4500 红色，加粗，比正文大 1.5 倍 |
| 省钱数字 | #00E676 绿色，加粗 |
| 正文/字幕 | 白色 36pt，底部安全区上沿 80px |
| 背景 | 深色系：#1a1a2e / #16213e / #0f3460 按天轮换 |

### 截图规范

每条视频的截图点画面必须包含：
1. 核心数字（大红字）
2. 态度句（白字，紧贴数字下方）
3. 右上角账号头像 + Logo
4. 右下角"长按识别"箭头
5. 顶部/底部留 5-8% 空白

### 节奏规范

- 前 1 秒至少 2 个动画元素
- 每 0.7-1.2 秒切换动效层（数字、文字、图形至少一个在动）
- 截图点停顿 1.5 秒静止（让观众截图）

## 4 条视频分镜与制作指南

### Day 4 — 你帮公司省过钱吗

**前 3 秒（完播率决定区）：**
- 黑屏 → 计数器翻滚：0 → 290,000（红色数字跳动上升）
- 剪映模板搜索：`number counter` 或 `数字滚动`
- 备选方案：用 SRT 字幕文件做数字递增序列

**3-8 秒（第一个截图点）：**
- 硬切：29万（大红色）瞬间变为 3,000（小白色）
- 反转彩蛋：3,000 下方小字"还是税前"（灰色 18pt）
- 态度句出现：给老板省钱 ≠ 给自己赚钱（白字绿 "="）

**8-15 秒（信息展开）：**
- 砍掉30% → 避开2个坑 → 锁住1个渠道
- 每个数字用 AR 悬浮效果逐个弹出
- 剪映模板搜索：`3D floating text` 或 `悬浮文字`
- 弹幕层叠加：底部飘过"真实""说得太对了""我就是这样"

**15-25 秒（系列预告 + CTA）：**
- 画面渐暗 → 中间出现"从明天开始"
- 最后 2 秒：头像飞入 + "你帮公司省过钱吗？"

**配色：** 背景 #1a1a2e（深紫蓝）

---

### Day 5 — 你工资配不上你脑子里的东西

**前 3 秒：**
- 左右分屏（剪映内置功能：Style → Split Screen）
- 左侧：年入 18 万（灰色调，小字）
- 右侧：帮客户省 300 万（红色大字，数字滚动弹出）
- 中间分界线：闪电劈开效果

**3-8 秒（核心对比）：**
- 左侧换成：日薪 400（灰色）
- 右侧换成：2000 块/半天（绿色，弹出）
- 态度句居中出现：你的工资，是你老板愿意付你的最低价

**8-18 秒（第二层冲击）：**
- 500 块/小时 用 AR 悬浮数字从底部升起
- 弹幕层：底部飘过"我身边就有""@他来看看"
- "人才市场给你标的价"→ 数字 500 从画面正中炸开出现

**18-25 秒（CTA）：**
- "@一个被低估的朋友"文字弹出
- 最后 0.5 秒纯色背景 + "评论区说说他有多懂行"

**配色：** 背景 #16213e（深蓝）

---

### Day 6 — 房产中介知道的秘密

**前 3 秒：**
- 航拍城市画面（Pexels 免费素材：搜索 "aerial city China"）
- 画外音起：说一个房产中介不会告诉你的事
- 画面闪白 → 切入数字

**3-8 秒（最大截图点）：**
- 模拟房源截图（用 Canva 做一张房产 APP 风格的图，导入剪映）
- 红圈标注：挂牌价 vs 真实成交价
- 红圈动画：剪映 Shapes → 红色圆圈 + pop-in 动画
- 剪映模板搜索：`red circle` 或 `红圈标注`

**8-18 秒（行业秘密逐个揭底）：**
- 三条判断逐条出现（急卖砍15% / 学区坑 / 户型没人要）
- 每条用撕纸揭开效果
- 剪映模板搜索：`paper tear` 或 `撕纸效果`

**18-28 秒（利益冲突 + CTA）：**
- 态度句：只有被裁的中介才敢说真话
- 弹幕层：中介评论"终于有人说真话了""我就是中介我作证"
- 最后 0.5 秒纯色 + "你觉得买房最大的坑是什么？"

**配色：** 背景 #0f3460（深藏蓝）

---

### Day 7 — 装修行业的信息差有多大

**前 3 秒：**
- 103平 花 10 万 → 硬切到 成本 4 万
- 10万 数字用计数器快速倒数到 4万
- 红色 → 绿色的颜色渐变

**3-10 秒（6万拆解）：**
- 柱状图/饼图动画：设计费1万 + 渠道费2万 + 信息差3万
- 剪映用 Shapes 做柱状图 + 关键帧动画逐条增长
- 每项增长时弹幕飘过对应评论

**10-20 秒（具体案例）：**
- 模拟报价单（Canva 做表格截图，导入剪映）
- 红圈逐个圈出：三万瓷砖 → 1.2万；全屋定制8万 → 不到3万
- 红圈 + 删除线动画（划掉虚高价，露出真实价）

**20-28 秒（态度句 + CTA）：**
- 态度句居中：你以为在买材料，其实在为信息差买单
- 弹幕层："刚装修完亏了5万""早看到就好了"
- 最后 0.5 秒纯色 + "你觉得你被坑了多少？"

**配色：** 背景 #1a1a2e（深紫蓝，与 Day 4 同但内容完全不同）

## 弹幕制作方法

剪映操作步骤：
1. 添加文字图层，内容填弹幕文字
2. 添加关键帧：从屏幕右侧外 → 移动到左侧外
3. 持续时间 2-3 秒
4. 透明度 80-90%
5. 颜色：白色/黄色/绿色/青色混用
6. 竖向位置错开（避免重叠）
7. 预制 10-15 条，复制粘贴错开时间

### 需要提前做的（一次性）

- [ ] 账号 Logo + 头像透明 PNG（用于截图点右上角）
- [ ] 启点品牌色板确认（深色背景三选一）
- [ ] 模拟房源截图（Canva 做，房产 APP 风格）
- [ ] 模拟装修报价单（Canva 做表格）
- [ ] 弹幕文字素材库（上面已有）

### 每条视频需要的

- [ ] 配音音频（gemini-tts-batch.py 生成）
- [ ] 航拍素材（仅 Day 6，Pexels 搜索 "aerial city"）
- [ ] 字幕（剪映自动识别后手动校对）

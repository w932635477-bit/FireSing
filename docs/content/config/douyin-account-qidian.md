# 启点 抖音账号设置方案

## 1. 基础资料

### 昵称（三选一）

| 方案 | 昵称 | 理由 |
|------|------|------|
| A | 启点·经验变现 | 直接点明价值，搜索友好 |
| B | 启点 | 品牌名本身足够简洁，后续可加副标题 |
| C | 启点·副业导航 | 偏副业向，覆盖面更广 |

**推荐方案A。** "经验变现"是目标用户最痛的点，且关键词搜索命中率高。

### 抖音号

建议用 `qidian_2026` 或 `qidian_jingyan`。简短好记，纯英文无特殊字符。

### 个人简介

```
帮40+中年人把行业经验变成收入
不是教你跳槽，是帮你把会的变成钱
经验≠过时，你的行业知识比你想的值钱
👇 免费测一测你的经验值多少钱
```

**要点：**
- 第一行说清做什么（定位）
- 第二行说不是什么（差异化）
- 第三行给信心（情绪价值）
- 第四行引流（行动号召）

### 所在地

选一个二线城市（如成都、武汉、长沙）。二线城市标签让内容更接地气，目标用户更多在三线及以下。

### 性别

男。40+男性是核心用户群，同性IP更容易建立信任。

### 行业分类

选「教育/知识付费」或「职场/创业」。

## 2. 头像方案

品牌账号头像需要专业感但不要太企业化。

**方案：** 深色背景 + 白色「启」字或「起点」首字母Q。

- 尺寸：400x400px，正方形
- 背景：深蓝 (#1a365d) 或深灰 (#2d3748)
- 字体：粗体无衬线，白色
- 不要用渐变、不要用emoji、不要用真人照片

如果你没有设计工具，告诉我，我可以用代码生成一个SVG头像。

## 3. 背景图

抖音主页顶部有一条背景图（1125x633px）。

**内容建议：**
- 左侧：品牌slogan "你的经验，比你想象的值钱"
- 右侧：一个简洁的路径图（发现→包装→渠道→收入）
- 配色和头像一致

## 4. 置顶视频（前3条必须准备好的）

置顶视频是用户点进主页后看到的第一印象。前3条决定用户是否关注。

### 视频1：账号宣言（15-20秒）

**脚本：**
```
你在这个行业干了十几年，
有人问你怎么选材料，你怎么避坑，
你随口就能答上来。

但是你没想过，这些经验可以卖钱。

我是启点，帮40+中年人把经验变成收入。
关注我，我教你把你会的变成钱。
```

**视觉：** 口播 + 大字标题字幕。背景干净（书架或纯色墙）。
**音乐：** 无，或极轻的背景白噪音。

### 视频2：案例故事（30-45秒）

**脚本（匿名化真实案例）：**
```
有个做建材的大哥，干了15年，
行业不行了，失业半年。

他来找我聊，我问他：
"买瓷砖你怎么帮客户省钱的？"
他说："同样的砖，建材城80一平，工程渠道只要30。"

我说：你把这个写成帖子，发闲鱼。

他发了。第一周就有人来问。
第一个月，光咨询费就收了500块。

500块不多，但他跟我说了一句话：
"我终于觉得我还有用。"

你的行业经验，比你想象的值钱。
关注我，我教你怎么变现。
```

**视觉：** 口播 + 关键数据字幕（15年、80→30、500元）。
**注意：** 用"有个大哥"代替真名，避免名人/真实身份。这是旧账号被封的血的教训。

### 视频3：干货清单（20-30秒）

**脚本：**
```
3个信号说明你的经验可以变现：

第一，有人经常免费问你行业问题
→ 说明你的知识有需求

第二，你能说出某个东西的底价或渠道
→ 说明你有信息差

第三，你帮朋友/客户避过坑省过钱
→ 说明你的经验有真实价值

3条全中的，你的经验至少值5000一个月。
关注启点，我教你一步步变现。
```

**视觉：** 1-2-3清单式，每条配大字字幕。

## 5. 内容支柱

所有内容围绕3个支柱，比例大约 4:3:3。

| 支柱 | 内容 | 目的 |
|------|------|------|
| A. 信心重建 | "你的经验比你想象的值钱"类内容，案例故事，正面激励 | 打破"我不行了"的心态 |
| B. 方法教学 | 具体怎么变现：怎么包装经验、怎么定价、怎么发第一条帖子 | 给可执行的行动指南 |
| C. 数据洞察 | 行业数据、副业收入数据、平台趋势 | 建立专业权威感 |

### 每周发布节奏

- 周一/三/五各发1条
- 每周至少1条口播 + 1条图文
- 初期以口播为主（制作成本低，信任感强）

## 6. 红线（必须遵守）

旧账号被罚4次的教训：

1. **不提任何名人名字。** 任正非、俞敏洪、马云、马斯克，全不提。讲案例一律用"一个做XX的大哥/大姐"。
2. **不引用未验证的数据。** 说"XX行业裁员6000人"之前必须有可查证的来源。没有来源就不说。
3. **不承诺收入结果。** 用"可能""有人做到了"，不用"保证""月入XX"。
4. **不搬运/不改编他人内容。** 所有内容原创。
5. **不碰敏感话题。** 不讨论政策、不评论企业、不聊裁员原因。

## 7. 引流路径

```
抖音视频 → 评论区/简介引导 →
  私信"变现" → 发启点H5链接 →
  用户完成免费阶段0评估 →
  付费用户进入阶段1-5
```

**评论区引导话术：**
- "想看看你的经验值多少钱？私信我发'变现'"
- "评论区打'经验'，我发你一份免费评估工具"

**不要在视频里直接放链接。** 抖音对导流管控严格，私信引导最安全。

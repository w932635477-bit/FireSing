## 一、Medvi 视频的底层逻辑

### 核心发现：不是数字人，是"氛围幻灯片"

Medvi 的广告视频不是 HeyGen/Synthesia 那种 AI 数字人口播。
实际做法是：**静态图片（AI 生成）→ Runway 图生视频 → AI 配音 → 字幕叠加**。

这意味着：
- 没有"说话的人"，只有"有氛围的图片在缓慢运动"
- 信息全部通过字幕 + 旁白传递
- 画面只是情感载体，不是信息载体
- 成本极低，批量生产极快

### Medvi 视频的 3 个核心格式

| 格式 | 占比 | 特征 | 目标 |
|------|------|------|------|
| "医生科普"幻灯片 | ~40% | 白大褂头像 + 医学术语字幕 + 温暖背景 | 建立专业权威 |
| "前后对比"展示 | ~30% | 左右分屏/上下翻页 + 数据标签 + 情感旁白 | 制造渴望 |
| "秘密揭露"钩子 | ~20% | 大字标题 + 暗色氛围 + 悬念音乐 | 激发好奇 |
| 直接 CTA | ~10% | 产品展示 + 价格 + 链接引导 | 直接转化 |

## 二、维度 1：播放时长结构分析

### Medvi 视频时长分布

| 时长区间 | 占比 | 适用格式 | 分析 |
|----------|------|----------|------|
| 15-30 秒 | 40% | 钩子/CTA | 快速曝光，追求完播率 |
| 30-45 秒 | 35% | 科普/对比 | 信息量最大的区间 |
| 45-60 秒 | 20% | 深度科普 | 完整故事线 |
| 60+ 秒 | 5% | 极少使用 | TikTok 算法不友好 |

### 完播率 vs 时长的关系

```
完播率:
15s  ████████████████████████  ~85-95%
30s  ████████████████████      ~70-80%
45s  ██████████████            ~50-65%
60s  ██████████                ~35-50%

关键阈值：30 秒是甜点。超过 30 秒，每多 1 秒流失约 2-3% 观众。
```

### 自用指南：时长策略

**黄金结构（30 秒版）：**
```
0-3s   钩子（必须在前 1.5 秒内出现核心信息）
3-8s   背景/上下文（一句话说清"这是什么"）
8-20s  核心内容（2-3 个关键数据点，每个 4 秒）
20-25s 方法暗示（不说透，留悬念）
25-30s CTA（明确的行动指令）
```

**扩展结构（45 秒版）：**
```
0-3s   钩子
3-8s   背景
8-25s  核心内容（4-5 个数据点）
25-35s 案例或对比
35-40s 方法暗示
40-45s CTA
```

**规则：**
- 前 3 秒决定 80% 的数据表现
- 每 3-5 秒必须有一个新的视觉或信息刺激
- 最后 5 秒的 CTA 必须重复关键信息
- 总时长控制在 30-45 秒，不超过 60 秒

## 三、维度 2：跳出率（前 3 秒生死线）

### Medvi 的前 3 秒策略

Medvi 的 5000+ 广告全部使用以下钩子模式之一：

**模式 A：反常识数字（最有效）**
```
画面：暗色背景 + 巨大数字
字幕："你可能不需要运动就能瘦"
旁白：1 秒内出声
```

**模式 B：身份筛选**
```
画面：特定人群的画面
字幕："如果你 BMI 超过 30，这个视频是给你的"
旁白：直接点名目标人群
```

**模式 C：秘密/阴谋**
```
画面：快速切换的暗色画面
字幕："减肥行业不想让你知道的真相"
旁白：低沉、神秘感
```

**模式 D：好奇缺口**
```
画面：模糊或部分遮挡的关键信息
字幕："99% 的人不知道这个方法"
旁白：引导继续看下去
```

### 跳出率数据推算

基于 TikTok/抖音算法和行业数据：

| 钩子类型 | 3 秒留存率 | 跳出原因 |
|----------|-----------|----------|
| 反常识数字 | 65-75% | 最高，数字冲击力强 |
| 身份筛选 | 55-65% | 筛选精准但非目标人群直接划走 |
| 秘密/阴谋 | 50-60% | 吸引好奇心但容易被认为是标题党 |
| 好奇缺口 | 45-55% | 效果最不稳定，取决于执行质量 |

### 自用指南：前 3 秒设计

**自用钩子模板（测试优先级排序）：**

| 优先级 | 钩子 | 适用格式 | 示例 |
|--------|------|----------|------|
| 1 | 反常识数字 | 数据震撼 | "2 个人，103 美元月费，4 亿营收" |
| 2 | 成本对比 | 对比冲击 | "10 人团队月花 5 万 vs 1 人月花 750" |
| 3 | 好奇缺口 | 方法论 | "这个方法 99% 的营销团队不知道" |
| 4 | 身份筛选 | 实操 | "如果你每个月花超过 1 万做内容推广" |

**执行规则：**
- 第 1 帧必须是文字（不是画面渐入）
- 文字字号 ≥ 屏幕宽度的 60%
- 旁白必须在 0.5 秒内出声（不能有黑屏 + 音乐前奏）
- 视频不要从黑色渐入，直接切入画面

## 四、维度 3：景别分析（远景/中景/近景）

### Medvi 视频的景别使用规律

Medvi 的视频不是传统影视的景别调度，而是**信息密度驱动的景别切换**：

| 景别 | 在 Medvi 视频中的使用 | 画面内容 | 占比 |
|------|---------------------|----------|------|
| 远景/全景 | 开场/转场 | 建筑、城市、科技场景 | ~15% |
| 中景 | 主体展示 | "医生"半身照、产品展示、工作场景 | ~45% |
| 近景/特写 | 数据/情感 | 数字特写、面部表情、手部动作 | ~30% |
| 纯文字/图表 | 信息传递 | 全屏字幕、数据图表、对比表 | ~10% |

### 景别节奏模式

```
典型 30 秒视频的景别节奏：

远景(2s) → 中景(4s) → 特写(3s) → 中景(4s) →
特写(3s) → 中景(5s) → 远景(2s) → 纯文字(3s) → 中景(4s)

规律：
- 开头用远景/中景建立环境
- 关键数据用特写放大
- 情感高潮用面部特写
- 每次景别切换 = 新的信息点
- 避免连续相同景别超过 5 秒
```

### 自用指南：景别设计原则

**每个分镜镜头的景别定义：**

```
远景/全景（Wide Shot）：
- 用途：开场建立场景、转场、结尾开阔感
- Runway 提示：slow pan, wide angle, establishing shot, cinematic
- 情绪：宏大、客观、冷静

中景（Medium Shot）：
- 用途：展示人物/产品/工作场景
- Runway 提示：medium shot, natural framing, documentary style
- 情绪：自然、亲近、日常

近景/特写（Close-up）：
- 用途：放大关键数据、情感连接、制造紧迫感
- Runway 提示：extreme close-up, shallow depth of field, intimate
- 情绪：紧迫、聚焦、亲密

纯文字（Text Overlay）：
- 用途：数据展示、对比、CTA
- 制作：剪映/FFmpeg 直接叠加
- 情绪：冷静、权威、清晰
```

**景别切换的"3 秒规则"：**
- 每个景别保持 3-5 秒
- 连续相同景别不超过 5 秒（否则观众视觉疲劳）
- 景别切换间隔 = 新信息点的引入
- 在关键数据前后，使用景别对比（远景→特写）制造视觉冲击

## 五、维度 4：AI 生成质量把控

### Medvi 被发现的 AI 破绽

以下是 Medvi 视频中暴露的 AI 生成质量问题（来自 BI/Futurism 调查）：

| 破绽类型 | 具体表现 | 出现频率 |
|----------|----------|----------|
| 手部生成错误 | 手指数量异常、关节扭曲 | 高（Midjourney 通病） |
| 文字乱码 | 药品包装上的字母扭曲、拼写错误 | 高（AI 不擅长文字渲染） |
| 头像重复 | 同一头像被 3+ 个不同"医生"使用 | 中 |
| 面部不自然 | 光滑过度、耳朵与头部融合 | 中 |
| 水印残留 | Gemini 水印出现在部分图像上 | 低（但在专业审查下致命） |

### Medvi 的质量控制失误总结

1. **批量生产时不做逐张检查**：800 个账号 = 数千张图，AI 生成的瑕疵混在其中
2. **没有统一风格规范**：不同工具（Midjourney/Gemini）生成的图片风格不一致
3. **文字渲染盲区**：AI 生成的产品包装/文件上的文字是乱码，但在小屏幕上不明显
4. **过度依赖单一工具**：头像重复是因为同一套 Midjourney seed 生成的变体太少

### 自用指南：AI 生成质量控制清单

**Step 1：参考图质量控制（Midjourney）**

```
检查项（每张图必须通过）：
□ 手部是否完整正确？如果有手部，重新生成或裁掉
□ 文字是否可读？如果图片中有文字，检查拼写
□ 面部是否自然？注意眼睛对焦、耳朵连接、牙齿
□ 光影是否一致？同一分镜内的多张图光影方向要一致
□ 风格是否统一？同一条视频的所有图片必须是同一风格
□ 分辨率是否足够？至少 1280x720，推荐 1920x1080
```

**Step 2：Runway 视频生成质量控制**

```
检查项（每段视频必须通过）：
□ 运动是否自然？不能有突然的物体变形或闪烁
□ 画面是否稳定？不能有明显抖动（除非是设计意图）
□ 细节是否保持？人脸/文字在运动中是否保持清晰
□ 5 秒内是否有明显 AI 瑕疵？如果有，重新生成
□ 首帧和末帧是否可用？拼接时首尾帧质量最关键
```

**Step 3：配音质量控制（MiniMax/ElevenLabs）**

```
检查项（每段配音必须通过）：
□ 发音是否准确？特别是数字、专业术语
□ 语速是否合适？30 秒视频旁白约 120-150 字
□ 停顿是否自然？关键数字前后需要停顿
□ 情感是否匹配？数据型冷静、对比型有张力
□ 音质是否干净？不能有 AI 配音常见的金属感
```

**Step 4：最终合成质量控制**

```
检查项（每条视频必须通过）：
□ 所有字幕是否可读？字号、颜色、描边
□ 音画是否同步？旁白和画面切换是否对齐
□ 整体节奏是否紧凑？有没有超过 2 秒的"空洞"段落
□ 去AI味后期是否到位？颗粒感、暗角、色彩
□ 在手机上预览效果？电脑上看 OK 但手机可能太小
```

### "去 AI 塑料味" 4 步法

这是从 Medvi 的教训 + Day 1 视频制作经验中总结的：

```
Step 1：先定电影级参考图（决定质感上限）
  → 在 Midjourney 中用 --style raw --ar 9:16 参数
  → 找到满意的参考图后再批量生成

Step 2：做分镜（明确情绪和镜头语言）
  → 每个镜头定义：景别 + 情绪 + 运动方式
  → 不要靠提示词随机生成

Step 3：画面驱动生成，不是堆提示词
  → 用图生视频（img2vid），不是纯文生视频
  → 控制运动幅度，宁小勿大

Step 4：后期加颗粒 + 光晕（10% 的工作决定 90% 的真实感）
  → FFmpeg: noise=c0s=12, vignette=0.3, contrast=1.08, saturation=0.92
  → 这步让 AI 生成画面从"塑料感"变成"胶片感"
```

## 六、维度 5：脚本写作分析

### Medvi 脚本的固定模板

Medvi 使用的是高度标准化的脚本模板（NYT 报道原文："每项业务动作都是一个 workflow 和 prompt"）：

**模板结构（4 段式）：**

```
第 1 段：问题引入（3-5 秒）
  - 一个反常识的陈述或一个令人震惊的数据
  - "你可能不是胖，是你的荷尔蒙出了问题"

第 2 段：科学解释（8-15 秒）
  - 用 2-3 个数据点解释"为什么"
  - "GLP-1 受体激动剂能帮你控制食欲"

第 3 段：方案推荐（5-10 秒）
  - 不说透，暗示有一个解决方案
  - "现在有一种新的方法，不需要节食和运动"

第 4 段：行动号召（3-5 秒）
  - 低摩擦行动引导
  - "点击链接免费评估"
```

### 脚本信息密度标准

```
密度标准（每 3 秒一个刺激点）：

3 秒 = 1 个数据点 + 1 个画面切换
10 秒 = 3 个数据点 + 3 次画面切换
30 秒 = 8-10 个数据点 + 8-10 次画面切换

关键：不要连续 5 秒没有新信息。
观众注意力阈值 = 3-5 秒。超过 5 秒没有新刺激 = 划走。
```

### 自用指南：脚本写作 SOP

**数据震撼型脚本模板（30 秒版）：**

```
[S01 - 钩子 3s]
画面：暗色背景 + 金色大数字
字幕："2个人，103美元月费"
旁白："一个人，2万美元启动资金，14个月做到4亿美元营收。"

[S02 - 背景 3s]
画面：城市远景 → 中景
字幕："团队只有2个人"
旁白："团队只有2个人。"

[S03 - 人物 5s]
画面：中景 → 人物特写
字幕："Matthew Gallagher，拖车公园长大"
旁白："这个人叫Matthew Gallagher，在拖车公园长大，用叔叔送的笔记本电脑自学编程。"

[S04 - 核心数据 8s]
画面：数据图表特写
字幕："营收4.01亿，净利6500万，净利率16.2%"
旁白："2025年，营收4.01亿美元，净利润6500万，净利率16.2%。"

[S05 - 对比 5s]
画面：左右分屏对比
字幕："2400人团队 vs 2人团队"
旁白："行业巨头有2400多名员工，净利率才5.5%。他用2个人，跑了同行3倍的利润率。"

[S06 - CTA 6s]
画面：工具截图
字幕："私信 AI获客"
旁白："这整套工具链，国内都有免费替代。私信AI获客，我发你完整工具清单。"
```

**脚本写作的 5 条硬规则：**

1. **每句旁白 ≤ 15 字**：长句在短视频中让人走神
2. **数字必须出现在字幕中**：观众 60% 的时间在看字幕，不是在听旁白
3. **不使用"今天就教大家"之类的套话**：直接给信息
4. **CTA 不要超过 2 个动作**：只要求"关注"或"私信"其中一个
5. **总字数控制**：30 秒视频旁白 100-130 字，45 秒 150-200 字

## 七、维度 6：视频生成（Runway）参数分析

### Medvi 的 Runway 使用方式

从素材分析推断的使用参数：

| 参数 | Medvi 可能设置 | 原因 |
|------|---------------|------|
| 模式 | Image-to-Video | 从静态图生成，不是纯文生 |
| 分辨率 | 720x1280 (9:16) | TikTok/Reels 竖屏格式 |
| 时长 | 5 秒/段 | Runway 标准长度 |
| Camera Pan | 缓慢平移/推进 | 不分散注意力 |
| Motion | 低-中 | 保持画面稳定，避免变形 |
| 风格 | 一致性 > 创意性 | 所有片段必须风格统一 |

### 自用指南：Runway 参数模板

**标准参数（适用于 80% 的镜头）：**

```
模式: gen4_turbo（Runway Gen-4 Turbo）
分辨率: 720x1280
时长: 5 秒
Credits: 25/clip

Camera Control:
  Pan:   缓慢左→右 或 右→左（不要快速移动）
  Tilt:  微幅上→下（建立感）或下→上（压迫感）
  Zoom:  缓慢推进（制造聚焦感）
  Roll:  0（不要旋转）

Motion:
  强度: 3-5/10（宁低勿高，低 = 更稳定）
  Motion Brush: 只用在需要运动的元素上

Style:
  参考: 统一使用同一个参考图风格
  一致性: 同一条视频的所有片段用相同的风格参数
```

**场景类型对应的 Camera 参数：**

```
数据震撼型：
  Zoom: 缓慢推进 (2-3/10)
  Pan:  无或极缓慢
  效果: 信息聚焦，不分散注意力

对比冲击型：
  Pan:  左→右 或 上→下（配合对比内容）
  Zoom: 无
  效果: 视觉"翻页"感

实操演示型：
  不使用 Runway（使用录屏素材）
  效果: 真实工具操作画面

方法论拆解型：
  Zoom: 极缓慢推进
  Tilt: 微幅上下
  效果: 稳定的"阅读"节奏
```

**Runway 生成的质量底线：**

- 如果 5 秒内出现明显变形/闪烁 → 重新生成（不要将就）
- 每个镜头生成 3 个候选，选最好的
- 生成前先测试 Camera 参数：用一张图生成 3 段不同参数，选最佳
- 风格一致性检查：所有片段放在同一时间线上预览，检查风格跳跃

## 八、维度 7：配音分析

### Medvi 的配音策略

Medvi 使用 ElevenLabs，为不同"医生"使用不同的声音。关键特征：

| 特征 | Medvi 做法 | 效果 |
|------|-----------|------|
| 声音类型 | 男性 + 女性混合，偏中年 | 建立专业感 |
| 语速 | 中等偏快 | 信息密度高，不停顿 |
| 音调 | 平稳，数据部分略降 | 冷静、可信 |
| 停顿 | 关键数据前短暂停顿 | 强调数字 |
| BGM | 极低音量（几乎听不到） | 纯氛围，不干扰 |
| 音效 | 几乎没有 | 干净、专业 |

### 自用指南：配音参数 SOP

**MiniMax Speech-02 HD 参数模板：**

```
模型: speech-02-hd
声音: male-qn-jingying（精英男声）
语速: 1.05（比正常稍快）
采样率: 24000

按脚本类型调整：
  数据震撼型: speed=1.05, 停顿标记 <#0.3#>
  对比冲击型: speed=1.0,  对比点加 <#0.4#> 停顿
  实操演示型: speed=0.95, 步骤间 <#0.5#> 停顿
  方法论型:   speed=1.05, 节奏感强
```

**配音脚本中的停顿标记规范：**

```
<#0.2#> = 短停顿（句子内部分隔）
<#0.3#> = 中停顿（关键数字前后）
<#0.4#> = 长停顿（段落切换）
<#0.5#> = 超长停顿（章节转换）

示例：
"一个人<#0.2#>2万美元启动资金<#0.3#>14个月做到4亿美元营收<#0.4#>团队只有2个人"
```

**配音质量控制 3 条线：**

1. **可懂度线**：每个字都能听清。如果有含糊不清的词 → 重新生成
2. **情感线**：语调匹配内容。数据不能激动，对比要有张力，CTA 要坚定
3. **节奏线**：每 3-5 秒有一个节奏变化（快→慢、高→低、连续→停顿）

## 九、每个关键把控点的汇总清单

### 从脚本到成片：7 个关键把控点

```
把控点 1：脚本信息密度
  □ 每 3 秒是否有新信息？
  □ 钩子是否在前 1.5 秒内出现？
  □ CTA 是否清晰且只有一个动作？
  □ 总字数是否在 100-200 字范围内？
  检查人：自己（写完后大声朗读一遍计时）

把控点 2：参考图风格一致性
  □ 所有图片是否同一风格？
  □ 光影方向是否一致？
  □ 是否有手部/文字/面部瑕疵？
  □ 分辨率是否 ≥ 1280x720？
  检查人：自己（放在同一画布上对比）

把控点 3：Runway 视频生成质量
  □ 5 秒内是否有变形/闪烁？
  □ 运动是否自然且不过度？
  □ 风格是否和参考图一致？
  □ 首帧末帧是否可用？
  检查人：逐段回放，至少看 3 遍

把控点 4：配音质量
  □ 每个字都能听清？
  □ 停顿位置是否自然？
  □ 情感是否匹配内容类型？
  □ 语速是否合适（30s ≈ 120-150 字）？
  检查人：闭眼只听音频，不看画面

把控点 5：音画同步
  □ 旁白和画面切换是否对齐？
  □ 字幕出现时间和旁白是否同步？
  □ 数据特写是否和旁白中的数字对齐？
  检查人：逐段检查，用时间码标注

把控点 6：去 AI 味后期
  □ 颗粒感是否自然（不过重也不过轻）？
  □ 暗角是否增强了聚焦感？
  □ 对比度和饱和度是否让画面更"胶片"？
  □ 在手机上预览效果是否 OK？
  检查参数：noise=c0s=12, contrast=1.08, saturation=0.92, vignette=0.3

把控点 7：最终质量门控
  □ 在手机上全屏播放，是否看起来专业？
  □ 字幕在手机尺寸下是否可读？
  □ 整体节奏是否有超过 2 秒的"空洞"？
  □ 是否有明显的 AI 生成痕迹（手/文字/光影）？
  □ CTA 是否在最后 5 秒内重复？
  检查人：发到手机上看（不是电脑上看）
```

## 十、转化为自用视频生产系统

### 自用视频生产的完整 SOP

```
Phase 1：选题 + 脚本（15 分钟）
  1. 从内容日历中选一个主题
  2. 用脚本模板生成脚本（ChatGPT/Claude）
  3. 标注每个镜头的：景别、情绪、运动方式
  4. 大声朗读计时，控制在 30-45 秒

Phase 2：参考图生成（10 分钟）
  1. 确定统一的视觉风格参数
  2. 为每个镜头生成 2-3 张候选参考图
  3. 质量检查（手部、文字、面部、光影）
  4. 选定最佳候选

Phase 3：Runway 视频生成（15 分钟）
  1. 每张参考图生成 5 秒视频
  2. 每个镜头生成 3 个候选
  3. 质量检查（变形、闪烁、风格一致性）
  4. 选定最佳候选

Phase 4：配音生成（5 分钟）
  1. 脚本中加入停顿标记
  2. MiniMax/ElevenLabs 生成配音
  3. 质量检查（可懂度、情感、节奏）
  4. 如不合格，调整参数重新生成

Phase 5：FFmpeg 合成（5 分钟）
  1. 运行 ffmpeg-compose 脚本
  2. 视频片段按顺序拼接
  3. 合并配音
  4. 应用后期滤镜（颗粒/暗角/对比度）

Phase 6：剪映精修（10 分钟）
  1. 添加字幕（大号、白色/金色、黑底描边）
  2. 添加 BGM（8-12% 音量）
  3. 检查音画同步
  4. 替换标题卡/CTA 卡
  5. 导出

Phase 7：最终检查（5 分钟）
  1. 手机预览
  2. 检查所有 7 个把控点
  3. 如有问题，回退到对应 Phase 修改
  4. 通过 → 发布

总耗时：~65 分钟/条（熟练后可压缩到 45 分钟）
日产能：3-4 条/天
```

### 批量生产模式

```
Day A（准备日）：一次性准备 5 条视频的素材
  - 写 5 条脚本（75 分钟）
  - 生成所有参考图（50 分钟）
  - Runway 批量生成视频（75 分钟）
  - 配音批量生成（25 分钟）

Day B（制作日）：合成 + 精修 5 条视频
  - FFmpeg 合成 5 条（25 分钟）
  - 剪映精修 5 条（50 分钟）
  - 最终检查 5 条（25 分钟）

总投入：2 天，约 325 分钟 → 产出 5 条成品
平均：65 分钟/条，可以一周产出 15-20 条
```

## 十一、与 Day 1 视频的对标分析

### Day 1 视频 vs 标准：差距分析

Day 1 视频（`day1-rough-cut-v2.mp4`，63 秒）对比上述标准：

| 维度 | Day 1 现状 | 标准要求 | 差距 |
|------|-----------|----------|------|
| 时长 | 63 秒 | 30-45 秒 | 太长，需要压缩到 45 秒以内 |
| 分镜数 | 10 段 | 6-8 段 | 段落太多，每段平均 6.3 秒 |
| 前三秒钩子 | 有（数字钩子） | 前 1.5 秒出核心信息 | OK |
| 景别变化 | 较少（主要是中景） | 每 3-5 秒切换景别 | 需要增加远景和特写 |
| 字幕 | 未添加 | 大号、金色高亮 | 需要在剪映中添加 |
| 配音 | MiniMax，质量 OK | 语速 1.05，停顿自然 | OK |
| 去 AI 味 | FFmpeg 后期已应用 | noise=12, vignette=0.3 | OK |
| BGM | 未添加 | 8-12% 音量 | 需要在剪映中添加 |
| CTA | 有（"私信 AI获客"） | 最后 5 秒重复 | OK |

### Day 1 视频优化建议

1. **压缩到 45 秒**：合并 S02(1.1s) + S03(5.8s) 为一段，合并 S07(3.5s) + S09(2.8s) 为一段
2. **增加景别变化**：在关键数据点（S05）使用特写镜头替换中景
3. **添加字幕**：所有数据必须出现在字幕中，金色高亮
4. **添加 BGM**：低音量氛围音乐，不能盖过旁白

## 情绪曲线

```
震撼 → 孤独 → 平静 → 专注 → 震撼 → 对比 → 冲击 → 节奏 → 高潮 → 温暖
高          低              高              高          高      低
```

两头高、中间有节奏变化，避免一路平。

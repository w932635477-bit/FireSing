# 去AI味工作流备忘

> 来源：抖音创作者分享（2026-04-17）
> 核心方法：4 步去除 AI 塑料感

## 4 步法

1. **先定电影级参考图**（决定质感上限）
   - 不要一上来就生成视频
   - 先找/生成高质量的参考图
   - 参考图的质感 = 视频质感的天花板

2. **做分镜**（明确情绪和镜头语言）
   - 每个镜头要有明确的情绪目标
   - 镜头之间要有节奏变化
   - 不要一路平到底

3. **画面驱动生成，不是堆提示词**
   - 用参考图驱动 Runway 生成
   - 提示词只写运动描述（slow pan, zoom in）
   - 不要写长篇画面描述

4. **后期加颗粒 + 光晕**（点睛之笔）
   - 这 10% 决定了"像AI"还是"像真实拍摄"
   - 胶片颗粒：强度 15-20%
   - 柔光/光晕：强度 10-15%
   - 饱和度降低：-5~-10%

## 为什么有效

AI 生成的视频有几个特征：
- 过于干净（没有噪点）
- 过于锐利（边缘太清晰）
- 过于饱和（颜色太鲜艳）
- 运动太流畅（没有手持的微小抖动）

4 步法逐一解决这些问题。

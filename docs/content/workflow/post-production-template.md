# 去AI味后期模板

> 4 步去除 AI 塑料感 + Gen-4 特有优化
> 工具：剪映（Mac/手机版均可）+ Runway Retime
> 这 10% 的后期决定了"像AI"还是"像真实拍摄"
> 最后更新：2026-04-17

---

## 第 0 步：Runway 端预处理（导入剪映前）

在 Runway 里先做这些，减少剪映工作量：

1. **4K Upscale**：选中的片段一键升 4K（最终质量）
2. **Retime → Handheld Shake**：强度 10-15%（Runway 内置比剪映更自然）
3. **Retime → Trim**：裁掉开头/结尾不稳定的 3-5 帧
4. **Retime → Speed**：如需变速，在 Runway 里先调好

> 导出后再导入剪映，此时已经有手持抖动 + 高分辨率。

---

## 第 1 步：胶片颗粒

打破 AI 生成的"过于干净"质感。

### 剪映操作

1. 选中所有视频片段（全选）
2. 点击「滤镜」→「质感」→「胶片」
3. 选择「柯达」或「富士」预设
4. 调整参数：

| 参数 | 推荐值 | 范围 |
|------|--------|------|
| 强度 | 15-20% | 太高会糊 |
| 颗粒大小 | 1-2px | 不要太粗 |
| 色偏 | 关闭 | 不需要 |

### 备选方案

如果剪映预设不合适，用「调节」手动：
- 对比度 +5~10
- 饱和度 -5~-10
- 高光 -5

---

## 第 2 步：光晕/辉光

模拟真实镜头的光线散射。

### 剪映操作

1. 选中所有片段
2. 点击「特效」→「光效」
3. 选择「柔光」或「镜头光晕」
4. 调整参数：

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 强度 | 10-15% | 若隐若现 |
| 范围 | 中等 | 不要全覆盖 |
| 位置 | 跟随光源方向 | 画面亮处 |

### 关键原则

光晕应该"看得到但说不出"，用户不会意识到有光晕，但会觉得画面更柔和。

---

## 第 3 步：色彩校正

统一所有镜头色调，消除 AI 的过饱和。

### 剪映操作

1. 逐个选中片段
2. 点击「调节」
3. 参数：

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 亮度 | 0~-5 | AI 视频偏亮 |
| 对比度 | +5~+10 | 增加层次感 |
| 饱和度 | -5~-10 | **最重要**，AI 总是过饱和 |
| 色温 | 按需微调 | 统一到暖色调 |
| 锐度 | -3~-5 | AI 视频过于锐利 |

### LUT 推荐（如有）

| LUT 名称 | 风格 | 适合 |
|----------|------|------|
| Kodak 2383 | 电影胶片 | 纪录片风格 |
| Rec.709 to P3 | 自然色彩 | 商业内容 |
| Kodachrome | 怀旧暖色 | 故事类内容 |

---

## 第 4 步：手持抖动（已在 Runway 完成）

> 如果在 Runway Retime 里已加了 Handheld Shake，**跳过此步**。

如果没在 Runway 里加：

1. 全选片段
2. 「特效」→「画面特效」→「抖动」
3. 选择最轻微的选项
4. 强度：3-5%

---

## 最终检查清单

对成片做最终检查：

### 视觉检查
- [ ] 关掉声音看一遍：画面是否自然？
- [ ] 截取任意一帧：能否看出是 AI 生成的？
- [ ] 色调是否统一？
- [ ] 颗粒是否过度？
- [ ] 手持抖动是否自然不突兀？

### 听觉检查
- [ ] 配音是否自然？
- [ ] BGM 是否合适？
- [ ] 音量平衡是否正确？

### 内容检查
- [ ] 所有数字是否正确？
- [ ] 字幕是否和配音一致？
- [ ] 转化引导是否清晰？

---

## 导出设置

| 参数 | 推荐值 |
|------|--------|
| 分辨率 | 1080x1920（9:16 竖版） |
| 帧率 | 24fps（匹配 Runway 输出） |
| 码率 | 高品质 |
| 格式 | MP4 |

> 如果 Runway 已做 4K upscale，剪映项目设为 1080x1920 导出即可（4K 源 → 1080 输出 = 超采样，画质更好）。

### 封面帧

- 从视频中选最有冲击力的一帧
- 或用 Canva 单独制作
- 要求：大数字 + 简洁文字 + 黑底金字

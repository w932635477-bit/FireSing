# 视频生产起飞检查清单（Pre-flight Checklist）

> 每次执行视频工作流前必读。从 video-production-spec.md 和 medvi-analysis.md 提取的核心规则。
> 最后更新：2026-04-18

---

## 一、脚本阶段（Stage 1）核心规则

- [ ] **总时长 30-45 秒**，超过 45 秒 = 拒绝
- [ ] **旁白字数**：30s → 100-130 字，45s → 150-200 字
- [ ] **每句 ≤ 15 个中文字**，超过就断句
- [ ] **至少 3 个具体数字**
- [ ] **钩子 = 前 3 秒**，必须在 1.5 秒内出现核心信息
- [ ] **Hook 类型**（4 选 1）：反常识数字 > 成本对比 > 好奇缺口 > 身份筛选
- [ ] **CTA = 最后 5 秒**，只有一个动作
- [ ] **禁用套话**："今天就教大家"、"大家好我是XX"
- [ ] **大声朗读计时**验证时长

## 二、参考图阶段（Stage 2）核心规则

- [ ] **9:16 竖版**，1440x2560（Seedream API）
- [ ] **提示词后缀**：`vertical composition 9:16`
- [ ] **风格统一**：深色调 + 暖金色 + 电影纪录片感
- [ ] **画面中无手部**（AI 生成有缺陷）
- [ ] **画面中无文字**（AI 文字一定是乱码）
- [ ] **6 张图构成情感弧线**：共情 → 向往 → 希望 → 震撼 → 对比 → 信任
- [ ] **图片是情绪壁纸，不是故事插图**
- [ ] **每张 prompt 包含去AI质感指令**（至少 3 条）
- [ ] **200px 宽度检验**：辨识度元素在手机缩略图下仍可识别

## 三、视频生成阶段（Stage 3）核心规则

- [ ] **只使用 Image-to-Video**，不用纯文生视频
- [ ] **提示词只写运动**，不重复描述画面内容
- [ ] **720x1280，24fps，5 秒/段**
- [ ] **运动强度 3-5/10**，宁低勿高
- [ ] **Fixed Seed 开启**，全片统一
- [ ] **每段 ≥ 3 个候选**，选最佳
- [ ] **后处理**：Trim + Handheld Shake 10-15% + 4K Upscale
- [ ] **拒收标准**：变形、闪烁、物体扭曲 = 重新生成

## 四、配音阶段（Stage 4）核心规则

- [ ] **引擎**：Gemini 3.1 Flash TTS（不是 MiniMax / Fish Audio）
- [ ] **3 遍听测**：连听 3 遍不觉得机械感
- [ ] **停顿标记**：`<#0.2#>` 短停顿，`<#0.3#>` 关键数字前，`<#0.4#>` 段落切换
- [ ] **每段用同一个 narrator profile**，只改 Director's Notes

## 五、合成阶段（Stage 5）核心规则

**FFmpeg 只做一件事：拼接视频片段 + 合并配音音频。秒级完成。**
- [ ] 视频片段按脚本顺序硬切拼接
- [ ] 配音音轨合并到视频
- [ ] 不做任何视觉处理（滤镜、字幕、叠加全部留给剪映）

**剪映做所有视觉工作：**
- [ ] 字幕（大号、白色/金色、黑底描边）
- [ ] BGM（音量 8-12%）
- [ ] 文字卡片
- [ ] 照片叠加
- [ ] 去AI 4 步滤镜
- [ ] AI标识水印（前 3 秒）
- [ ] 色彩校正

## 六、去AI后期阶段（Stage 6）剪映 4 步法

> 全部在剪映里完成。FFmpeg 不做任何视觉处理。

| 步骤 | 剪映操作 | 参数 |
|------|---------|------|
| 胶片颗粒 | 滤镜 → 质感 → 胶片 | 强度 15-20% |
| 镜头光晕 | 特效 → 光效 → 柔光 | 强度 10-15% |
| 色彩校正 | 调节 → 对比度/饱和度/色温 | 对比+8%, 饱和-8%, 色温统一 |
| 手持抖动 | 如 Runway 未做：特效 → 扭曲 → 微抖 | 强度 3-5% |

## 七、AI 内容标识（法规强制，2025-09-01 生效）

**每条视频必须满足以下 3 项：**

- [ ] **显性标识**：剪映里在视频开头添加 "AI生成内容" 文字贴纸，持续 ≥ 3 秒
- [ ] **隐性标识**：导出后用 FFmpeg 一条命令写入元数据（见下方）
- [ ] **发布声明**：在平台发布界面勾选 "AI生成内容"

**隐性标识命令（导出后执行一次，3 秒完成）：**
```bash
ffmpeg -i output.mp4 -metadata comment="本视频由AI生成合成，包含AI生成的图像和配音" -c copy output_labeled.mp4
```

> 不合规 = 限流/下架/封号。`-c copy` 不重编码，秒级完成。

## 八、平台合规检查

**抖音（所有视频）：**
- [ ] 无虚假宣传和效果承诺
- [ ] 无违反社区准则内容
- [ ] CTA 使用批准的模板

**抖音（涉及健康/减肥话题时额外检查）：**
- [ ] 发布者须为认证医疗专业人员
- [ ] 无具体疗效承诺
- [ ] 无暗示医疗建议
- [ ] 添加 "仅供参考，不构成医疗建议" 免责声明

**小红书：**
- [ ] 禁止虚假 Before/After 对比图
- [ ] 禁止夸大效果宣传
- [ ] 标注 AI 生成内容

## 九、景别切换节奏

```
远景(3s) → 中景(4s) → 特写(3s) → 中景(4s) →
特写(3s) → 中景(5s) → 远景(2s) → 文字卡片(3s) → 中景(4s)
```

- 每条视频 **6-8 个镜头**
- 单镜头 **不超过 5 秒**
- 至少 **2 种景别**（远景/中景/特写/文字卡片）
- 连续相同景别 **不超过 2 个**

## 十、字幕样式

- 白色文字 (#FFFFFF)，黑色描边 (2-3px)，字号 ≥ 36pt
- **关键数字用金色 (#c9a96e) 加粗**，1.5 倍常规字号
- 字幕位置底部居中，留出平台 UI 安全区
- 100% 旁白文字有对应字幕

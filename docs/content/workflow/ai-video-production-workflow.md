# AI 视频生成工作流（完整版）— Medvi 工作流（旧版）

> 工作流类型：**Medvi**（电影纪录片风格商业内容，旁白驱动）
> 本文档已被 video-production-spec.md 取代，保留作为参考
> 去AI塑料味 4 步法 + 批量生产流程
> 工具链：Runway Gen-4 + ElevenLabs + Seedream 4.5 + 剪映
> 最后更新：2026-04-17

---

## 总览

```
脚本 → 分镜表 → 参考图 → 图生视频 → 配音 → 合成 → 去AI味后期 → 成片
```

每条视频预计耗时：30-45 分钟（熟练后可压到 20 分钟）

---

## Step 1: 脚本

**输入**：选题想法
**输出**：完整视频脚本（45-60 秒）
**工具**：DeepSeek / ChatGPT

脚本格式：
- 钩子（3-5 秒）— 反差数字或冲突
- 主体（30-40 秒）— 信息密度高
- 转化（5-10 秒）— 引导关注/私信

**质量检查**：
- [ ] 旁白字数 ≤ 180 字（45 秒约 150 字，55 秒约 180 字）
- [ ] 至少 3 个关键数字
- [ ] 有明确的转化引导

---

## Step 2: 分镜表

**输入**：视频脚本
**输出**：8-12 个镜头的分镜表
**工具**：本文档模板

每个镜头定义：

| 字段 | 说明 |
|------|------|
| 编号 | S01, S02, ... |
| 时长 | 秒数 |
| 旁白 | 该镜头对应的旁白文字 |
| 画面描述 | 具体场景、人物、物品 |
| 情绪/氛围 | 紧张/平静/震撼/温暖 |
| 运动方式 | 推/拉/摇/移/固定 |
| 参考图关键词 | 用于生成参考图的英文关键词 |

**质量检查**：
- [ ] 镜头总时长 = 脚本目标时长 ± 3 秒
- [ ] 相邻镜头情绪有变化（避免平淡）
- [ ] 至少 2 个运动镜头

---

## Step 3: 参考图

**输入**：分镜表的关键词
**输出**：每个镜头 1 张参考图（共 8-12 张）
**工具**：Seedream 4.5（EvoLink API，$0.030/张）

**这是最关键的一步** — 参考图决定视频的质感上限。

### Seedream 4.5 批量生成

```bash
# 批量生成所有参考图（每镜头 2 张候选）
export EVOLINK_API_KEY="your-key"
python docs/content/scripts/seedream-batch.py --candidates 2

# 只生成单个镜头
python docs/content/scripts/seedream-batch.py --shot S01

# 预览模式（不实际生成）
python docs/content/scripts/seedream-batch.py --dry-run
```

### 提示词模板

```
[画面内容], [光影描述], [构图], [色调], [摄影风格/镜头], vertical composition 9:16
```

### 风格一致性规则

所有参考图统一：
- **色调**：深色调为主，金色/暖色点缀（和 PDF 品牌色一致）
- **风格**：电影级质感、纪录片风格
- **画面比**：**9:16 竖版**（Runway Gen-4 原生支持，无需裁剪）
- **构图**：主体居中偏下，上方留空间给运动和字幕
- **后缀**：提示词末尾加 `vertical composition 9:16`
- **API 尺寸**：`1440x2560`（9:16 2K）

### 操作步骤

1. 为每个镜头生成 2-3 张候选
2. 选出风格最统一的一组
3. 确保色调、光影、构图连贯
4. 导出高分辨率版本

**质量检查**：
- [ ] 所有参考图色调统一
- [ ] 人物/场景风格连贯
- [ ] 分辨率 ≥ 1024px 宽

---

## Step 4: 图生视频

**输入**：参考图（8-12 张）
**输出**：视频片段（每个 5 秒）
**工具**：Runway Gen-4 / Gen-4 Turbo

### 参数模板

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 模型 | Gen-4 Turbo（迭代）/ Gen-4（最终） | Turbo 5 credits/s，Gen-4 12 credits/s |
| 分辨率 | 9:16 — 720x1280 | 抖音/小红书竖版原生 |
| 时长 | 5s | 大多数镜头 |
| Fixed Seed | 开启，固定一个值 | 保持全片风格一致 |
| FPS | 24fps | Gen-4 固定输出 |

### 关键原则

**画面驱动，不是提示词驱动**
- Gen-4 必须上传参考图（这是优势，不是限制）
- 参考图定义了一切：主体、构图、色调、光影
- 提示词**只写运动**：`slow zoom in`、`subtle pan left`
- 不要在提示词里重复描述画面中已有的内容

### 推荐流程

1. **Turbo 迭代**：每个镜头生成 3-5 个候选（成本低、速度快）
2. **Gen-4 最终**：选中的用 Gen-4 重新生成（质量最高）
3. **4K Upscale**：一键升到 4K
4. **Retime**：裁剪 + 内置手持抖动（不消耗 credits）

### 操作步骤

1. 上传参考图到 Runway
2. 设置运动参数
3. 生成 2-3 个候选
4. 选最自然的一个
5. 导出 MP4

**质量检查**：
- [ ] 无明显变形/扭曲
- [ ] 运动自然不卡顿
- [ ] 色调与参考图一致
- [ ] 无 AI 水印（付费版）

---

## Step 5: 配音

**输入**：完整旁白文字
**输出**：MP3 音频文件（每镜头一个文件）
**工具**：MiniMax Speech-02（T2A API，3.5元/万字符）

### MiniMax Speech-02 批量生成

```bash
# 批量生成所有镜头配音
export MINIMAX_API_KEY="your-key"
python docs/content/scripts/minimax-tts-batch.py

# 只生成单个镜头
python docs/content/scripts/minimax-tts-batch.py --shot S01

# 生成完整旁白为一个文件
python docs/content/scripts/minimax-tts-batch.py --full

# 预览模式
python docs/content/scripts/minimax-tts-batch.py --dry-run
```

### MiniMax 参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 模型 | speech-02-hd | 最高音质 |
| 音色 | male-qn-jingying | 精英男声（商业旁白） |
| 语速 | 1.05 | 稍快于日常，适合短视频 |
| 采样率 | 32000 | 足够语音清晰度 |
| 格式 | MP3 128kbps | 兼容剪映 |

### 配音节奏控制

- 关键数字前加停顿标记：`<#0.3#>`（0.3 秒）
- 语速：稍快于日常对话（speed=1.05）
- 句末：自然收尾，不要拖音
- 钩子部分：语气加重

### 操作步骤

1. 确认旁白文案已分段
2. 运行批量脚本生成所有片段
3. 逐段听质量，不满意可调整 speed 或换 voice
4. 所有片段导出到 `assets/voiceover/`

**质量检查**：
- [ ] 无机械感（听 3 遍不觉得假）
- [ ] 关键数字有强调
- [ ] 总时长匹配视频目标时长
- [ ] 音质清晰无噪音

---

## Step 6: 合成

**输入**：视频片段 + 配音 + BGM
**输出**：粗剪视频
**工具**：剪映

### 剪辑节奏

- 每个镜头 3-5 秒，不要超过 5 秒
- 镜头切换用硬切（不要花哨转场）
- 配音和画面对齐：说到数字时切到数据卡片
- BGM 音量 8-12%（不要盖过配音）

### 字幕

- 全程字幕（抖音 80% 用户静音刷）
- 关键数字放大加粗，用品牌色（金色）
- 字幕位置：底部中央

### 操作步骤

1. 导入所有视频片段
2. 按 分镜顺序排列
3. 导入配音，对齐画面
4. 添加 BGM
5. 添加字幕（自动生成 + 手动校对数字）
6. 导出草稿

---

## Step 7: 去AI味后期

**输入**：粗剪视频
**输出**：最终成片
**工具**：剪映

> 这一步是 10% 决定 90% 效果的关键。

### 4 项后期处理

#### 0. Runway 预处理

在导入剪映前，先在 Runway 完成这些：

- **4K Upscale**：选中的片段一键升 4K
- **Retime → Handheld Shake**：强度 10-15%（内置比剪映更自然）
- **Retime → Trim**：裁掉开头/结尾不稳定帧

#### 1. 胶片颗粒

- **工具**：剪映 → 滤镜 → 质感 → 颗粒
- **参数**：强度 15-20%，大小 1-2px
- **目的**：打破 AI 生成的"过于干净"的质感

#### 2. 光晕/辉光

- **工具**：剪映 → 特效 → 光效 → 柔光
- **参数**：强度 10-15%，范围中等
- **目的**：模拟真实镜头的光线散射

#### 3. 色彩校正

- **工具**：剪映 → 调节
- **参数**：
  - 对比度 +5~10
  - 饱和度 -5~-10（AI 视频往往过饱和）
  - 色温微调（统一所有镜头）
- **可选**：套 LUT（推荐电影感 LUT）

#### 4. 手持抖动（已在 Runway 完成）

> 如果在 Runway Retime 里已加了 Handheld Shake，**跳过此步**。

- **工具**：剪映 → 特效 → 扭曲 → 微抖
- **参数**：强度 3-5%
- **目的**：模拟手持拍摄感

### 封面帧

- 从视频中选一帧，或用 Canva 单独制作
- 要求：大数字 + 简洁文字 + 品牌色
- 比例：9:16（抖音竖版）

**质量检查**：
- [ ] 颗粒效果自然，不过度
- [ ] 光晕不抢画面
- [ ] 所有镜头色调统一
- [ ] 整体"像真实拍摄"而非"像AI生成"

## 批量生产提速技巧

1. **脚本批量化**：一次写 3-5 条脚本，建脚本库
2. **参考图复用**：同一系列视频共用 3-5 张背景图
3. **配音模板化**：ElevenLabs 保存 Voice Settings
4. **剪映模板**：做好一个项目后另存为模板
5. **后期预设**：保存颗粒/光晕/调色参数为一键预设
6. **素材库**：常用数据卡片、封面模板、BGM 分类存放

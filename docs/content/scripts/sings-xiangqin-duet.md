# Sings 破圈对唱 — 男女相亲标准大战

## 基本信息

- 歌曲类型：原创对唱（Suno 生成原创旋律，非翻唱）
- 主题灵感：《今天你要嫁给我》相亲主题，但歌词和旋律均为原创
- 主题：男女相亲标准尖锐对立
- 目标：破圈，评论区引发站队
- 时长：30-45 秒（剪映裁剪）
- 风格：快节奏 128 BPM，electronic pop beat

## 原创歌词（128 BPM 电子流行对唱，自然节奏）

> Suno 不能翻唱改编，歌词按原创流行歌节奏写作，短句 + 对仗 + 押韵

### [Verse 1] 男方标准（荒谬但有部分人认同）


### [Pre-Chorus] 对峙爆发

```

```

### [Outro] CTA（无和解，最尖锐处收尾）

```

```

## 视觉设计（4 个镜头）

### S01 — 钩子：相亲现场

- 场景：咖啡厅，男女面对面坐
- 男：西装革履，一脸自信
- 女：职业装，挑眉看对方
- 歌词字幕：[Male] 我相亲要求就三条 真的不多

### S02 — 男方标准

- 场景：男方视角的"理想型"幻想
- 男方举着清单，上面写着标准
- 歌词字幕：不能超过一百一 脾气好就行...

### S03 — 女方反击

- 场景：女方亮出自己的条件
- 女方掏出手机展示房产证/工资单
- 歌词字幕：你的算盘打得比工资还响...

### S04 — 收尾钩子

- 场景：两人同时站起来，表情复杂
- 中间出现大字：你站谁？
- 歌词字幕：站男扣一 站女扣二 说说你站谁

## 注意事项

- 歌词中的具体数字（月薪八千等）可根据实际情况调整
- 标签不要加 #彩礼 #婆媳 等容易触发审核的敏感词
- 封面用 S01 的相亲场景，女方的挑眉表情最抓眼球
- CTA 一定要引导站队，这是评论裂变的关键

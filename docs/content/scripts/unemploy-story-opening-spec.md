# 失业者来信 — 统一视频开头设计 v2

> 用途：每集视频的前1.5秒，解决2秒跳出率
> 目标受众：35-50岁失业/待业职场人
> 核心策略：陈述句给正面预期 → 制造第二层好奇"凭什么说我低估了" → 留住看故事

---

## 一句话总结

**「你的经验，比你想象的值钱」**

10个字，陈述句，不是疑问句。核心锚点是"值钱"——这是失业者最需要的肯定。

---

## 为什么这句话有效

| 维度 | 效果 | 原因 |
|------|------|------|
| 受众自筛选 | "经验"只对干了10年以上的人有意义 | 自动过滤应届生，精准命中40+ |
| 正面预期 | "比你想象的值钱"给了一个承诺 | 比"值多少钱"的疑问句更有力量，观众会想"凭什么这么说" |
| 悬念制造 | 陈述句但没有论证 | 大脑需要看到证据，必须继续看 |
| 信息密度 | 10个字，手机竖屏0.5秒可读完 | 远低于2秒决策窗口 |
| 两拍节奏 | 先"你的经验"，再"比你想象的值钱" | 第一拍建立归属感，第二拍制造好奇 |
| 通用性 | 不依赖具体故事内容 | 每集通用，不需要改字 |

---

## 分镜时间轴（1.5秒总时长）

### T=0.0-0.2s — 黑屏冲击

- **画面**：纯黑（#000000）
- **声音**：一声低沉鼓点（bass hit），频率60-80Hz，持续0.15s，衰减0.05s
- **作用**：物理层面打断刷屏惯性，与抖音默认行为形成反差

### T=0.2-0.8s — 第一拍「你的经验」

- **画面**：黑底上出现白色大字，居中
- **文字**：「你的经验」
- **字体**：思源黑体 Heavy / 苹方-简 中黑体，字号占屏幕宽度 **60%**
- **颜色**：纯白（#FFFFFF）
- **动画**：从0%透明度到100%，持续0.3s ease-out，不做缩放或位移
- **位置**：垂直居中偏上（屏幕上方1/3处），为第二拍留空间

### T=0.8-1.5s — 第二拍「比你想象的值钱」

- **画面**：第一拍文字保持在原位（不消失），第二拍从下方滑入
- **文字**：「比你想象的值钱」
- **字体**：同上
- **颜色**：全部白色，但 **"值钱"二字用金色（#FFD700）**
- **字号**：与第一拍相同或略小（占屏宽55-60%）
- **位置**：第一拍下方，两行间距约屏幕高度的5%
- **动画**：从屏幕下方滑入（translateY: 20% → 0），持续0.25s ease-out，同步淡入
- **作用**：金色"值钱"是视觉钩子——在全黑白画面中唯一亮色，自动吸引视线

### T=1.5s — 切走

- **画面**：所有文字瞬间切走（不做淡出），直接切到S01故事卡片
- **声音**：旁白第一句话在切画面的同时开始
- **作用**：1.5秒内完成开头，不浪费任何帧

---

## 系列标题如何出现

系列标题「失业者来信 | 第X封」**不在开头1.5秒内出现**。

出现方式：作为S01故事卡片的底部小字，字体小、颜色浅灰（#999999），持续2-3秒后淡出。

原因：
1. 1.5秒内放不下三组信息（核心句+系列标题+故事画面）
2. 系列标题对留住观众没有帮助，新观众不认识系列名
3. 放在故事卡片底部，不影响核心信息的视觉权重

---

## 视觉风格规范

### 字体选择

| 平台 | 首选字体 | 备选 | 说明 |
|------|----------|------|------|
| 剪映 iOS | 苹方-简 中黑体 | 思源黑体 Heavy | 系统内置，无需安装 |
| 剪映 Android | 思源黑体 Heavy | Noto Sans SC Bold | 确保粗体，不能用细体 |

### 字号计算（9:16竖屏，1080x1920）

- 第一拍「你的经验」：约 **648px 宽**（屏幕宽60%），对应字号约 **180-200sp**
- 第二拍「比你想象的值钱」：约 **594-648px 宽**（屏幕宽55-60%），对应字号约 **160-180sp**
- "值钱"金色部分：与周围文字同字号，只改颜色

### 颜色规范

| 元素 | 色值 | 说明 |
|------|------|------|
| 背景 | #000000 | 纯黑，不能用深灰 |
| 主文字 | #FFFFFF | 纯白，无阴影无描边 |
| "值钱"高亮 | #FFD700 | 标准金色，不用渐变不用glow |
| 系列标题 | #999999 | 浅灰，小字，不抢视线 |

**不要加**：文字阴影、描边、发光效果、渐变填充。纯色即可。

## 音频设计

### 鼓点音效规格

```
频率：60-80Hz（低频）
时长：0.15s + 0.05s衰减
音量：-6dB（比旁白响3dB）
类型：合成bass hit 或实录鼓皮敲击
```

### 获取方式

1. 剪映音效库搜索"鼓点"或"bass hit"，选最短最沉的一个
2. 如果没有合适的，用任意"心跳"音效替代（频率接近）
3. 不要用音乐，不要用铃声，不要用"叮"之类的高频音

### 音轨时间轴

```
0.0s  低沉鼓点（1次，0.2s内结束）
0.2s  安静（文字出现，让观众读）
0.8s  安静（第二拍出现）
1.5s  旁白开始（S01第一句话，与画面切换同步）
```

---

## 剪映制作步骤（逐步操作）

### 第1步：新建项目

1. 打开剪映 → 新建项目
2. 选择9:16竖屏比例（1080x1920）
3. 添加一段黑色背景素材（时长设为0.2s）

### 第2步：制作第一拍（T=0.2-0.8s）

1. 在0.2s处添加新片段：黑色背景，时长0.6s
2. 添加文字：「你的经验」
   - 字体：苹方-简 中黑体 / 思源黑体 Heavy
   - 颜色：纯白 #FFFFFF
   - 大小：拖到占屏幕宽度约60%
   - 位置：垂直居中偏上（屏幕上方约1/3处）
3. 文字动画：淡入，时长0.3s

### 第3步：制作第二拍（T=0.8-1.5s）

1. 在0.8s处延长当前片段至1.5s总时长（即再延长0.7s）
2. 添加第二行文字：「比你想象的值钱」
   - 字体：同上
   - 颜色：全部白色
   - 然后单独选中"值钱"二字，改颜色为金色 #FFD700
   - 大小：与第一拍相同或略小
   - 位置：第一拍下方，两行间距约屏幕高度5%
3. 第二行文字动画：从下方滑入 + 淡入，时长0.25s

### 第4步：添加鼓点音效

1. 在时间轴最开头（T=0.0s）添加音效
2. 搜索"鼓点"或"bass hit"
3. 选择最短最沉的音效，确保在0.2s内结束
4. 音量调至-6dB（比默认响一点）

### 第5步：衔接正片

1. 在1.5s处添加S01氛围空镜素材
2. **不做过渡效果**，直接硬切（cross-dissolve会让画面模糊，降低冲击力）
3. S01旁白音轨从1.5s处开始
4. 在S01画面底部添加系列标题：「失业者来信 | 第X封」
   - 字体：苹方-简 常规体
   - 颜色：#999999（浅灰）
   - 大小：约为核心文字的1/3
   - 持续2-3秒后淡出

### 第6步：保存为模板

1. 保存当前项目为模板（或复制项目）
2. 每集只需替换：系列标题编号 + S01空镜 + 旁白音轨

---

## 与正片旁白的衔接

开头1.5s结束 → 硬切到S01画面 → 旁白第一句话同步开始。

| 集数 | 旁白开场（S01第一句） |
|------|----------------------|
| 第1封 | "38岁，建材行业干了12年……" |
| 第2封 | "42岁，HR总监，干了15年……" |
| 第3封 | "45岁，To B销售干了15年……" |

开头说"你的经验值钱"，正片立刻用"38岁、12年经验"回答——观众会在脑中自动完成"这确实是有经验的人"的判断。

## 关键指标

| 指标 | 目标 | 说明 |
|------|------|------|
| 3秒完播率 | >75% | 1.5s开头+0.5s故事开头，控制在2s内给够信息 |
| 整体完播率 | >40% | 70-90秒视频的行业基准 |
| 评论区行业打卡率 | >5% | CTA"你做什么行业"的转化 |
| 滑动停止率 | 高于同类视频 | 对比同赛道前3秒数据 |

## 不要做的事

- **不要**超过1.5秒——每多0.1秒都在流失观众
- **不要**加背景音乐（鼓点即可，音乐分散注意力）
- **不要**加花哨动画（弹跳、旋转、打字机效果——降低严肃感）
- **不要**在开头放人脸（不认识的人脸不会产生共鸣）
- **不要**用红色/黄色等"短视频风格"配色（只有"值钱"用金色，其余全黑白）
- **不要**在开头透露故事结局（"他后来赚了4000块"——破坏悬念）
- **不要**在开头放系列标题（放S01卡片底部即可）
- **不要**用淡出过渡（硬切更有力）
- **不要**给文字加阴影/描边/发光（降低专业感）
- **不要**用细体字（必须用粗体/黑体，手机户外要能看清）

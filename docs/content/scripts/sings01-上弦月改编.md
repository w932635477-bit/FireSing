## 制作技术路径

保留原曲旋律（不生成新歌），需要：

1. **获取《上弦月》伴奏/KTV版本** — 剪映音乐库、QQ音乐伴奏版
2. **用 AI 声音工具生成新歌词演唱**：
   - 方案A：Suno Audio Input — 上传原曲片段 + 新歌词 → 生成同旋律演唱
   - 方案B：天工AI音乐 — 上传参考音频 + 输入歌词
   - 方案C：录 guide vocal → RVC 换声（FireSing MVP 方向）
3. **混合：AI人声 + 原曲伴奏**

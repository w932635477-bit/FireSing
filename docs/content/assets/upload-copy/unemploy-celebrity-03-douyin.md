# 抖音上传文案 — 失业名人堂 #03 马云

## 标题

阿里万亿帝国，但他高考数学1分、去KFC面试被拒、被叫骗子

## 文案

高考考了3次。
数学第一次1分。
去KFC应聘，24个人里唯一被拒。
月薪89块当翻译社小工。

1995年他骑着自行车追了6个偷井盖的，被路人当成多管闲事。电视台拍了下来。那个瘦小的男人就是马云。

被全世界拒绝的人，反而在替别人守井盖。

后来的事你们都知道了——湖畔花园18人凑了50万，做了阿里巴巴，万亿市值。

但现在AI来了。
9200万个岗位将被替代。
AI筛选简历，你连面试都进不去。

有人说：马云那个年代遍地机会，没学历还能创业，现在红利吃完了，别拿幸存者偏差灌鸡汤。
也有人说：1995年搞互联网所有人都说是骗局，2000年泡沫破裂公司差点死掉，他哪一步赶上好时候了？

是时代的问题还是你自己的问题？评论区吵起来 👇

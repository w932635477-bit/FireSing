# FireSing UI 设计文档

> Apple Human Interface Guidelines 风格 · 桌面端 MVP · 中文界面

---

## 1. 设计哲学

FireSing 是一个创作工具，不是管理后台。界面应该像 GarageBand 一样让人想上手试试，像 Final Cut 一样让人信任它的输出质量。

**三个原则：**

1. **内容为王**。歌词文本、音色波形、视频预览占据视觉重心，控件退居边缘。
2. **状态透明**。用户永远知道系统在干什么、卡在哪、需要什么操作。Pipeline 8 步进度不应该是黑色幽默。
3. **操作不可怕**。上传 50MB 文件、分配 30 段音色、启动 3 分钟 pipeline，每一步都要让用户觉得 "我随时可以反悔"。

## 2. 设计系统

### 2.1 调色板

不用 Tailwind 默认蓝色。用一套有辨识度的暖色系。


### 2.2 字体

```
标题    SF Pro Display  600 (Semibold)  或系统等价
正文    SF Pro Text     400 (Regular)
次要    SF Pro Text     400             #86868B
数字    SF Mono         500 (Medium)
```

Next.js 已配置 Geist 字体族，视觉等价于 SF Pro，直接使用。

### 2.3 间距与圆角

```
间距基数: 4px
  xs  4px    组件内元素间距
  sm  8px    同组元素间距
  md  16px   卡片内边距
  lg  24px   区块间距
  xl  32px   页面区域间距
  2xl 48px   主要留白

圆角:
  按钮/输入框    8px   (rounded-lg)
  卡片           12px  (rounded-xl)
  对话框         16px  (rounded-2xl)
  状态 badge     9999px (rounded-full)
```

### 2.4 阴影

```
卡片默认     无阴影，仅 1px #D2D2D7 边框
卡片 hover   box-shadow: 0 2px 8px rgba(0,0,0,0.06)
对话框       box-shadow: 0 24px 80px rgba(0,0,0,0.18)
按钮         无阴影 (扁平化)
```

### 2.5 动画

```
页面过渡     200ms ease-out    (opacity + translateY)
按钮 hover   150ms ease        (background-color)
进度条       500ms ease-out    (width)
步骤切换     300ms ease-out    (scale + opacity)
错误抖动     400ms (shake)
```

**交互细节：**
- 卡片网格：3 列 (1440px+), 2 列 (768px+), 1 列 (手机)
- 每张卡片显示：歌曲标题、状态 badge (带颜色点)、创建日期
- 卡片 hover：轻微上浮 + 阴影加深
- 点击卡片 → 跳转 `/songs/{id}`
- 右上角 "上传新歌" 按钮 (Primary)
- 空状态：居中提示 "还没有歌曲" + 引导上传的虚线框

- LRC 用普通文件选择
- 上传中：按钮变 loading 态，虚线区域显示进度百分比
- 成功后自动跳转详情页

## 6. 交互规范

### 6.1 加载状态

| 场景 | 表现 |
|------|------|
| 页面首次加载 | 骨架屏 (Skeleton) 或 "加载中..." 灰色文字 |
| 按钮操作 | 按钮变 disabled + 文字变为 "上传中..." / "处理中..." |
| 文件上传 | 进度百分比显示在拖拽区域内 |
| Pipeline | SSE 驱动的进度条 + 步骤列表 |

### 6.2 错误处理

| 场景 | 表现 |
|------|------|
| 网络错误 | Toast 通知：顶部红色条，5 秒后自动消失 |
| API 错误 | Toast + 详情折叠面板 |
| Pipeline 失败 | 进度页专属错误态 (红色大叉 + 错误详情 + 重试按钮) |
| 文件格式错误 | 表单字段下方红色提示文字 |

### 6.3 确认操作

| 操作 | 确认方式 |
|------|----------|
| 删除歌曲 | 二次确认对话框："确定删除 {title}？此操作不可撤销" |
| 开始处理 | 直接执行 (因为可从 error 状态恢复) |
| 其他操作 | 无需确认 |

## 10. 技术实现备注

### 当前实现 vs 本文档差异

| 项目 | 当前实现 | 本文档目标 |
|------|----------|-----------|
| 主色调 | blue-600 | #FF6B35 (暖橘) |
| 页面底色 | gray-50 | #F5F5F7 (冷白) |

| 错误提示 | alert() | Toast 通知 |
| 删除确认 | 无 | 二次确认对话框 |
| Header | 白底不透明 | 毛玻璃效果 |
| 步骤列表 | 编号圆点 | 符号圆点 (✓/●/○/✗) |
| 音色颜色 | 紫色 badge | 10 色循环 + 圆点 |

### 迁移策略

不需要一次性重写。按优先级：

1. **调色板替换** (30 min) — 换 CSS 变量，全局变色
2. **拖拽上传区域** (1 hr) — 替换 file input
3. **进度页动效** (1 hr) — 条纹动画 + 步骤图标
4. **Toast 通知** (1 hr) — 替换 alert()
5. **Header 毛玻璃** (15 min) — 一行 CSS
6. **删除确认** (30 min) — 确认对话框

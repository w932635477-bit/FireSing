# FireSing UI 设计系统 — 深色主题

> Apple HIG Dark Mode · Stitch-ready · 2026-04

---

## 1. 设计哲学

FireSing 是创作工具，界面要让用户"想上手试试"。深色主题降低视觉疲劳，突出内容本身。

三个原则：
1. **内容为王** — 歌词、波形、视频预览占据视觉重心，控件退居边缘
2. **状态透明** — 用户永远知道系统在干什么、卡在哪
3. **操作可逆** — 上传、分配、处理，每步都可以反悔

```
脉冲   2000ms  步骤指示器脉冲周期
```

## 3. 无障碍基础

- 所有按钮 `aria-label`
- 表单 `<label>` 关联
- 颜色对比度 ≥ 4.5:1 (WCAG AA)
  - #F5F5F7 on #000000 = 18.3:1 ✓
  - #98989D on #1C1C1E = 5.2:1 ✓
  - #FF6B35 on #000000 = 3.5:1 ⚠ (大文字可用)
  - #FF6B35 on #1C1C1E = 3.9:1 ✓
- 进度条 `role="progressbar"` + `aria-valuenow`
- 步骤列表 `role="list"` + `role="listitem"`
- focus-visible: 2px #0A84FF outline
